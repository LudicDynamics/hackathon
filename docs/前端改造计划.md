## 0. 现状基线与总判据

### 0.1 现状一句话

当前 `apps/web/src`（7 组件 / 1020 行）是**一份按文档写的功能占位清单**：该有的名字大都有了，但画布不是画布（卡片走 `flex flex-wrap` 流式排版）、色板用的是 doc-04 §1~§9 已降级的 NoDesign 手账口径、doc-19 的四个 P0 多模态项几乎为零。

### 0.2 三条总判据（每个阶段收工都拿这三条量）

| # | 判据 | 怎么验 |
|---|---|---|
| J1 | **画布是空间，不是列表** | 任取一张卡片拖到任意位置，刷新后位置不变；缩放以光标为锚；退出遮罩后相机回到进入前的位置 |
| J2 | **一个身份、一种物理**（doc-04 §10.1） | 截图里找不出第二种材质语言；所有影子是暖色漫射软影；hover 只有"墨底纸字反转"一种强反馈 |
| J3 | **视、听、动同时在场**（doc-19 §0.2） | 关掉声音，演示的感染力下降一半以上；打开声音，每一次拖拽/落笔/掷骰/开锁都有拟音回应 |

### 0.3 目标工期

总计约 **35.5 人时**，按 P0→P5 六阶段推进。每阶段可独立收工、独立降级（见 §8）。

## 2. P0 地基：让画布成为空间（约 5.5h）

> **这是唯一的强前置阶段。不做这一步，后面所有视觉打磨都是在给一个卡片列表刷漆。**

### T0.1 后端补齐画布状态（1.5h · `apps/server/src/routes/world.ts`）

`canvas.db` 已建好 `cards(x,y,width,height,z_index)` / `links` / `presence` 三张表，但 `/api/layer` 一个字段都没往外吐。改造：

```jsonc
// GET /api/layer?layer=world/贝克街  →
{
  "layer": "world/贝克街",
  "bg": { "src": "assets/scenes/贝克街/parchment-warm.png", "tone": "warm", "grain": "parchment" },
  "items": [
    { "path": "...", "filename": "...", "frontmatter": {...}, "body": "...",
      "x": 320, "y": 180, "w": 280, "h": 180, "z": 3, "rot": -1.8 }
  ],
  "links": [ { "id": "l1", "from": "路径A", "to": "路径B", "style": "dashed", "label": null } ],
  "presence": [ { "characterId": "华生", "x": 860, "y": 700, "following": false } ],
  "worldFrozen": false
}
```

规则：
- `bg` 从该层 `README.md` 的 frontmatter 取（doc-10 E0：**bg 是 README 的 config 字段，不是组件**）；
- 没有 `cards` 记录的文件，**服务端**用螺旋排座算出座位并**立即落库**——保证"已摆放的永不重排"（doc-06 §2.5）；
- `rot` 由 `hash(path) % 7 - 3` 派生（确定性伪随机，doc-04 §4：同一张纸每次都歪得一样）。

新增：`POST /api/card/position { path, x, y }` —— 拖拽结束回写。

### T0.2 相机（1h · `lib/camera.ts` + `state/useCamera.ts`）

抄 v3 的数学，**不抄 v2 的离散档位**：

- rAF 插值：`c += (t - c) * 0.13`，差值 < 0.1px 时吸附；
- 滚轮以光标为锚：`factor = Math.pow(1.0016, -deltaY)`，缩放范围 `clamp(0.28, 2.2)`；
- pointer 平移 + 双指 pinch；移动 > 4px 才判定为拖拽（避免误触）；
- `flyTo(x, y, z?)` 平滑推进，用于 gate 穿越、beacon 跳转、minimap 点击、"在空间中看"回跳；
- **层级相机记忆**：`CAMS[layerId] = {x,y,z}`，切层与退出遮罩时弹回（doc-06 §3.4.2 运动连续）。

### T0.3 画布渲染重写（2h · `Canvas.tsx` + `CanvasObject.tsx`）

- 单 transform 层：`translate(vw/2, vh/2) scale(z) translate(-cx, -cy)`；
- 每个物件 `position:absolute; left:x; top:y; transform: rotate(var(--target-rot))`；
- `CanvasObject` 统一承载：拖拽（pointer）、`pushFrom` 软碰撞推挤、hover 高亮关联连线、`ink-seep` 入场、`age` 风化三档；
- drop 判定分流（doc-06 §5.1）：落点与实体卡片相交 → `use_item_on`；落点在空白 → `move()` 放回场景。

### T0.4 软碰撞与排座（0.5h · `lib/collide.ts` + `lib/seat.ts`）

直接移植 v2：`PAD = 22`，被推物件位移 `×0.72`，`relaxAll` 迭代 4 轮，`.pushed` 过渡 `.25s cubic-bezier(.2,.8,.3,1)`。

### T0.5 关系线层（0.5h · `LinkLayer.tsx`）

移植 v2 `createConnection / updateLink`：贝塞尔曲线、`thread-dashed` + `dashFlow 20s`、新 dashed 线落下时旧线自动 `thread-archived`、hover 高亮整条。数据源是 `canvas.db.links`（doc-10 E13：线条属于画布状态层，不从 md 派生）。

**P0 验收**：拖一张卡片到新位置 → 刷新后位置不变 → 滚轮以光标为锚缩放 → 相邻卡片被推开 → 卡片之间的虚线跟着动。

## 3. P1 换皮：v2 的墨的物理（约 4h）

> 成本最低、观感提升最大的一段。**先做 P1 再做 P2，因为 P2 的演出都长在 P1 的材质上。**

### T1.1 Token 全量替换（1h · `styles/index.css` + `tailwind.config.js`）

| 变量 | 现状（NoDesign，作废） | 目标（v2 基准，doc-04 §10.2） |
|---|---|---|
| `--ink` | `#2B2117` | `#292820` |
| `--muted` | `#5F5142` | `#777468` |
| `--paper` | — | `#f4f0e8` |
| `--cream` | `#FFFEF6` | `#fbf8f1` |
| `--wall`（背景墙） | `#d9d0bf` | `#d9d0bf`（不变） |
| `--rust` | `#A8362B` | `#c96f4c`（作家回音 / 玩家连线） |
| `--sage` | `#5C6B57` | `#899b87`（世界门卡） |
| `--blue` | `#49626A` | `#7893a2`（note 连线） |
| `--line` | `rgba(43,33,23,x)` | `rgba(41,40,32,.15)` |

配套：
- **圆角**：按钮/面板 20px、工具栏 24px、合成面板 18px、空间触点 14px、头像 50%；
- **阴影**：`0 8px 30px rgba(45,38,28,.13)` 系 + `backdrop-blur`；仅 `.paper` 卡保留 `5px 8px 0 rgba(71,58,41,.12)` 微硬影；拖拽时 `0 22px 50px rgba(35,28,20,.32)` + z 提升；
- **交互态**：hover = 墨底纸字反转（`background:var(--ink); color:var(--paper)`）作为**唯一强反馈**；删掉现有的 scale/ring 混搭。

### T1.2 全局材质层（0.5h）

- `body::before` fractalNoise 颗粒：`baseFrequency .8 / numOctaves 3 / 180px 一格 / opacity .18`（当前完全没有，纸质感的关键一层）；
- 画布底：`radial-gradient(ellipse at 48% 42%, #eee8dc 0%, #d4c9b6 70%)`；
- 网格：80px 线性网格 `rgba(41,40,32,.035)`——**替换掉现在 28px @ .12 的圆点网格**（太密太吵）；
- 边缘 vignette（doc-19 §1.1 微距摄影质感）。

### T1.3 墨动画库（1h · `styles/animations.css`）

移植 v2 全套：

| 动画 | 参数 | 用在哪 |
|---|---|---|
| `paperForm` | `scale .92→1`，1.25s `cubic-bezier(.16,1,.3,1)` | 物件落地 |
| `textInkSpread` | `blur 3.2px→0`，opacity `.18→1`，1.35s | 文字洇出 |
| `faintMetaIn` | 延迟淡入 | 元信息小字 |
| `breathe` / `echoBreathe` | 5s / 1.6s | 角色 halo 常态 / 作家落笔共鸣 |

### T1.4 字体分工归位（0.5h）

roster 已经引全（Caveat / LXGW WenKai / Manrope / DM Mono），但用错了：
- **Caveat** 现在全站只在信件落款用了一次 → 应承担 note 标题、gate 标题、chalk 手写物、品牌字（v2 里 `.note` 就是 27px Caveat）；
- **LXGW WenKai** = 中文正文与 chalk 叙事（✓ 已正确）；
- **Manrope** = 拉丁 UI 正文；
- **DM Mono** = 元信息 9~12px 小字 + 大字距 `.06em`，以及时间印章。

### T1.5 角色在场归位（1h · `PresenceNode.tsx`）

现在角色是画布顶部一排 pill 小头像（`Canvas.tsx:126`），像个工具栏。改为 v2 `.presence`：
- 104px 径向渐变光环头像（琥珀→赭→靛→墨），`hue-rotate` 按角色名 hash 派生；
- `breathe 5s` 呼吸 + 状态点（在线绿 `#7eaa75` → 回音铁锈红）；
- **摆在场景坐标上**（来自 `/api/layer` 的 `presence`），不是固定在顶部；
- 作家落笔时全场 presence 进 `echoing` 态，状态行切"落笔中…"，写完恢复。

**P1 验收**：截图与 `画布世界v2-niko.html` 并排看，材质、色温、圆角、影子应属同一套系统；找不出第二种材质语言。

## 4. P2 多模态四件套（doc-19 的 P0，约 8h）

> **原型里无处可抄，必须自研。** 两份原型都没有声音、没有动态背景、没有骰子仪式、没有表情差分——照着原型打磨到"好看"，交出去的还是一个静态画布。

### T2.1 全景声场（2.5h · `lib/audio.ts` + `state/useAudio.ts`）

引 Howler，三层结构（doc-19 §2.1）：

| 层 | 内容 | 触发 |
|---|---|---|
| L1 Ambient | `rain.mp3` / `fireplace.mp3` / `cellar_drip.mp3` | 切层时按该层 README 的 `ambient` 字段交叉淡入淡出 **1.5s** |
| L2 BGM | `calm.mp3` / `tense.mp3` / `crisis.mp3` | 按作家单轮返回的 `mood` 标签平滑切换音轨增益 |
| L3 Foley | 8 个短音效（见 §6 资产清单） | 拖拽 / 收纳 / 掷骰 / 开锁 / 落墨 / 开门 / 检定成功 / 大失败 |

实现要点：全局单例；首次用户交互后才 `unlock()`（浏览器自动播放策略）；顶栏留一枚静音开关（演示现场必须能一键静音）。

### T2.2 2.5D 视差与粒子（2h · `SceneBackdrop.tsx` + `ParticleLayer.tsx`）

现状只有 `perspective:1200px` 和鼠标 ±3deg 倾斜。补齐：
- **三层速率分离**（doc-19 §1.1）：前景浮层 1.35x 反向位移、中景（物件层）1.0x、远景背景 0.25x；
- **远景**：`SceneBackdrop` 读 `/api/layer` 的 `bg`，`.webm/.mp4` 走 `<video autoplay loop muted playsinline>`，图片走 `<img>`，缺省走材质底纹；
- **前景粒子**：40 行左右的 Canvas 粒子层（室内浮尘 / 室外雨丝雪花），按 README 的 `bgStyle.tone` 选粒子类型，性能预算 < 2% CPU；
- **vignette**：边缘物理暗角，中央焦点保持微距感。

### T2.3 掷骰仪式（2h · `DiceCeremony.tsx`）

现在的 `DiceRoller` 是 60px 骰子嵌在 chalk 卡里。升级为全屏仪式（doc-19 §3.3）：

```
点击骰子卡 → 全屏压暗 40% + 悬念滚奏音效
           → 按住蓄力（蓄力条 + 音高升高）→ 释放
           → 大号 2.5D 骰子翻滚 1.2s + 实木撞击拟音
           → 服务端真随机 + expect 判定
           → 大成功：金光爆裂 + 华丽和弦 / 大失败：猩红裂痕 + 断弦重音 + 全屏震颤
           → 结果回写 frontmatter.result + 落事件表 → 卡片落定
```

保留现有的 `/api/dice` 契约（`{filePath, rollType, expect}` → `{result, passed}`），只换表现层。CSS 3D Cube 复用现有实现，尺寸放大到 ~160px。

### T2.4 以物解谜演出补全（1.5h · `RightSidebar.tsx` + `CanvasObject.tsx`）

链路已通（`/api/use-item`），缺的是**手感与反向操作**：
- **场景 → 背包**（doc-06 §5.1 第一行，当前完全缺失）：场景卡片可拖，右侧边栏做 drop 区，落下 → `move(场景目录 → player/)` + 皮扣"啪嗒"音；
- **合法目标高亮微吸附**：拖起背包道具时，可接受 `use_item_on` 的实体（门/锁/箱/角色头像）发微光并轻微吸附；
- **开锁演出**：命中后播放咔哒音 + 目标卡片抖动 + 内容物幻影落地。

**P2 验收**：戴上耳机走一遍 demo 动线，拖拽、收纳、掷骰、开锁每一步都有声音回应；场景切换时环境音平滑换底；骰子结算能让旁观者"哦"一声。

## 5. P3 接真数据：消灭演示穿帮点（约 7h）

### T3.1 角色 agent 流式打通（2.5h · `apps/server/src/index.ts` + `CharacterModal.tsx`）

**当前最致命的假数据**：`CharacterModal.tsx:53` 的回复是本地 `sampleReplies` 随机数组，而服务端 `character_prompt` 分支是个空注释。

- 服务端：`character_prompt` 接到消息 → 转发给 `lifecycle` 里对应的角色进程 → 流式 token 通过 WS `character_token` 逐字推回，结束发 `character_done`；
- 前端：删掉 `sampleReplies`，改为订阅 WS 流；
- **逐字流式的节奏 = 角色性格的主秀场**（doc-06 §3.2）：不同角色配不同的每字延迟基数。

### T3.2 6 表情差分（1.5h · `lib/emo.ts` + `CharacterModal.tsx`）

- 资产：每角色 6 张（`normal/smile/shock/sad/angry/thinking`），路径约定 `assets/characters/<角色>/emo/<tag>.png`；
- 驱动：角色 preset 约束句首输出 `[emo: <tag>]`（`presets/character.json` 已需同步）；
- 前端：流式解析首部标签 → 平滑切图（`transition: opacity .35s` 交叉淡入）→ 从可见台词中滤除标签；
- 立绘 `scale 1.02` 呼吸循环。

### T3.3 遮罩的四条连续性（1.5h · `CharacterModal.tsx`）

当前遮罩底是 `bg-black/60`，**直接违反 doc-06 §3.4.1**（"遮罩的底 = 画布本身压暗+虚化，不是黑底不是独立背景图"）。改：
- 视觉连续：画布不卸载，套 `filter: brightness(.35) blur(6px)`，玩家仍能隐约看见炉火与便签；
- 运动连续：进入 = `flyTo` 锚点推进到角色头像 → 压暗虚化 → 对话框从底部升入；退出 = 对称逆播 + 相机弹回进入前状态；
- 空间连续：对话框锚定在**角色立绘所在的位置**，不是屏幕正中凭空出现；
- 结构连续：对话期间世界不停，退出后画布上应能看到新落地的东西（**money shot：这场对话改变了画布**）。

### T3.4 作家演出通道（1.5h · `writer/WriterChannel.tsx`）

现在选 choice 只弹了个 toast 就靠 `file_changed` 全量重拉。按 doc-06 §2.1 补：

```
玩家输入/选 choice → 纸条折起飞出（~400ms）→ 红杆铅笔从上空落下（420ms）
                  → 悬停呼吸（~500ms，"在想"）→ chalk 湿墨流式写出 + 刮纸拟音
                  → 世界变化（幻影壳 ghostWrite → 内容落地 → 座位过户）
                  → 洇干落定 → 收笔淡出
```

配套：
- **状态机**：`idle ⇄ writing`。writing 中再按 Enter → placeholder 变"作家正在写……"，输入无效（诚实，不排队不打断）；writing 中切层 → 整条撤回，写了一半的旁白原地擦掉；
- **perm vs temp**（doc-06 §2.2）：叙事落定进 LAYERS；引导提示 8s 后淡出+右移（像被手抹掉），不落盘；
- **主画布玩家自由输入**：现在主画布上玩家**根本没有输入框**，只能点 choice。补 v3 的 `FloatingInput`（折叠 pill → 展开 writing-surface 横格纸）。

### T3.5 时间印章（0.5h · `chrome/TimeSeal.tsx`）

`App.tsx:255` 的"第 1 天 · 暴雨初歇 17:40"是硬编码字符串。改为从最新 chalk 的 `frontmatter.status.data` 取时间/天数，DM Mono 大字距呈现。doc-19 §3.2 明确：**这是唯一的常驻状态 UI，不做理智罗盘/金币袋/数值条**。

**P3 验收**：断网时前端不再"假装有人回话"；跟角色说一句话，回来看画布桌上确实多了东西。
