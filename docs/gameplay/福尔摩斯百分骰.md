# 福尔摩斯百分骰（简化类克苏鲁）

福尔摩斯英日模板 `whitechapel` / `whitechapel-jp` 调查统一使用 `1d100`、`expect: '<=60'`，低掷成功。不是完整克苏鲁规则，也不引入技能成长、理智或奖励骰。

| 骰点 | 判定 |
|---|---|
| 1–12 | 大成功：额外发现 |
| 13–60 | 成功：得到线索解释 |
| 61–95 | 失败：保留下一步与见漏记录 |
| 96–100 | 严重失败：失去隐蔽调查机会，但不切断唯一出口 |

各档保留原世界的事实、选项与物品奖励；反转的是骰点方向，不是真相。服务端声明动作投骰返回与保存的回执将 `crit` / `fumble` 对齐上述分档，不能沿用“100 大成功”的高掷标签。百分骰动画沿用双 D10 位权展示，不额外产生随机数。

本批成功率固定 60%。RP、证物、谜题难度的动态修正未实现，不能让作家事后修改门槛。其他世界保留 2d10 高掷成功。

模板转换工具 `tools/experiences/holmes-percentile.mjs` 只重排四档并替换骰型和规则说明，保留英日正文、动作、奖励；跳过已有结果的文件。不会自动迁移玩家存档或重算旧骰点。

回归：`tools/direct-world-actions.test.mjs` 覆盖 1/12/13/60/61/95/96/100 边界、成功方向、大成功/严重失败、重复请求不重掷及奖励幂等。
