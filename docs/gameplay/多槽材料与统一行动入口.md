# 多槽材料与统一行动入口

2026-09-14。本批实现统一选择分发和多槽材料准备；不重做叙事引擎，不修改 pi-rp，不覆盖玩家存档。

## 按钮声明决定行为

画布悬停、原位阅读和背包阅读复用 `EntityInteractions`。不得由阅读页另行直调 `/choice` 而丢掉返回的 `action`。

| 声明 | 当前执行方式 |
|---|---|
| `read` / `take` / `enter` | 打开已存在内容、既有物品移动、既有进层通路；不派发作家 |
| `reply` | 直接显示预写回答，不调用模型 |
| `character` | 打开角色对话；不会自动代玩家发送问题 |
| `stage` | 多槽选择材料；准备审核草稿，不提交、不执行 |
| `writer` | 复杂请求进入作家输入框，允许修改，Send 才执行 |
| 未声明的旧 choice | 前端兼容：先填作家栏；不靠模型猜按钮分类 |

点击材料选择 ≠ 准备审核草稿 ≠ Send 请求审核 ≠ 后续确认执行。审核草稿明确要求只审核一次、区分证据与推论，不消费物品、不实施计划、不生成结局。**这是请求范围和现有短回合限制，不是工具级只读沙箱；不能声称已硬性禁止模型越界。**

## 多槽声明

声明仍在原 Markdown 的 `choice_actions`，用 `choice.options[].id` 对应，不用显示标题作为 ID。

```yaml
choice:
  options:
    - id: prepare-review
      label: 整理した材料を確認する
choice_actions:
  prepare-review:
    kind: stage
    slots:
      - id: evidence
        title: 推論と根拠
        required: true
        paths: [player/deduction.md, player/alternative-deduction.md]
      - id: plan
        title: 安全な実行計画
        required: true
        paths: [player/operation-plan.md]
```

- 1–8 个槽，每槽支持多份材料；默认容量为该槽去重后的候选数，可用 `maxItems: 1` 明确限制单份（允许 1–12）。总候选与提交文件不超过 12 个。
- 同槽多选在 `selections` 中使用重复的 `slot`、不同的 `path`，每份保留独立版本。选择、移除、切槽始终可操作，仅准备审核请求期间锁定；点击材料优先进入当前兼容槽，否则进入兼容槽。
- `paths` 是此槽的候选范围；前端可查看全文、替换和清空，不能偷偷把未选材料送给作家。
- 必填槽缺件时禁用准备按钮；服务端重复校验。一个文件不能占两个槽。
- 检查存在、路径资格与版本，不检查「推理是否正确」。可选槽空着不阻断。
- 旧 `stage.paths` 兼容转换成逐文件可选槽；新模板使用显式 `slots`。
- 通过已记录的移动事件解析文件搬移，不凭同名文件猜身份。

## 请求与版本

`POST /api/choice` 维持 `{ path, choice }`。stage 返回 `world/source/choice/revision/slots/items/missing`；每项材料带 `declaredPath/path/revision/title/body`，revision 为原始文件 SHA-256。

`POST /api/material-review`：

```json
{
  "world": "<active world root>",
  "path": "world/review.md",
  "choice": "prepare-review",
  "revision": "<source SHA-256>",
  "selections": [
    { "slot": "evidence", "path": "player/deduction.md", "revision": "<file SHA-256>" },
    { "slot": "plan", "path": "player/operation-plan.md", "revision": "<file SHA-256>" }
  ]
}
```

成功返回 `{ ok:true, prompt, materials }`，仅生成前端草稿；不派发 Agent、不移动文件、不重复记 choice。服务端重读声明和材料，拒绝旧版本、越界槽、重复文件、缺必填项；世界已切换返回 409。材料快照总长度最多 32000 字符，超限明确报错。

草稿固定这次选中的正文版本；之后编辑源文件不会悄悄替换草稿里的证据，需要重新准备。玩家主动修改草稿仍属于自由输入，不冒充未修改的结构化提交。

## 模板与本批边界

`tools/experiences/choice-bindings.mjs` 与五处模板入口同步：雾坞材料、福尔摩斯两份文章、分支线传真草稿、魔法草稿。新存档可用；旧存档保留现有剧情与声明，旧 paths 也可打开兼容槽位。

仍待下一批：简单动态询问的受限角色回合、通用「审核回执 → 确认执行」协议、资源奖惩的原子兑现。既有 `dice_outcomes` 的四档文字回写复用，不宣称已支持任意骰型或自动发奖扣物。福尔摩斯现有骰子快捷路径保留，材料审核不是强制作文关卡。
