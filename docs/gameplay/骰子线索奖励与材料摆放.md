# 骰子线索奖励与材料摆放

2026-09-14：玩法提示与叙事分开。带 `dice_outcomes` 的 Chalk 在桌面仅显示场景短句与已裁决结果，概率、骰型说明与操作规则保留在实体 hover 的展开说明中，不作为剧情正文投射。`<!--resolved-dice:13-->`（空白可选）解析为结果边界，不显示源码；结果正文与奖励物品默认折为可点击信封，点击再展开。

## 材料与纹理

材料面板复用 `opened-letter-paper.webp`，候选区复用 `inventory-suede-lining.webp`，材料纸片复用 `location-hover-paper.webp`。点击槽位后点击材料，或拖材料到兼容槽位。移动已选材料会清除原槽；查看、移除、必填校验和服务端文件版本校验保留。选择不执行，审核仍需显式发送。

## 物理演出

共用 D10Stage 支持 `1d10`、`1d100`、`2d10`，另支持 `1d6`、`2d6` 的方骰物理形状。`2d10` 是两颗相加，不是百分骰；0 面各自解释为 10。服务端骰点始终唯一权威，前端仅模拟碰撞轨迹和与结果一致的朝向。不改变概率、阈值或世界规则。

## 线索奖励

`dice_outcomes[].rewards` 可选数组（至多三项）：`{path,title,body}`；路径必须在 `world/` 内且不是 README。雾坞和福尔摩斯体验版各档声明调查记录：成功获得调查笔记，大成功获得额外发现笔记，失败保留见漏与下一步记录，不伪称获得成功线索。

玩家落定面板根据服务端 `outcomeGrade` 展示档位：成功柔光、大成功较强金色柔光、失败轻微偏移与沉色；遵守系统减少动态设置。不是按动画重新判定成功。收纳演出独立于投骰演出，仅来自持久化物品事件。

服务端先保存骰子回执，再经 `createEntity` 生成 `portable: true` 的 note，附 `dice_reward: {source,result,grade}`。不会直接塞进背包；Chalk 增加收纳动作。收纳仍走 `moveEntity`，只有成功世界事件才触发右上角短暂绒面提示，不根据点击猜测成功。

同路径不同来源物品拒绝覆盖；重复处理追踪移动事件，不重复生成已领取或删除的奖励。失败可按原骰点重试，不重掷。文件与事件不是跨动作事务，发生部分失败时保留真实已成功动作，不能宣称全部完成。

旧存档不自动覆盖模板，也不追溯发奖。已有 `dice_outcomes` 但无 rewards 的存档保留原裁决；需要单独迁移时先备份并核对当前剧情。

验证：`apps/web/test/dice-stage-types.test.mjs`、`tools/dice-rewards.test.mjs`；材料版本回归见 `tools/material-review.test.mjs`。
