# 月下之誓 契约开场

模板 `templates/moonlit-contract`，显示名 **月下の誓い — The Moonlit Pact**，语言日语。入口只有一个 opening、一张背景 CG、一件未结契约的蓝丝带；骑士由背景与 Writer 台词演出，不额外增加角色卡或角色小天地。

用户最终要求：女性主角在左、男性骑士在右，保留月下契约的左右构图，尚未握手，以免 CG 提前替玩家作决定。早期角色 CG 不进入版本库，最终版本移除已有作品专名和标志性角色装束。BGM 复用 emberglass（Mystical/fantasy loop，CC0）。

契约前允许询问与拒绝。明确同意且请求出发后，Writer 从当前 README、opening 和实际物品读取上下文，先记录约定，再生成一个月下中庭子目录。之后每次明确继续，生成当前目录直下的一层：README、opening、item、独立背景图。已有场景回访复用，只补缺件，不连续后台递归生成。

初始只生成并发布开场 CG；后续背景通过现有 generate_image 按需生成。autoWrite=scenes，普通选项仍需在侧栏选择后 Send。继承现有初始化协议，未修改引擎。

验证：检查世界 manifest、唯一 opening 和物品、图片路径、BGM 文件、选项解析与目录扫描。真实 Writer 续写与后续生图需配置供应商并运行，没有用静态检查冒充生成成功。
