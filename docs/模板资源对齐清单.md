本仓库文档优先。已检查 `origin/main` 的 `doc-24-五世界可玩Demo体验设计.md`（`cae7cc9` 收紧后的评审稿）：已确认的身份与世界真相保持；短 Demo 选项、最终动作、结局与 CG 候选不视为定案。当前 niko 上旧四世界长流程施工单不能用来覆盖远端的新边界。本次不自动 merge 正在协作中的 main。

## 本轮已落实

| 模板 | 正式图片 | 背景 | 玩家 | 图像角色映射 |
|---|---:|---:|---|---|
| wuwu | 10 | 6 | investigator | viola → vera；silverkite → silver-kite；keeper → old-mo |
| whitechapel | 12 | 5 | sherlock-holmes | watson / edith / wayne / blackburn / tom |
| divergence | 10 | 6 | returner | ryo → ryo-child；shopkeeper |
| firstsnow | 9 | 6 | radio-director | nanami；sumi → sumi-yukimura |

- 图片保留世界内相对路径，由 `/api/asset` 提供，不打包进前端 JS。
- 场景 README 的 `bg`、人物 README 与实体的 `avatar`、manifest 的角色与封面同步接图。
- `world.json.player` 声明玩家 id / name / avatar；玩家不是 NPC，不混进 `characters`。前端左下角读取它，旧模板仍可省略。
- `assets/source-manifest.json` 记录源图和 WebP 的 SHA-256，后续可以识别同名换图；质量 82。
- `node tools/sync-template-assets.mjs` 只同步素材与相关字段，不重建对白、记忆、preset 或故事线。旧 `migrate-canvas-worlds.mjs` 会重建内容，不应用作日常素材更新。
- `node --test tools/template-assets.test.mjs` 验证完整性和引用。
