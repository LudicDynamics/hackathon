# 提案：角色对话框加入 GPT-Live 语音通话模式

> 状态：**已采纳（2026-09-15）**，由 `10-对话框通话-共同上下文.md` 冻结、`13-门禁与回写.md` 登记。实现落在 `apps/web/src/lib/live-call-store.ts`（单例）+ `apps/web/src/components/overlay/CharacterModal.tsx`（通话版面）。**本文保留为提案历史，不再是权威契约；与 `10` 冲突处以 `10` 为准。**
> 原需修改的冻结契约：`docs/live-voice/00-共同上下文.md`（yoshi 批次 L）——已按 `docs/live-voice/10 §1` 完成修订（§0 / §2.1 / §4 / §7.1）。

## 0. 一句话

角色对话框（`CharacterModal`）增加「语音通话」模式：玩家按下通话按钮后，与角色进行 GPT-Live 全双工语音对话。GPT-Live 是端到端通道（听、说都由它完成），所以这个模式下**不使用逐页朗读（TTS），也不使用语音转写（STT）**。角色大脑仍是 pi-rp 角色 agent（沿用 `00` 的 client delegation，不变量 1 不变）。

## 1. 为什么

- 现在对话框只有「打字 → 角色 agent 回复 → 逐页 TTS 朗读」一条路；GPT-Live 只在心象風景（nook）里可用，入口深、玩家很难发现。
- niko 希望对话框里能选「文字 + 朗读」或「语音通话」，并即时切换。
- GPT-Live **不是 TTS 引擎**（不能把一段固定台词交给它念），所以不会作为 `/api/tts` 的回落目标（与 `00` §2.1、§5.6 一致）。朗读的回落顺序见 §5，与本模式分开。

## 2. 行为

| 项 | 文字模式（现状） | 语音通话模式（新增） |
|---|---|---|
| 输入 | 输入框 + 语音转写按钮（STT，只写草稿） | 麦克风直连 GPT-Live（WebRTC） |
| 角色回复的来源 | 角色 agent 的 `character_message` | 同左（delegation 回灌后 GPT-Live 说出） |
| 声音 | `/api/tts` 逐页朗读（本机 / 千问） | GPT-Live 语音；**逐页朗读关闭** |
| 文字 | 翻页显示 | 字幕：输入/输出转写 + `character_message` |
| 开场招呼语（本地写死的一句） | 显示并朗读 | 不显示 |

- **进入**：对话框内有「文字 / 通话」切换，通话模式下显式点「开始通话」才建会话（`00` §2.9：MUST NOT 自动开通话，按分钟计费，建会话预扣 15 秒）。
- **退出**：点「挂断」、切回文字模式、关闭对话框、世界切换，任意一种都挂断（`POST /api/live/close` + data channel `session.close`）。
- **可用性**：`GET /api/live/config` 返回 `available:false` 时不渲染通话切换（`00` §2.9），文字模式照常。
- **语言**：沿用 `00` §2.10，`'en' | 'ja'`，由前端按世界语言传入；界面为中文时通话语言按世界语言，而不是界面语言。

## 3. 复用什么（不新增接口与帧）

- 端点：`POST /api/live/session`、`POST /api/live/close`、`GET /api/live/config`，**形状不变**。
- 前端：`apps/web/src/lib/live-call.ts` 的 `useLiveCall`，**接口不变**，对话框与 NookView 共用。
- 帧：继续消费既有 `character_delta` / `character_message` / `character_idle`（`00` §2.8，不新增 `live_*` 帧）。
- 角色 agent 生命周期、音色映射（`resolveLiveVoice`）、instructions 边界：全部沿用 `00` §2.4–§2.7。

## 5. 附带：文字模式的朗读引擎顺序（niko 需求）

与语音通话无关，但同一批讨论：

- 引擎只有两个：**本机**（setsuna，经 Tailscale；部署版经 Tailscale Funnel，见 `docs/development/Vercel验证部署.md`）与**千问**（DashScope）。
- 设置面板提供「本机优先（失败回落千问）/ 千问优先 / 仅千问 / 仅本机」，写入服务端配置（如 `AIRP_TTS_ENGINE_ORDER`），`/api/tts` 每次请求重新读取，改完立即生效。
- 这项只改 `docs/tts/` 的选路，不触及 `00`；可以先于通话模式单独做。

## 6. 风险与未决

1. **费用**：通话按语音时长计费，沉默也计费。建议对话框里显示「通话中 · 按分钟计费」，并在页面隐藏（切标签页）时自动挂断，待确认。
2. **角色 agent 无崩溃重启**（`00` L-C2）：通话中角色 agent 退出，只能靠超时兜底；对话框需要把超时错误显示在可见位置（`00` §5.7）。
3. **音色撞车**（`00` L-C1）：GPT-Live 音色少于 DashScope，同世界可能多人同声；对话框里更容易被察觉。
4. **真机未验证**：`00` §7.3 输入转写是否稳定到达仍待一次真实通话验证；本提案实现前应先在 nook 里做这次验证。
