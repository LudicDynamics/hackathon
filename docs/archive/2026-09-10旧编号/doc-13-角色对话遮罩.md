# 角色对话遮罩（特写态）

> 2026-09-08。明月提议：双击角色进入 Galgame 式遮罩，玩家与角色直接对话。
> 张力自陈：可能破坏画布的存在感，但表现效果好、接近游戏感。
> 本文立场：**这个 option 成立，但要给它立规矩**——做对了它是画布的一种光学状态（特写），做坏了它是"离开游戏进菜单"（双层架构错误的重演）。

## 0. 概念重构：不是遮罩 vs 画布，是注意力光学

人跟人说话时，视野聚焦到对方，环境退为背景——这是注意力的生理结构，不是界面切换。

- 双击角色 = **凑近一个人说话**，画布失焦（不是消失）。
- 剧场对应物：**追光**（打在演员身上时，舞台没有消失）。
- 电影对应物：**特写**（全景/特写切换是基本语法，观众从不觉得"离开电影"——因为连续性没断）。

**判据**：遮罩做得对不对，就看玩家退出时是否"回到"画布——如果玩家的心智是"结束了另一个界面"，就失败了。

## 1. 空间操作家族（人也是一扇门）

| 操作 | 对象 | 结果 | 运动语言 |
|---|---|---|---|
| 双击门卡 | 地方 | **换画布**（跨层，去另一个地方） | 锚点推进 → 门面 → 展开 |
| 双击精灵 | 人 | **开遮罩**（同人层，凑近一个人） | 锚点推进 → 压暗虚化 → 对话框升入 |
| Esc | — | 对称退回 | 退回你原来的位置/相机 |

门后面是另一个地方，人后面是一场对话——**AIRP 的两种深度用同一种运动语言（推进）表达**。空间连续性由"推进到谁/什么面前"保证。

## 2. 气泡 vs 遮罩的分工（什么时候用哪个）

| | 气泡 | 遮罩 |
|---|---|---|
| 媒介身份 | 画布的一部分 | 画布的特写态 |
| 内容 | 一句半句：路过搭话、场景回应、氛围台词 | 一场戏：有来有回、多轮、情绪推进 |
| 话的性质 | **公共**（旁观者听得见） | **私密**（凑到耳边） |
| 寿命 | 说完就散 | 形成记忆/关系 |
| 架构对应 | 轻量上下文（场景黑板+一句上文） | 角色进程主场（角色卡+关系史+场景状态） |

两个判据合用：**一句话/公共 → 气泡；一场戏/私密 → 遮罩**。对话深度决定上下文深度——气泡是 rp 进程的"前台窗口"，遮罩是它的主场（doc-12 懒灵魂：双击=强制 spawn+正式会谈）。

## 3. 四条连续性（护住画布存在感的工程清单）

这是"特写"与"另一个界面"的分界线。四条缺一，遮罩就退化成独立界面：

1. **视觉连续**：遮罩的底 = **画布本身压暗+虚化**（不是黑底不是独立背景图）。你能隐约看见炉火、便签、门——你仍然知道你在临江旅店，就在柜台前。
2. **运动连续**：进入=锚点推进（goEnter ①段同款数学，终点从门卡换成精灵）；退出=对话框降下、压暗淡出、相机弹回双击前的状态（画布记忆原则）。
3. **空间连续**：对话框锚定在**精灵所在的位置**（立绘=精灵放大），不是屏幕中央凭空出现——你凑近的是"那里的他"。
4. **结构连续**：**对话的后果退场时由画布揭示**——对话期间世界没停（作家写板书、别的东西落地，透过压暗隐约可见），退出后玩家主动看一眼画布："桌上多了碗汤"。**对话改变画布**，遮罩反而是强调画布存在感的手段。

## 4. 遮罩的解剖（Galgame 元素的批判性筛选）

| Galgame 标配 | 取/舍 | AIRP 版本 |
|---|---|---|
| 立绘 | ✅ 取 | **精灵放大**（同一真相——另做一套立绘素材就是双层架构错误重演；SVG 无所谓放大） |
| 对话框 | ✅ 取 | 纸材质、信/便签同族（token 复用），框内不是打字机黑体，是**角色的字** |
| 逐字流式 | ✅ 必须 | **节奏=角色性格的主秀场**（doc-12 节奏参数：老周慢半拍在遮罩里被放大感受——同一句话节奏天差地别） |
| 玩家输入 | ✅ 保留 | 纸条通道内嵌（对话框底部一行输入）——对话形态=角色流式+玩家自由输入 |
| 选项 | ✅ 作家可塞 | 黑板选项板迁移（doc-02 §6：`[A]`可点按钮、`until`过期），选项是快捷方式不是唯一通道 |
| 旁白 | ⚠️ 降级 | 作家退场（导演不介入演员的戏）；必要旁白用**描述行**（对话框上沿斜体小字） |
| 属性栏/亲密度 UI | ❌ 舍 | 原型不做系统 UI（低阈值不渲染） |
| 全脸眨眼/口型 | ❌ 先舍 | 精灵 idle 呼吸动画的放大版够用；留题材包 |

## 5. 期间与作家：三人各在哪

- **角色**：主场演出（气泡流式、节奏性格）。
- **作家**：退到幕后（他的编排物化为角色台词的时机与内容，doc-12 契约不变：作家给舞台指令不给台词）。
- **玩家**：主演（输入纸条；选择选项；中途 Esc 走人）。
- **画布**：压暗但活着——世界事件继续透出（强于"暂停世界"：世界不等你的对话）。

## 6. 双击 vs 单击的输入分工

- 单击精灵 = 场景搭话（气泡一句 + 醒来动作，doc-12 §3）。
- 双击精灵 = 正式对话（遮罩一场戏）。
- 双击门 = 穿越换画布——**双击 = "深度交互"的统一动词**（地方和人都是双击进入），输入语言的对称又一次来自"人也是门"。

## 7. 原型验证清单

1. **进入动效**：锚点推进到老周 → 画布压暗虚化（CSS filter + transition）→ 纸对话框从底部升入 → 老周 SVG 立绘放大呼吸。
2. **对话循环**：老周流式台词（慢节奏）→ 等输入 → 应答（canned 多轮：问汤/问房/问楼上那位常客）。
3. **选项演示**：某一轮塞三个选项（黑板选项板机制）。
4. **退场揭示**：对话里答应住店 → Esc → 退出遮罩，钥匙便签在柜台落地（**money shot：这场对话改变了画布**）。
5. **中途 Esc**：对话框降下、压暗淡出、相机弹回——"失礼离场"也走完整的退场动画。

## 8. 待定

1. 遮罩内自由输入的兜底应答深度（原型 canned 三轮就够，真实架构靠 rp 进程）。
2. 对话中途 Esc，角色记不记得你半途而废（角色记忆——架构层课题，原型不做）。
3. 对话记录要不要物化（关键承诺落成画布上的字条——和"后果揭示"天然一体，原型可做一例）。
4. 多人对话遮罩（群聊）远期；画布上围桌而谈 vs 遮罩内多人立绘，到时候再争。
