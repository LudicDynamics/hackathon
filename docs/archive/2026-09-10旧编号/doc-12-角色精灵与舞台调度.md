# 角色精灵：编排的表现问题（剧团模型）

> 2026-09-08。回应明月的发现：独立角色+编排的架构里，**编排难以表现**。
> 结论先行：架构不用推翻——**编排不直接表现，编排物化为演员的动作**。戏剧几百年前就解决了这个问题：观众从来不需要看见导演。

## 0. 问题重构：把"表现编排"换成"编排落在哪个动作上"

- 编排难表现，是因为把它想成了消息传递（谁给谁发了什么指令、等谁的回复）——消息在视觉上是隐形的，画出来也没人想看。
- 剧场的答案：观众看到的全部是演员的动作。导演的决定 100% 物化为**走位**（谁去哪）、**动作**（做什么）、**台词**（说什么）。
- 设计纪律：**编排的每个决定必须落在一个可见动作上；没有可见落点的编排是幕后工作，不该画出来。**

## 1. 剧团隐喻：三者各自的可见身体

| 剧团 | AIRP | 可见身体 |
|---|---|---|
| 导演 | 作家 | 一支笔（飞行轨迹 = 编排痕迹；只现身，不说破） |
| 演员 | 角色精灵 | 身体（精灵+走位）、声音（流式气泡）、生活（idle） |
| 主演兼观众 | 玩家 | 纸条（对作家）、点击（对角色） |

## 2. 三个通道（媒体分工——沿用"一个媒介一句话"的纪律）

| 媒介 | 谁 | 特性 |
|---|---|---|
| 气泡 = 台词 | 角色 | 流式、**自己的节奏**、说完就散（口头的话） |
| 板书 = 旁白 | 作家 | 流式、落定永久（书面的话） |
| 走位 = 调度 | 编排 | 笔碰一下 → 人走过去（空间的决定用空间表达） |

谁在说话由媒介直接编码——气泡里的话一定是角色说的，板书上的一定是作家写的。
这层分工不能塌：**作家替角色写台词，观众就再也分不清谁在场**。

多角色场景的扩展：**笔的位置 = 聚光灯**。笔在谁那里，谁在台上——笔依次飞向将说话的角色，就是最自然的轮转指示。

## 3. 独立角色的三件自有物

1. **自己的节奏**——气泡逐字流式的速度 = 性格参数（老周慢半拍，集市小贩机关枪）。节奏是角色的第一可视人格。这是流式底座的隐藏红利：作家写字有节奏，角色说话也该有节奏。
2. **自己的生活**——idle 行为（擦杯子、挑火、踱步）。没剧情时角色也在活——"世界在自己动"的角色版。
3. **自己的醒来**——被搭话的瞬间从 idle 态切注意态（抬头、停手、面向你）。doc-02 §4.5 liveness 的戏内版：用动作表达"他在听"，**不用 spinner 表达"进程在跑"**——工程状态永远不画给用户（戏内动作 vs 工程控件的分界）。

## 4. 懒灵魂：第一句话才存在

- 画布层：第一眼才存在。角色灵魂：**第一句话才有**。
- 角色独立进程按需 spawn：你第一次跟老周说话，他的 rp 进程才启动；精灵从"画"变"人"。
- **延迟被演出吸收**：spawn 延迟（几百 ms～秒级）正好被"醒来"动画吃掉（低头擦杯子→抬头看你）。等待不是要遮掩的丑，是戏的一部分。
  同构：Nodesign 幻影物件吸收生图延迟；**走位吸收生成延迟**（边走边想，走到位话也到，气泡开始流）。

## 5. 架构契约的对应修正

- 编排给角色的**不是台词**（那是提线木偶，"独立角色"名存实亡），而是**舞台指令**：情境 + 开口时机 +（可选）走位。
- 台词必须从角色自己的进程出——独立性的实义。
- 视觉一一对应：**笔只管调度（碰一下/领着走），话角色自己说（气泡自己的节奏）**。
- writerAct 的 say 步骤据此拆两拍：
  - **cue（说戏）**：笔飞到角色悬停 + 气泡冒「…」「……」「………」逐点（欲言又止 = 在被说戏/在想，三连点本身就是 thinking 指示器）；
  - **say（台词）**：气泡清空换正式台词，流式逐字，节奏 = 角色参数。

## 6. 不表现什么（纪律）

- 上下文组装、记忆检索、编排内部决策——全部隐形。
- 反面教材：角色头顶 spinner——把工程状态画给了用户。要表达"他在想"，用「……」逐点 + 抬头。
- 低阈值不渲染（doc-02 #12）沿用：不是所有状态都值得常驻像素。
- 完备性检查：任何编排决定要么落在三通道（台词/走位/idle）之一上，要么就该待在幕后——不存在"必须表现但无法表现"的编排。

## 7. 原型验证清单（下一步）

1. **say 拆两拍**：cue（笔悬停 + 「……」逐点）→ say（气泡流式 + 节奏参数）——对照现在的"瞬间 pop"。
2. **老周的醒来**：第一次点击精灵的注意态切换（擦杯子 → 抬头）。
3. **走位**：住店剧情升级——老周从柜台后走出来、走到你面前，钥匙便签在他身边落地。**你永远看不见"编排"，但你看见老周朝你走来——这就是编排被表达了**（money shot）。
4. **idle 生活**：擦杯子循环动画（无剧情时的常态）。
5. **节奏对比**：加一个快节奏角色（集市小贩）对照老周——同一句话节奏天差地别，节奏即性格。

## 8. 待定

2. 「……」逐点的速度也是节奏参数吗？（是——cue 阶段就在表性格。）
3. 角色会写字吗？（doc-02 §6：角色在画布上写字、用户可回话直达角色——角色写信用自己的手迹还是板书体？手迹=题材包/字体问题，先留给题材包。）
