## 3. 冻结形状：角色身份（A1）

**问题**：`character_delta`/`character_message`/`character_idle` 等角色来源帧只有 `source: 'character'`，无法区分 nanami 与 sumi。

**冻结决定**：

1. `EventSink` 签名改为 `(source, event, characterId?: string) => void`（`lifecycle.ts:9`）。
2. `handleEngineEvent` 从 `clientKey` 派生：`clientKey.startsWith('character:')` 时取 `slice('character:'.length)`，否则 `undefined`。
3. `EventBridge.emitEngine(source, event, characterId?)`（`event-bridge.ts:245`）把 `characterId` 透传给 `mapEngineEvent`。
4. `mapEngineEvent(source, event, toolArgs, characterId?)`：**凡本次 `push` 的帧，若 `characterId` 有值则附加 `characterId` 字段**。一次添加覆盖全部角色帧，不逐帧手写。
5. `index.ts:41` 的 sink 桥接改为 `(source, event, characterId) => eventBridge.emitEngine(source, event, characterId)`。
6. `frameSink` 路径（`turn_aborted`/`replay_entry`，`lifecycle.ts:168,257`）**本批不动**：它们已带 `source: 'writer'`，角色 `turn_aborted` 的 `characterId` 登记为后续（见该篇冲突节）。

**帧名不变**（`docs/tools/12 §6.2` 不动），载荷可带 `characterId`。A1 迁移前的历史帧可缺失，但 UX batch 的公开消费路径不得用“当前 active modal id”补身份。

**UX batch 回写（2026-09-13）：** `useWorld` 对 `character_*` 帧只转发到 `airp:character-frame`；App identity router 只接受 `characterId` 存在且等于 active character 的帧，再送入 `CharacterFrameQueue`。缺失或不匹配的帧必须丢弃并产生可见诊断/错误，不得进入 CharacterModal；Nook 不监听原始 WS。旧单角色 fallback 只允许在迁移 Adapter 内部明确标记，不能成为 production public path。

## 4. 冻结形状：世界事件消费与去重（A2）

1. **`world_event` case**（`useWorld.ts` switch 新增）：
   - 形状 `{ type:'world_event', event: {...10 字段...}, timestamp }`（`docs/tools/12 §6.3`，与 `EventBridge` `:280` 逐字一致；字段清单 = `packages/shared/src/schemas/events.ts:112-123`：`seq/id/projectId/type/actor/layer/subject/turn/detail/createdAt`。另 15 是**事件 `type` 的类数**，别混）。
   - `event.seq` 是唯一排序游标；`event.id` 是去重键。
2. **去重纪律**（`docs/tools/12 §6.4`）：`useWorld` 维护 `seenEventIds: Set<string>`，**上限 200、FIFO 淘汰**。`world_event` 与 HTTP 响应里的 `event` 都先过它。**纪律：谁消费、谁登记**——登记点与消费点必须同处，否则先到的副本会吞掉后到的真副本（详见 `02` §3.3.1）。
   - 本批**只消费 `world_event`**（HTTP 响应里的 `event` 字段的消费面在后续批次），故 `Set` 先只由 `world_event` 填充；结构先建好，避免后续改造。
3. **`file_changed` 行为不变**：仍是整层重取的触发器（现状），本批不做局部化。
4. **`world_event` 是否触发整层重取**：**是**（本批最小实现）。理由：语义正确优先于性能；`entity_*` 类事件必然伴随文件变化，重取是安全的。增量优化登记为后续。
5. **删两条死监听**：`item_moved`、`god_action` 的 `case` 与 `msg.type ===` 判断**全删**。
