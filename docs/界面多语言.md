# 界面多语言（首轮）

通用 UI 保留 English / 简体中文 / 日本語 切换。载入声明 `world.json.locale: "ja"` 的新世界时默认切日语，之后仍可手动切换界面。偏好写入本机 `localStorage` 的 `airp-ui-locale`；选择语言同时更新页面 `lang`。世界切换的默认值不翻译或覆写世界文件。

首轮覆盖主界面导航、背包、世界选择器、行动输入提示、音频/特效开关、通用实体行动和互动字段标题。词典集中于 `apps/web/src/lib/messages.json`，缺失翻译回退英文。仅切换文案，不重挂载画布或重取世界。

世界名、Markdown 正文、作者写的 choice/action、人物介绍和 Agent 回复由世界内容决定，不用 UI 词典批量替换。五世界正在独立重写日语内容，首个为 `first-snow-jp`，具体范围见《世界日语化迁移》。角色 `name` 是可选日文显示名，`id` 继续作为协议标识。界面语言本身不决定 Agent 回复语言；日本语世界通过自己的语言文档和人物 preset 约束生成。

世界选择器发现 `first-snow-jp` 后隐藏旧 `firstsnow` 模板入口，但不删除文件或过滤玩家已有存档。角色遮罩目前仍是旧回复显示实现；日语模式不播放英文随机台词，而明确显示回复接线未完成的状态。骰子仪式和上帝工具等通用 UI 尚有英文，不能把世界文本迁移等同于全应用本地化完成。
