# 界面多语言（首轮）

默认英文，Header 提供 English / 简体中文 / 日本語 切换。偏好写入本机 `localStorage` 的 `airp-ui-locale`，不改世界文件、Agent 提示词或协议字段。选择语言同时更新页面 `lang`。

首轮覆盖主界面导航、背包、世界选择器、行动输入提示、音频/特效开关、通用实体行动和互动字段标题。词典集中于 `apps/web/src/lib/messages.json`，缺失翻译回退英文。仅切换文案，不重挂载画布或重取世界。

世界名、Markdown 正文、作者写的 choice/action、人物介绍和 Agent 回复仍是原文；骰子仪式、上帝工具及角色对话细节仍有英文，后续逐项迁移。界面语言暂不决定 Agent 回复语言，避免把显示偏好默认为生成协议。
