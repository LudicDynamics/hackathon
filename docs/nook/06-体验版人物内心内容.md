## 2. 每人七份作者输入，其中六张为公开卡

`characters/<id>/` 直接子级由本批写入七份作者内容。其中 `identity.md` 与 `README.md`、
`personality.md`、`memory.md` 同属**角色根配置**：角色自己与 Writer 读取它，但 public nook
projection 必须过滤这四份根配置，玩家可见的公开卡只有下列六张
（裁决见 [本轮共同上下文](../../2026-09-14-agent-photo-content-design/00-共同上下文.md) §5.3 第 9 条；
实现见 `packages/shared/src/rules/characters.ts` 的 `characterRootConfigOf` / `nookCardPaths`）。

| 文件 | 内容 | 公开卡 |
|---|---|---|
| `identity.md` | 我是谁、职业与自我认同；不只是角色标签 | 否（根配置） |
| `relationships.md` | 与玩家及相关人的关系；区分已知关系和未获知的私下交谈 | 是 |
| `diary.md` | 开场前的一则第一人称日记；`component: diary` | 是 |
| `unspoken.md` | 尚未说出的心事，不等于已告诉玩家 | 是 |
| `likes-and-fears.md` | 喜欢什么、害怕什么，关联具体生活与选择 | 是 |
| `near-term.md` | 当前想做的一两件事；愿望不等于已执行 | 是 |
| `long-term.md` | 长期想成为怎样的人，不预写必达结局 | 是 |

全部放在`characters/<id>/`直接子级，英文稳定路径、日语标题和正文、`portable: false`。沿用已有note与diary渲染，不新增组件。关系用可读文字和真实角色路径；不是尚未实现的自动关系线。README仍是人物说明，原personality与memory保留。

## 3. 创作与事实边界

本批新增的是依照已确认角色设定写出的开场生活细节，不把新增喜好当作旧文档已有事实。每人有自己的语气与动机，不用同一套“喜欢朋友、害怕失败”的通用占位。

- Ryo用七岁孩子的语言；只知道明天取青蛙，不知道事故或2024。旧素材版的“店主女儿”不覆盖已确认体验版的送修女孩身份。
- Watson关心患者与Holmes；Edith、Tom、Blackburn、Wayne各写自身生活与关系，不在可读日记、心事里泄露必须调查的凶手答案。
- 七海和澄都能表达希望，但不预定玩家赴约、恋爱、另一人缺席，也不读取对方私聊。
- 老莫能承认自己消灯，不编造他看见追踪船；其他证人的记录同样有知识边界。
- 魔法学院写想尝试的魔法，不提前支付代价或宣称玩家已施法。

上述六张公开卡是玩家获准查看的小天地内容；`identity.md` 属根配置，不进 public nook projection。“心事”是叙事上的未说出口，不是技术上的保密文件。没有加锁机制，也不往这里放必须靠调查才能揭露的幕后答案。

## 4. 内容源与角色读取

唯一创作源为`tools/experiences/character-nooks.mjs`，经`tools/experiences/index.mjs`加入各体验包的files。`install-experiences.mjs`沿用已有profile file slot，在`README.md / personality.md / memory.md`后追加上述七个文件。只读该角色的资料，不加载其他角色心事或世界剧情skill。

不改平台preset骨架、工具白名单或instruction常量。模板的profile补七个path，保留音色、素材和其他已存在配置。沿用doc-11初始化协议的file slot契约，具体资料清单由本篇维护。

2026-09-14：福尔摩斯新增四人的私有表演边界由世界内容源的可选`instructions`提供；编译器写入角色preset的`role-context` block，不复制到README、personality或六张公开卡。它约束本角色知道的时间、原稿流转与应答方式，不让每个NPC读取全世界真相。小天地并不是保密通道。

`memory.md`仍保留“本局尚无新约定”的空局记忆。日记是已写开场设定，不冒充本局RP；游玩后角色可以沿真实对话更新自身资料，不清空、不凭空补玩家行动。

自动检查13人×7份作者内容的存在、文本、语言、直接层级、关系目标、preset读取路径、模板与编译源一致性、原记忆未被预填（现行覆盖见 `tools/world-editions.test.mjs` 与 `tools/check-world-editions.mjs`）。`identity.md` 被 public nook projection 过滤的契约由 `packages/shared/test/init-rules.test.mjs` 与 `apps/server/test/nook-routes.test.mjs` 验证；隔离副本经真实`GET /api/nook`验证公开卡可读，不拿正在游玩的存档作fixture。

从对应体验版新建存档即可带上这些内容。旧存档不自动覆盖，本批不执行迁移。
