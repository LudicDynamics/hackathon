# 动态素材接线（2026-09-13）

性能补充：初雪提供 960×540、20fps、无音轨的 H.264 `*-lite.mp4`；服务端存在轻量版本时优先返回（透明视频不转 H.264，避免丢 alpha）。开场从 906,969 字节降至 230,334 字节，街道从 5,330,690 降至 740,226 字节。视频不跟鼠标视差移动，视频场景的主要 chrome 不使用实时背景模糊。原始视频保留，不覆盖。90 帧实测基线平均 16.87ms、无 >34ms 帧，尚不能把用户所有迟滞归因于文件大小。

本次已完成：未写之门开场背景与信封、手机、门三张定稿道具图，取自兄弟仓库 `worldlines-assets/worlds/unwritten-door-demo`；原图复制进模板 assets，Markdown 用 bg/image 引用。没有为门外预生成背景，不覆盖游戏中已揭露的剧情。

素材真相源为 `worldlines-assets/looping/seedance/`。`node tools/sync-seedance.mjs`（先编译 shared，系统需 cwebp）同步模板及现有存档，仅更新媒体字段，不覆盖正文、角色 id 和历史。每个世界的 `assets/motion/seedance/manifest.json` 记录源路径、字节数及 SHA-256。WebM 原样复制；不携带任务文件和绿幕输入。

覆盖：wuwu 6 背景 + 2 人物、whitechapel 6 + 1、divergence 6 + 1、firstsnow 6 + 1、first-snow-jp 复用初雪 6 + 1、unwritten-door 1 + 0、magic-academy 0 + 1。共 25 个不同背景和 6 个不同人物成片，落入 7 个模板及 17 个现有存档。5 个 mistport 背景暂无对应模板；魔法学院尚未提供背景视频，保留静图。无匹配的新增场景不猜测替换。

人物配置及 Markdown 的 `avatarVideo` 指向透明 WebM，`avatar` 为透明 WebP 兜底；`GET /api/characters` 返回二者。静图取自批准的透明 PNG，缩至宽 600px、q82，不能用绿幕输入。只播放当前打开的角色特写，使用 contain 保留轮廓；不可见时暂停。小头像和场景缩略图继续使用静图，不启动额外解码器。特效关闭或播放失败回退静图。

背景为 1280×720、人物为 834×1112 VP9 alpha；均为 6 秒、24fps、无音轨循环。BGM 独立播放。新 Seedance 路径没有同名 lite 替代文件；旧 MP4 和静图仍保留。

README 增加可选 `bgVideo`（世界相对 mp4/webm 路径），原 `bg` 不变。`GET /api/layer` 的 `bg` 新增可选 `video` 字段。特效打开时优先静音循环视频，特效关闭时卸载视频并显示静态图；标签页隐藏时暂停，返回后恢复；视频加载失败回退 bg。沿用世界会话资源 URL 隔离，不把不同存档的同名视频混用。
