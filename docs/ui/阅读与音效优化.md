# 阅读与音效优化

- 背包实体点击打开完整 Markdown；只有明确点击「放回场景」才移动文件。失败保留阅读窗。
- 普通画布文档点击正文或聚焦后 Enter 打开详情；不把查看转换成剧情选择。按钮、链接、门、人物和特殊道具保留各自行为。
- 画布文档在原坐标展开到约 500px，保留倾角；不创建全屏弹窗、不压暗或模糊背景。使用自然中性纸纹和明朝／衬线字体，18px 字号、1.85 行高，长文内部滚动且不触发画布缩放。点击标题、折回按钮、纸外或 Escape 收起。背包阅读纸片停靠左下角。
- 世界选择是左侧宽 360px 的纸面目录，没有背景遮罩；保留「世界 → 存档」、返回当前故事、可恢复删除确认。后台仍可看见、交互，目录外点击收起。
- 存档确认后立即收起选择器，独立显示加载遮罩；失败重新打开选择器。加载尚未完成时不允许继续操作旧世界。
- 交互音复用 Canvas 的魔王魂素材及 0.14–0.28 音量；旧素材保留。相同音效至少间隔 500ms，并按音频时长阻止重叠。迟到超过 500ms 的加载结果丢弃，静音、后台、音频上下文未运行时不排队补播。
- 主题曲、层 BGM、环境音解析与三轨关系不变。素材署名见 `assets/audio/CREDITS.md`。
- 日文初雪模板与本地已有 4 个日文存档补 `audio.theme: canvas-firstsnow`。载入响应和 `/api/manifest` 统一返回已解析 URL，避免刚切世界时把裸主题名交给前端。英文初雪的合并支线恢复英文；已有英文存档只同步与旧模板逐字一致的文件，不覆盖玩家演化内容。
