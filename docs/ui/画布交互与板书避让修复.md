# 画布交互与板书避让修复

2026-09-14。针对偶发缩放 / 平移失效和新板书重叠，修复两条可由代码与测试确认的路径；不声称覆盖所有同类现象。

## 相机驱动恢复

主画布与小天地都挂载 `Canvas`，原来共用一个 `wakeDriver`。小天地卸载将它清空，主画布未重新挂载，后续相机命令没有驱动刷新 DOM。

`lib/camera-drivers.ts` 管理挂载顺序：只由顶层画布驱动插值，退出后唤醒前一个画布并恢复其视口尺寸。不会增加逐帧 React 渲染。

## 新板书按真实尺寸避让

原 footprint 默认 gate 遇到任意卡片 hover / reading 就暂停整层回传。现在仍用 `isInflated` 排除该卡的膨胀尺寸，但其他稳定卡可以回传；漏测卡保留重试，鼠标离开后补测。显式传入的整层 gate 仍受尊重。

实测写入成功且 `updated > 0` 时，主画布主动重取同一层，触发服务端 `reseatLayer`。不依赖 SQLite 文件监听恰好送达，不在前端新建排座算法，不写叙事事件。切层后的旧回执不触发重取。

这是对 footprint 早期「任一卡 hover 阻断整批」规则的细化；尺寸唯一来源、膨胀态不回写、服务端排座的边界不变。

## 生成中临时板书

用户进一步指出「小字浮动且不可拖，变大后恢复」。临时 `ChalkMark` 原来没有正式卡的 26px 字号覆盖，并每 24ms 重新解析不断变长的 Markdown。现在直接呈现已确认正文，使用同样字号与正文样式；不再做这段逐字重解析。正式卡仍在文件落盘后接管，未落盘的幻影仍不可作为实体拖动，但其事件必须穿透到画布。

临时排座原来漏算 chalk 幻影，只算 image。现计入两类；完整正文在布局阶段实测，若重叠只挪幻影到空位，不改真实卡坐标。100 个候选座位耗尽时排到占用边界下方，禁止回落中心叠放。正式落盘位置仍以服务端重取为准。
