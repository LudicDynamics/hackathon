## 3. 主观流程与目录

玩家先在零级放送室听到七海叫自己，读到纸上消不干净的约定；进入一级“今夜の約束”，再选择放送室、咖啡店或屋顶。场景里的物件让玩家有具体话题可问，而不是只点角色名字选恋爱结局。

```text
world/                         零级：放送終了まで九十秒
  README.md                    场景第一眼
  01-opening.md                首次可行动 Chalk
  request-sheet.md             可携带的节目用纸
  tonight/                     一级：今夜の約束
    radio-studio/              二级：七海与台本
    amber-cafe/                 二级：澄与四十分钟
    campus-rooftop/             二级：初雪旧约
    first-snow/                 二级：短结算的场景骨架
```

当前前端以 `map` 对应 `world/`，因此零级直接放根目录；不是绕过导入进入一级。每个目录仍用自己的 README 描述场景，没有在 manifest 里重复声明 layers。

## 4. 生成语言与显示接线

Writer 通过已有世界 skill 加载流程读取 `skills/first-snow-jp-continuity/SKILL.md`；其首段指向根 `language.md`。角色 preset 使用平台 `system-char`，其后读世界语言文件与各自的四份角色文档。没有复制平台提示词正文、绑定新模型或改生图管线。

两个角色 preset 里的语言槽相同：

```json
{
  "kind": "slot",
  "id": "world-language",
  "slot": "file",
  "options": {
    "path": "language.md",
    "baseDir": "cwd",
    "onMissing": "skip"
  }
}
```

`world.json.locale = "ja"` 让 UI 在世界载入时切日语；`characters[].name` 是可选显示名，不改变 `characters[].id` 或文件路径。未声明的旧模板保持原回退行为。
