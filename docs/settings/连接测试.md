# 连接测试

> 2026-09-15 · niko 需求：在设置里一键测所有 API——作家与角色的模型、TTS、语音输入、GPT Live。起因：DeepSeek 接口卡住时，角色对话只显示「character did not finish this turn」，看不出是钥匙没配、服务没通还是模型不回。

## 在哪里

顶栏「Voice & connections」→「Server connections」最下方「Connection test」→「Test connections」。只在 localhost 可用（与连接设置同一门禁）。

## 测什么

| 行 | 探针 | 判定 |
|---|---|---|
| DeepSeek API | `deepseek-chat` 5 token 对话 | 回了字就算通；25 秒没回报「no reply within 25s」 |
| OpenAI-compatible API | `gpt-4.1-mini` 5 token 对话（用 `OPENAI_BASE_URL`） | 同上 |
| Writer | 作家**当前选中的模型**，按 provider 路由到上面两个 API | DeepSeek / OpenAI 之外的 provider（如 vercel-ai-gateway）标为「未配置」并说明没有直连探针，但代理进程在跑 |
| Character · `<id>` | 每个已启动的角色，同上 | 同上；没开世界时跳过 |
| TTS · DashScope | 合成一个字「嗯。」 | 返回 WAV 即通 |
| TTS · local | 本机 TTS 合成「嗯。」（`AIRP_TTS_LOCAL_BASE_URL/v1/tts`） | 返回 WAV 即通；超时按本机 TTS 的超时设置（上限 25 秒） |
| Voice input (STT) | `GET /models/<AIRP_STT_MODEL>` | 200 即通，不上传音频 |
| GPT Live | 只看 key 是否存在 | 会话只在真正通话时创建，不预建 |

每行显示：正常 / 失败 / 未配置、耗时、详情（模型名与回复、或错误原因）。所有探针并行，总时长不超过最慢的一项（25 秒）。

## 费用与安全

- 每次运行花：两到几个模型各 5 token、两次一个字的 TTS。可忽略。
- 详情里不含 key；请求走服务端，浏览器只拿结果。
- 探针结果与「Configured」不同：后者只看 key 有没有填。
