# NoDesign 视觉设计风格分析：手账风的"纸的物理"

> 明月的观察：前端组件 UI/UX 渲染活泼亲和，手账风为主。
> 本文验证并拆解这套视觉体系：它不是一个元素一个元素的手账装饰，而是一套
> **自洽的"纸世界"材质系统**——有物理、有词汇表、有字体分工、有工程化的换肤机制。
> 只讲思路，不贴源码（引用个别 token 值/原文短句作为证据，属合理引用）。


> **2026-09-11 视觉基准更替（明月）**：经实测，原型 `画布世界v2-niko.html`（Hearth · WorldLines，在 `infini-canvas` 项目里）比 NoDesign 手账路线**更流畅**，**定为新的前端视觉基准——以后所有前端按 v2 风格设计**。差异分析与 v2 风格规格见文末 **§10**；§1~§9 的 NoDesign 分析降级为参考源。

> **2026-08-30 本地优先追加批注**：AIRP 架构从"纯云端"调整为"本地开源自部署"，对视觉设计没有直接影响。唯一变化：本地版的世界选择/世界管理界面（启动器）需要视觉设计，云端版不需要——但那是应用层 UI，不改变纸世界的视觉语言。

## ⚠️ AIRP 批注（2026-08-30 带着产品上下文回看）

**手账纸世界直接继承**——但视觉体系没有"两套语言"，而是**一套语言 + 材质皮肤**：

| 层 | 视觉语言 | 来源 |
|---|---|---|
| **所有层级（统一）** | 手账纸世界 + **材质皮肤**（material 词汇表） | Nodesign 纸的物理 + doc-04 §6 |

> **2026-09-08 修正（明月）**：本文批注"结构层 / 场景层两套视觉语言"的划分**思路错了**——两层深度根本不够。正确模型：**每一层都是一块平等的无限画布，切换层级 = 换画布**，"场景"只是画布 + 材质皮肤 + 物件，不存在第二套渲染管线。见 doc-05 §3.2。
> **2026-09-10 修正（明月）**：角色呈现再收窄——**画布上不做角色精灵动画、无 idle 演出**，角色在场 = **类光标 + 圆形头像**（轻量在场感）；**进入单聊遮罩时才出现左右分屏大半身立绘**（立绘只在遮罩里渲染，画布上不渲染）。"场景层的物件精灵、角色精灵"不再是视觉课题。

继承的具体点：
- **§3 字体分工 = 身份分工**——角色写的字=手写体、作家旁白=楷体、系统/等宽=机器，直接形成"谁写的"视觉身份。NPC 的话、角色的信、玩家的选择，靠字体一眼区分；
- **§1 四件套物料 + §2 纸的物理**：世界 UI（卡片/窗口/悬浮对话窗）直接用；
- **§6 材质词汇表**：世界模板的材质（便签/卷宗/小票/牛皮纸…）直接成为世界题材的视觉词汇——**材质 = 每层画布的皮肤**（奇幻世界的羊皮纸、科幻世界的终端墨版）;
- **§7 洞察 1 修正**：手账="未完成、可涂改"暗示 → AIRP 是"**可互动、可进入**"暗示——纸世界的"可以改"在 AIRP 里变成"可以碰"；
- **§7 洞察 2 强化**：纸世界与"画布即世界"隐喻互相成全——大地图是钉着城市卡片的墙，走进城市是一张展开的纸。

**需要自创的**（Nodesign 完全没有）：层级之间的视觉叙事（从大地图 zoom 进城市的"进入感"、穿越过场）、**角色遮罩的立绘呈现**（左右分屏大半身立绘 + 呼吸动画）、**叙事 frontmatter 的表格渲染**（choice 选项卡 / status 折叠表格的纸面风格）——这些是 AIRP 视觉的下一个设计课题。


## 1. 验证结论：一套完整的"纸世界"材质体系

手账风不是零散元素（贴纸、胶带、手写体）的堆砌，而是有一套**统一的物理**：全站没有纯白、没有纯黑、只有一个光向、字体有明确分工、连"选中文字"都是红笔划痕。这套体系有自己的名字——**"纸的物理"**（代码注释原话），核心物料四件套：**暖纸、墨字、铅笔灰、红笔**。

| 物料 | 值 | 用途 |
|---|---|---|
| 暖纸 | `#FFFEF6`（纸）/ `#F0EADB`（墙）/ `#FAF0C6`（法律纸）/ `#E2D3B4`（牛皮纸）/ `#FBF3CF`（便签） | 一切卡片、板面、底色的来源 |
| 墨字 | `#2B2117` / `#5F5142` | 正文与标题（**全站没有纯黑**，中性灰全部换暖墨） |
| 铅笔灰 | `#A39882` | 次要信息、灰字 |
| 红笔 | `#A8362B` | 唯一强调色：红圈、红笔光标、选中划痕、批注 |

代码注释里立的两条口径可以当设计规约读：
> 1) 白 → 纸。全站没有纯白，最亮的是 #FFFEF6。
> 2) 中性灰 → 暖墨。所有 rgba(0,0,0,x) 的描边换成 rgba(43,33,23,x)。

## 2. "纸的物理"：光向、影子、颗粒

### 2.1 一个光向

> 光向全站统一：右上打光 → 影子一律偏左下（-x, +y）。

全站只有一盏灯。所有影子（卡片、浮层、窗口、登录墙的纸）都遵守同一个光向——这是"纸上世界"可信度的根基：**任何两个物件放在一起，它们的影子方向一致，用户就默认它们在同一世界里**。

### 2.2 阴影三档 = 距离感

影子分 near / mid / far 三档：
- **near**：刚被动过、摆在最上面的那张（最"浮"）；
- **far**：贴得最平的（最"沉"）。

层次全靠影子表达。ChatDock 悬浮聊天卡遵循同一规则：固定=贴板（mid）、悬浮=浮得高（near）。连"钉住的纸才有钉子"（图钉只在固定态出现）这种细节都在讲物理故事。

### 2.3 颗粒噪声：让纯色不那么塑料

纸面铺一层压得很淡的 fractalNoise 颗粒（140px 一格）——纯色是塑料的，纸是有纹理的。这个颗粒是纸世界区别于"卡片 UI"的最后一层质感。

### 2.4 卡片 = 纸，工具 = 墨面

- **卡片是纸**：纸色 + 颗粒 + 直角 + 单光向影子；弹窗背后那层压暗是"暖的"（暖墨色 rgba(43,33,23,0.38)），不是中性黑；
- **浮在纸上的工具是"墨面"**（INK_SURFACE）：工具栏、地址栏这类"操作面"用深墨色，与纸面形成"纸上写字/纸上放工具"的层级；
- 有一条配色纪律被注释钉住："一条工具栏不能有两种物料"（SitePublishControl 发布控件必须用墨面配色，不能混纸面）——**一个表面只有一个身份**。

## 3. 字体即人格：楷体 = 人写的，等宽 = 机器写的

这是全站最有哲学味的视觉决策，theme.js 注释原文：

> 字体的分工是**有意义的**，不是没统一：楷体 = 人写的（正文、标题、按钮），等宽 = 机器写的（文件名、id、token 数、终端输出）。

**三套字体，三种身份：**

| 字体 | 身份 | 用在哪 |
|---|---|---|
| **霞鹜文楷**（LXGW WenKai ND / Screen） | 人写的字 | 全站正文、标题、按钮（门面字 52KB 子集秒显；长文走全量字库按需分片的屏幕优化版） |
| **龙藏体**（Long Cang） | 硬笔手写、圆珠笔手感 | 画布"写一段字"的默认笔迹。注释：楷体太工整像印出来的；2.9MB swap 加载，"先用楷体显影，字体到了再换笔迹" |
| **Caveat**（可变字重） | 好看的英文手写 | 手写栈英文那一笔（龙藏体的拉丁字形很糙，用户点名要一套好看的英文手写） |
| **等宽**（SF Mono / Cascadia / Menlo） | 机器写的东西 | 文件名、id、token 数、终端输出、时间码——**等宽只留给机器** |

这套分工直接服务于产品叙事：**画布上 Agent 写的是手写体（龙藏/楷体），用户看到的一切"人写的"都是手写笔迹；而机器内部的语言（文件名、token）用等宽，一眼区分"这是人写的还是机器生成的"**。连登录墙那张"终端墨版"和"用量小票"都用等宽——同一个世界里的同一条规矩。

## 4. 手绘而非印刷：SVG 手绘零件

PaperBits 是"纸上的手绘零件"（红圈、长尾夹、手绘下划线），注释直接说明动机：

> 都是 SVG 手绘而不是字体符号：印刷体的圆圈和下划线太齐整，跟这套「随手写的」语气冲突。**路径本身带抖动**，缩放到任何尺寸都还是手画的。

同样的思想延伸到关系线（board-bindings）：
- **手绘线**：沿贝塞尔采样 + 法线确定性抖动（以线 id 做种子——同一条线每次抖在同一处，抖动是笔迹不是噪声）；
- **丝线**：图钉 + 重力下垂（侦探板推理味）；
- **墨线**：安静归档。

材质轴（墨线/手绘/丝线）与语义轴（改自/批注/接着做…）正交——"纸世界"里连线条都有笔触和材质。**确定性伪随机**是贯穿手法：动画"活"但不"吵"，同一句话每次都歪得一样。

## 5. 细节是语气：连选中态都是红笔划痕

- **文字选中**：默认的亮蓝在整套暖纸里是唯一一块冷色，全局改成红笔划过的痕迹（半透明红）；
- **聊天输入框**：红笔光标 + 聚焦时"纸抬起来一档"（阴影变化）。注释解释了为什么：纸上没有边框，只靠一根 1px 的竖线判断有没有聚焦太吃力——**交互反馈也物化成纸的物理**（聚焦 = 纸被拿起）；
- **shimmer**（工具运行中）：一束光从左到右扫过文字，"工具在跑，不是卡住"；
- **画布上的字一律不可选**："画布是图形表面，不是文档"——防止拖拽变拉选区（真实事故），例外是输入框/可编辑区（"打字的地方把选中还回来"）。

## 6. 材质词汇表："能共用的是材质，不是坐标"

登录墙（AuthGate）有一份**材质词汇表**（wall-css.js），是全场景共用的那半 CSS，切口是用户当初定的那句话：

> **能共用的是材质，不是坐标。** 这里只有「一张纸长什么样」——板面、纸基座与三档景深、纸材、固定件、瑕疵、编号红圈、线索线、板上的字、登记卡。每张纸摆在哪、上面写什么，不在这儿——那是一套构图的事。

**纸材族**：便签 / 方格纸 / 终端墨版 / 牛皮卷宗 / 小票 / 黄笺 / 索引卡 / 描图纸
**固定件**：图钉 / 回形针 / 订书钉
**瑕疵**：折痕 / 褶皱 / 折角 / 装订孔

这套词汇表把"手账元素"正式化成一个可枚举的材质系统：加一面新墙 = 加一个场景文件复用词汇表，不用动材质定义。

登录墙还有一段节奏设计很值得抄（用户定的）：一轮 10 秒，"慢慢钉上去 5.5s → 站着 1.4s → 中速摘下来 3.1s"，每张纸之间错开 240ms——"**展开本身就是内容**"，不是静止十几秒 + 眨眼切换。注释还标明了唯一该动的旋钮（still），防止后人乱改破坏"一张张摆上去"的手感。

## 7. 为什么这套风格适合 AI 创作工具（设计洞察）

1. **手账 = "未完成、可涂改"的心理暗示**：印刷体/工程 UI 暗示"成品、不可动"；纸和手写体暗示"还可以改"。对"Agent 生成 + 用户圈改"的创作工作台，这个暗示与产品语义完全同构——**产物就该像手账一样可以被圈、被批、被撕下来重写**。
2. **纸世界与"画布即工作桌"的隐喻互相成全**：画布是桌面/墙，卡片是钉上去的纸，关系线是侦探板的线索线，Agent 是铅笔。产品结构（无限画布 + 物件）与视觉语言（纸世界）共用同一套空间隐喻，用户不需要学两套心智模型。
3. **亲和力来自"少一点机器味"**：全站没有纯白纯黑（数字感最强的两极）、选中是红笔划痕（而不是系统蓝）、错误也用人话。数字产品最冷的部分（文本框聚焦、选区、状态条）全部被翻译进纸世界的物理。
4. **一致性是工程化的，不是靠自觉**：所有值收进单一 token 源（theme.js），注释明言"只改这个文件的值，组件一行不动"（110 处 bgWhite、191 处 border、269 处 FONT_SANS 一次归位）；换肤 = 改 token；材质词汇表让"纸"可以跨页面复用。**手账风能全站统一，是因为它先被建模成了系统，然后才被渲染成风格。**

## 8. 可借鉴清单

| # | 手法 | 思路 | 成本/收益 |
|---|---|---|---|
| 1 | **一个光向 + 三档影子** | 全站只有一盏灯，影子分档表距离感 | 极低，立刻获得"同一世界"感 |

## 10. 新视觉基准：画布世界 v2（2026-09-11 定稿）

> 明月 2026-09-11 定稿：原型 `画布世界v2-niko.html`（在 `infini-canvas` 项目里；明月 index(2) 引擎 + 我们的世界数据/作家后端）实测比 NoDesign 路线**更流畅**，升为前端视觉基准。§1~§9 保留为"纸世界"参考源，v2 是其上的重新着色与重新塑形。

### 10.1 一句话

2026-09-12 素材版入口修订：本轮整页 UI 以 `worldlines-canvas/app/src` 为对照。默认直接进入 Fogwharf，Header 与左侧故事栏独立收起；展开使用暖羊皮纸，世界内物件使用低饱和紫色半透明材质。左下为玩家身份，右侧为常驻伙伴，底部圆形头像为遇见的人，物品通过独立袋口展开。全沉浸隐藏全部界面，仅保留可聚焦的恢复按钮。验收顺序与未完成项见 `UI验收清单.md`。

v2 把 NoDesign 的"**纸墙/侦探板**"换成了"**一张墨画布**"：全界面只保留两个身份——**奶油纸面与暖墨字**，所有物件共用同一种材质（无深色墨面工具栏、无钉子无贴纸），靠**全圆角、暖色漫射软影、低饱和三色、慢连续动画**获得流畅感。

| 维度 | v2 值 |

| 物理 | 物件软碰撞推挤（PAD 22px · .72 回弹）、拖拽大软影 `0 22px 50px` + z 提升 |
| 交互态（**取代红笔划痕/红笔光标）** | hover=墨底纸字反转（唯一强反馈）、拖拽=悬浮、aged-faint 风化（opacity .42 + grayscale 25%） |
| 角色在场 | 104px 径向渐变光环头像（琥珀→赭→靛→墨）+ 呼吸 + 状态点（在线绿→回音铁锈红）——落实 doc-04 批注"类光标+圆形头像" |

### 10.3 v2 vs NoDesign（§1~§8）差异表

### 10.4 为什么"更流畅"（测试结论的机理拆解）

1. **单材质**：全站一个身份，视线无"纸↔墨面"硬切换；
2. **圆角+软影**：无锐角硬边，扫描阻力小——最直接的"顺滑"来源；
3. **三色低饱和**：没有高饱和红抢眼，焦点让给内容；
4. **慢缓动曲线**（`.16,1,.3,1`）+ 连续动画（呼吸/洇墨/连线流动）——时间上连续，无突跳；
5. **软碰撞/拖拽悬浮**——空间上连续，物件像液体互推；
6. **元信息小字+大字距**：界面让位于正文，信息分层更静音；
7. **背景更深、物件微亮**：层次靠亮度差而非阴影，物件有"发光感"（halo 光环）。

### 10.5 代价与边界（诚实登记）

1. **文具道具感消失**：红笔/图钉/瑕疵那套"手账辨识度"没了，v2 更接近"现代暖色设计系统"，独特性靠颗粒/墨动画/三色支撑；
2. **材质皮肤需重新定义**：世界模板的 mat-parchment/mat-warm… 若保留，须在"圆角+软影+三色并存"下重做皮肤变体，不能直接搬 NoDesign 直角皮肤；
3. **圆角与"纸是直边"叙事有语义偏移**：v2 已用"墨滴/液体"叙事自洽（圆角=墨迹），做新组件时文案与视觉要一致说"墨"，不说"纸"；
4. **色深适用边界**：story 渐变 `#49626a→#d7b47d`、背景 `#d9d0bf` 默认服务"沉/暮"题材；明亮题材（集市/白昼）需派生更亮的奶油刻度。

### 10.6 落地纪律

- 前端新组件一律从 v2 样式语汇出发生成（token 级引用 §10.2），不再默认实现 §1~§8 的 NoDesign 口径；
- §6 材质词汇表保留为**世界题材概念**，具体视觉实现按 §10.5-2 在新基准下重做；
- 角色呈现按"halo 头像（画布）+ 立绘（遮罩）"执行，与 doc-05/doc-06 一致；
- 文案语气同步"说墨不说纸"（§10.5-3），与 doc-03 人话原则不冲突。

### 10.7 多模态与感官系统规格（2026-09-11 评委导向升级，详见 doc-19）

2026-09-12 性能默认值：粒子与鼠标视差由 Header 的 `Motion` 开关统一控制，默认关闭；静态背景与画布拖拽/缩放继续运行。开启才挂载粒子动画并更新视差，避免空闲页面持续绘制。

> 为对齐 PlayCo（视听动大满贯）与 AnotherBall（舞台大秀与沉迷感）的评审标准，视觉系统升级为**视、听、动一体化的“2.5D 微缩立体纸雕剧场”**：

1. **全景声场体系（Audio Engine）**：
   - **环境白噪音**：场景层级挂载环境循环音（`ambient_rain.mp3`、`ambient_fireplace.mp3`），切层时 1.5s 交叉淡入淡出；
   - **实体拟音（Foley）**：拖拽卡片沙沙声、背包收纳啪嗒声、实木骰子翻滚落木声、钥匙开锁咔哒声、落墨笔尖轻响；
   - **动态配乐**：预制悬疑/日常/博弈短 BGM，随剧情情绪标签平滑切换音轨增益。
2. **2.5D 纸雕立体微缩空间（Shadow Box & Parallax）**：
   - 画布容器启用 `perspective: 1200px`，鼠标在视口移动时产生微视差（前景 1.35x，中景 1.0x，远景 0.25x）；
   - 前景常驻轻量 Canvas 浮尘微光微粒，打破平面 DOM 的塑料感；
   - 关键剧情时刻触发**舞台追光（Cinematic Spotlight）**：背景压暗至 15%，聚光灯照射关键证物或角色。
3. **动态微循环背景（Film Assets）**：
   - 场景 README frontmatter 声明的 `bg` 支持 3~5 秒无缝 AI 循环短视频（WebM/MP4：跳动火苗、窗外雨痕），以 `<video autoplay loop muted>` 铺底。
4. **角色全套 6 情绪差分立绘（Prompt 标签驱动）**：
   - 遮罩特写中支持 6 情绪差分图：`normal` / `smile` / `shock` / `sad` / `angry` / `thinking`；
   - 驱动机制：角色 Agent 在输出台词句首附带 `[emo: <tag>]` 标签，前端即时捕获平滑切图并滤除标签；配合缓慢呼吸动效（scale 1.02）。
5. **轻量世界时间感知（无复杂 HUD）**：
   - 不做夸张的理智罗盘或金币袋 UI；状态随 frontmatter 走，界面仅以一枚极简的 DM Mono 字体**世界时间与天数印章**（如“第 3 天 · 暴雨夜 23:15”）展示进度。

### 10.8 素材场景投影态与整页布局基准（2026-09-12 定稿）

`../worldlines-canvas/app/src/`（本地构建运行于 `http://127.0.0.1:8792/`）不再只作为机制样例，而是 AIRP 的**前端整壳替换源与素材场景整页 UI/UX 基准**。页面结构、尺度、CSS、响应式和演出时序按当前源代码 1:1 迁入；AIRP 仅替换它的数据/命令适配层，并做下述沉浸态修正。v2 token 仍是视觉语法；当层级声明 `bg` 时，界面进入 scene-projection：背景素材成为舞台，空间实体与 chrome 转为暗色半透明投影，Chalk 转为暖亮墨色。

整页交互遵循“**读—看—写**”三段，但不把三段永久同时钉在屏幕上。世界舞台是唯一常驻底座，阅读和创作是可完全退出的“世界之外”覆盖层：

1. **读**：需要时从左侧滑入白色书面叙事页，承载章节、时间、正文、引语、choice、玩家身份与当前目标；关闭后完全隐去，不给画布预留白边；
2. **看**：中部全出血世界舞台，场景图、雾层、地点铭牌、空间实体、无壳 Chalk 和角色立绘共同构成可探索空间；
3. **写**：底部中央按需唤起作家行动台，自由输入与 choice 汇入同一 writer 通道，明确呈现 idle / writing / skip / progress；纯沉浸时行动台也能完全隐去。

play 模式不设常驻顶栏。世界选择、设置、履历与上帝之手从边缘唤起区或命令面板进入；白色框架只在 reading / authoring 时出现，用来明确“玩家暂时站在世界之外”。Tab 临时切换 chrome，Enter 唤起行动台，Esc 逐层退回零 chrome 的 immersive 纯舞台；显隐不得卸载 Canvas、改变坐标原点或重置相机。

以下细节整体采用：Chalk 去卡片化、约 26px 的窄行宽手写排版与轻微旋转；永久/临时板书的落定与擦除；anchor 虚线回指；背景遮罩、雾层与慢速 Ken Burns；左下角玩家档案、角色圆牌/道具方牌卡组；hover 简介、面包屑、工具、缩放、声音、履历和常驻同伴全部收向舞台边缘，并可随 chrome 一起彻底退出。hover 只预览，不能自动打开直聊。具体替换边界、AIRP gateway 与验收见 `前端改造计划.md` §2.1–2.3。

原型中的中文产品文案、demo `engine.js`、`localStorage` 真相源、`/api/state`、`/api/command` 与固定 1080×640 数据坐标不照搬。产品可见文案迁入时一律翻译为英文；数据继续以 AIRP 的文件/SQLite、HTTP 与 WS 为准。视觉上的紫粉色、布局和交互时序以 8792 为准，不在移植过程中顺手重设计；世界素材不整体打进 web bundle，而应随世界目录由 `/api/asset` 懒加载。

---

> NoDesign 的手账风不是"加贴纸"，而是**把整个 UI 建造成一个有物理的纸世界**。而 2026-09-11 的多模态升级进一步将这张墨画布演化为一个**2.5D 视差纸雕剧场**：全景声音造境、AI 动态画卷铺底、大号物理骰子定乾坤、全套差分立绘赋予角色灵魂，让 AI 互动游戏既好玩（Playable）、又有秀感（Show）与沉迷感（Obsession）。
