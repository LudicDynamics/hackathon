## ① 一句话定位

**初始化执行的所有"该不该动"与"动了算不算成"的判断，都收在三个零依赖纯函数文件里**：`rules/emptiness.ts`（判空与判成品）、`rules/init-fallback.ts`（W2 兜底文案）、`rules/characters.ts`（角色 id 形状与路径归属）。它们吃**调用方喂进来的文件清单**，不碰 store、不碰 fs、不碰 zod——因此可以在 `node --test` 里直接表驱动穷举边界，而且 `airp-init` 命令、`GET /api/nook`、`arrangeCards` 的 nook 分支、服务端路由**共用同一份口径**，不可能出现"两套正则/两套判空"。

一句话反例（本批要消灭的状态）：契约 §1 逐字记录，本批前 `isLayerEmpty`/`isNookEmpty`/W2 兜底常量**不存在**，`isValidCharacterId` 也**不存在**；`dirOf` 是 `layers.ts` 的私有函数。本批把这三件补上，并把 `dirOf` 导出。

### 2.2 精确签名（以已落地代码为准，`file:line` 见 §⑧）

```ts
// packages/shared/src/rules/emptiness.ts
/** Paths in `files` that are direct children of `dir`. Private helper. */
function directChildren(files: readonly string[], dir: string): string[];

export function isLayerEmpty(files: readonly string[], dir: string): boolean;
export function isNookEmpty(files: readonly string[], dir: string): boolean;
export function hasInitProduct(
  files: readonly string[],
  dir: string,
  kind: 'scene' | 'nook'
): boolean;

// packages/shared/src/rules/init-fallback.ts
export interface W2SceneFiles {
  'README.md': string;
  'opening.md': string;
}
export function w2SceneTemplate(dirName: string): W2SceneFiles;

// packages/shared/src/rules/characters.ts
export function isValidCharacterId(id: string): boolean;
export function nookIdOf(id: string): string | null;
export function characterIdOfPath(path: string): string | null;

// packages/shared/src/store/layers.ts
export function dirOf(p: string): string;   // 本批从私有改为导出
```

**`files` 参数的语义（唯一口径，契约 §3.1 末段）**：`files` = `store.listFiles(dir)` 的返回值。三条既定语义（`packages/shared/src/store/local-store.ts:210-233`，实测）：

1. **跳过 dotfile 与 `node_modules`**：`entry.name.startsWith('.') || entry.name === 'node_modules'`（`:218`）。
2. **返回相 worldRoot 相对（POSIX 分隔符）路径**，即使传了 `prefix`（`:232` 的 `path.relative(this.worldRoot, abs).split(path.sep).join('/')`；`chalk.test.mjs:361` 实测 `listFiles('world/room') === ['world/room/README.md']`）。
3. **不返回目录本身**，只 push 文件（`:222-224`），且**递归**（`:220-221` 对子目录继续 walk）。

因此「`dir` 的直接子级」的精确口径 = `files` 里去掉 `dir + '/'` 前缀后**不含 `/`** 的项（`emptiness.ts:15-25` 的实现）。这一点是整个文件的地基：`isLayerEmpty`/`isNookEmpty`/`hasInitProduct` 全部建立在它之上。

## ③ 行为契约逐步（每步写"漏了会怎样"）

### 3.1 `directChildren(files, dir)`（私有）

1. `prefix = dir === '' ? '' : dir + '/'`（`emptiness.ts:16`）。`dir === ''` 代表世界根本身。漏了 → 对 `dir=''` 会拼出 `'/'`，所有路径都不匹配，世界根永远"空"。
2. 逐条 `f`：不 `startsWith(prefix)` → 跳过（`:19`）。漏了 → 兄弟层/子目录的文件会污染本层判定。
3. `rest = f.slice(prefix.length)`；`rest === ''`（不可能是文件，兜底）或 `rest.includes('/')` → 跳过（`:21`）。漏了 → 深层子目录被算作直接子级（`world/a/sub/README.md` 会被当成 `world/a` 的 README）。
4. 其余 push 进 `out`，返回**名字**（不含 dir 前缀，如 `README.md`）。漏了 → 调用方拿到的是全路径，`includes('README.md')` 这类比较会错。

### 3.2 `isLayerEmpty(files, dir)`（doc-11 §3.1）

1. `!directChildren(files, dir).includes('README.md')`（`emptiness.ts:33-35`）。
2. **判据只有"直接子级有没有 `README.md`"**，大小写**敏感**、逐字匹配。漏了 → `Readme.md`/`readme.md` 会被误判为"已初始化"，一个从未写过的层永远不再初始化。
3. **只看直接子级**。漏了 → 子目录里的 README 把父层"填满"，父层变永远 stub。
4. `dir` 是**相 worldRoot 相对目录**，如 `world/baker-street/crime-scene`（`emptiness.ts:31`）。

### 3.3 `isNookEmpty(files, dir)`（doc-11 §4.1）

1. `directChildren(files, dir).every((name) => name.endsWith('.json'))`（`emptiness.ts:44-46`）。
2. **空 ⟺ 直接子级全是 `*.json`**：`preset.json` 是配置不是内容，任意其它 `.json` 同样不算内容。漏了 → 一个有 `preset.json` 的角色目录永远不是"空"，小天地初始化永不触发。
3. **只看直接子级**（契约 §3.1 冻结）：`characters/<id>/sub/letter.md` 不算填满父目录。理由：doc-11 §4.3 的产出（README.md + identity.md + 内容文件）本就落在直接子级，直接子级判定与产出规范自洽。
4. 空目录（`[]` 或只有子目录）→ `every` 对空数组返回 `true` → 空。漏了 → 无 `preset.json` 的裸目录永远不初始化。

### 3.4 `hasInitProduct(files, dir, kind)`（契约 §3.2）

1. `children = directChildren(files, dir)`（`emptiness.ts:64`）。
2. `kind === 'scene'` → `children.includes('README.md')`（`:65-66`）。理由：doc-11 §3.3 要求 README 覆盖 stub 占位；README 没写成，层仍是 stub。
3. `kind === 'nook'` → `children.some((name) => !name.endsWith('.json'))`（`:67`）。任一非 `.json` 文件（README.md / identity.md / 内容文件）即合格。
4. **不合格视同 `failed`**（契约 §3.2 末段），命令走 W2（§2.3 第 6 步）。漏了 → 模型"completed 但什么都没写"会落一条 `layer_initialized` 谎报，层仍是 stub，下次进入再触发，形成死循环。
5. 与 `isLayerEmpty` 的关系：对 `kind:'scene'` 两者是**互反**（`hasInitProduct` 即 `!isLayerEmpty`）；对 `kind:'nook'` **不等价**——`isNookEmpty` 排除所有 `.json`，`hasInitProduct` 只要求存在非 `.json`，二者是同一判据的两面。

### 3.5 `w2SceneTemplate(dirName)`（doc-11 §5）

1. 返回**两个文件的完整内容**，键即文件名（`init-fallback.ts:29-35`）。
2. `'README.md'` = 占位 readme：frontmatter `type: readme` / `name: <dirName>` / **`material: stub`**，正文 `# <dirName>` + `(This place has not taken shape yet.)`（`:31-32`）。
3. `'opening.md'` = 空 chalk：frontmatter `type: chalk`，正文 `(You stand here. Nothing is clear yet.)`（`:33`）。
4. **文件名冻结**为 `README.md` 与 `opening.md`（契约 §3.3）。`opening.md` 与 `03` 篇正文一致；**不得**用 `evening.md`（那是 holmes 世界的手写内容）。漏了 → 写到 `evening.md` 会覆盖模板世界既有内容。
5. **`material: stub` 是合法的**（`MATERIAL_SKINS` 含 `stub`，`schemas/forms.ts:193-198`），是"这里还没长出来"的皮肤。与"成功产出的 README 用 brief 给的默认材质"（doc-11 §3.3）**不冲突**：两条分属"成功产出"与"W2 兜底"两个不同路径（契约 §3.3 末条）。
6. `isLayerEmpty` 与 W2 自洽：W2 落下 `README.md` 之后该层不再是 stub，不会二次触发。

### 3.6 `isValidCharacterId(id)` / `nookIdOf(id)` / `characterIdOfPath(path)`（nook 00 §5.2）

1. `CHARACTER_ID_RE = /^[a-z0-9][a-z0-9-]*$/`（`characters.ts:18`）；`isValidCharacterId` 即 `.test(id)`（`:21-23`）。
2. `nookIdOf(id)` = 合法 → `` `characters/${id}` ``，否则 `null`（`:32-34`）。**这是唯一拼 nook 路径形状的地方**（`:29-30` 注释；nook 00 反模式 2）。
3. `characterIdOfPath(path)`（`:43-50`）：
   1. `path` 不以 `characters/` 开头 → `null`（`:45`）。
   2. 去掉前缀取 `rest`；取 `rest` 里**第一个 `/` 之前**的段作 `id`（`:47-48`）。因此 `characters/ryo` 与 `characters/ryo/letters/unsent.md` 都得 `'ryo'`（它只回答"归属哪个角色"，不回答"是不是直接子目录"）。
   3. `<id>` 必须通过 `isValidCharacterId`，否则 `null`（`:49`）。
4. **穿越天然被挡住**：id 段不含 `/`，且正则不接受 `.`。`characters/a/../..` → `'a'`（剩余段无关）；`characters/` → `rest=''` → 非法 → `null`；`characters`（无尾斜杠）→ `startsWith('characters/')` 假 → `null`。漏了正则这道闸、改用"路径 normalize"→ 会把 `characters/<id>/../..` 放过（nook 00 §3.2 明禁）。

## ⑤ 落账

**本文件不落任何事件。** 三个文件是纯函数/纯常量，没有 `ActionContext`、不 `appendEvent`。

落账发生在调用者：`hasInitProduct` 的返回值驱动 `airp-init` 命令分流到 `recordLayerInitialized` / `recordLayerInitFailed`（`packages/shared/src/actions/layer.ts:105-171`，契约 §2.3 第 6 步）。事件的 `type` 与 detail 形状**本批零新增**（契约 §6：`layer_initialized: { layer, name, by, files }` / `layer_init_failed: { layer, name, reason, fallback }`，`schemas/events.ts:96-106`）。`w2SceneTemplate` 的产物由命令写盘后，`files` 数组按实际落盘路径构造，交给 `recordLayerInitialized` / `recordLayerInitFailed`。

## ⑦ 错误边界

| 情形 | 行为 | 依据 |
|---|---|---|
| `dir` 带尾斜杠（`'world/x/'`） | **未定义**：`prefix` 会拼成 `'world/x//'`，全部不匹配 → 一律判"空"。调用方 MUST 传归一化目录（无前导 `./`、无尾 `/`） | `emptiness.ts:16`；契约 §3.1 只说"worldRoot 相对" |
| `dir` 相对世界根但 `files` 来自别的前缀 | 判定结果无意义（前缀不匹配） | `files` 语义见 §2.2 |
| `dir = ''` | 世界根本身：`directChildren` 收根下的直接文件（如 `world.json`） | `emptiness.ts:16` |
| 目录里只有 dotfile（`.gitkeep`） | `listFiles` 跳过 dotfile → 判"空" | `local-store.ts:218` |
| 目录里只有 `node_modules/` | 同上被跳过 → 判"空" | `local-store.ts:218` |
| 文件大小写不匹配（`Readme.md`） | 视为**没有** README → 判 stub；`.JSON` 亦不算 `.json` → 算内容 | 字节级 `includes`/`endsWith`（`emptiness.ts:34,45,67`） |
| `w2SceneTemplate('')` | 生成 `name:` 与 `# ` 为空的 README；不报错 | 无入参校验（纯字符串插值） |
| `dirName` 含 `/` | 原样插进 frontmatter/标题；不报错、不 sanitize | `init-fallback.ts:31-32` |
| `isValidCharacterId(null/undefined)` | 运行时 `.test` 收到非字符串会抛 `TypeError`（TS 签名排除）；调用方 MUST 先保证是 `string` | `characters.ts:22` |

## ⑪ 发现的冲突

### 冲突 1 — `w2SceneTemplate` 的返回形状：契约冻结的签名 ≠ 已落地代码

- 契约 §3.3（`docs/init/00` 第 137 行）冻结：
  ```ts
  export function w2SceneTemplate(dirName: string): { readme: string; chalk: string };
  ```
- 代码（`packages/shared/src/rules/init-fallback.ts:18-23,29-35`）返回：
  ```ts
  export interface W2SceneFiles { 'README.md': string; 'opening.md': string; }
  export function w2SceneTemplate(dirName: string): W2SceneFiles;
  ```
- 差异：契约给的是**语义键** `readme`/`chalk`，代码给的是**文件名键**。二者都满足"文件名冻结为 `README.md` + `opening.md`"的意图，但**签名不逐字一致**。
- 倾向：**代码形状更优**——文件名即键，调用方 `for (const [name, body] of Object.entries(tpl)) await store.writeFile(path.join(dir, name), body)` 一步落盘，不会出现"键叫 readme 但文件叫什么"的二义。建议由主 agent 把契约 §3.3 的签名改成 `W2SceneFiles`（或至少承认 `{readme,chalk}` 是等价替代）。

### 冲突 2 — W2 模板文案：doc-11 §5 是中文，契约 §3.3 冻结英文

### 冲突 3 — `layerIdOf`（`actions/layer.ts:23`）与 `layerOfDir`（`store/layers.ts:37`）是同一条映射的两份实现
