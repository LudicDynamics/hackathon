# docs/audio/05 内容声明与素材缺口

> 隶属 A1「音频接线」批次。上游契约：`docs/audio/00-共同上下文.md`（**冻结**，本文 MUST 遵守其 §2/§3/§4/§7/§9，MUST NOT 私改形状）。
> 本文只负责 **内容侧**：4 个模板逐层 README 的 `ambient`/`bgm` 声明、`world.json audio.theme`、素材缺口清单、可解析声明样例。
> 服务端路由与解析器归 `01`，引擎归 `02`，前端状态归 `03`，Foley/stinger 触发点归 `04`，测试与元文件回写归 `06`。

## 1 一句话定位

**本文回答"每一层该声明什么声音"——把 12 个派生层（4 模板）映射到 `assets/audio/` 里**真实存在**的键，把不存在的键如实登记为缺口，并给出逐字可被 `parseFrontmatter` 解析的声明样例。**

冻结口径（引自 `00-共同上下文.md`）：

- 解析律（§1）：`assets/` 开头 = 世界相对路径（走 `/api/asset`）；**裸名 = 平台池键（走 `/api/audio`）**。本文全部用裸名。
- `ambient` 裸名可选项（§2.3）只有 `rain` / `fireplace` / `cellar-drip` + `ambient/pool/` 11 条；`bgm` 裸名只有 `bgm/` 三情绪 + `themes/` 五主题曲。
- 缺省 = 继承（§3.3）：`该层 README > 世界 README（map 层）> null`。
- **解析为 null = 声明静音**（§7）；**素材加载失败 = 合成兜底**（§7）。二者不同，本文对"无适配素材"的层给的是**明确的 null 声明**，不是含糊省略。

## 2 签名 / 参数 / 类型

### 2.1 层 README 新增字段（契约 §3.1，冻结）

```yaml
ambient: <bare-key> | <assets/…> | 缺省     # 环境音床
bgm:     <bare-key> | <assets/…> | 缺省     # 情绪配乐
```

- **顶层字段**，与 `bg` / `bgStyle` 平级，**不嵌 `bgStyle`**（`00` §3.1 冻结点）。
- 类型：`string | undefined`。合法形态只有两种（裸名 / `assets/` 前缀）；第三种（含 `/` 但非 `assets/` 开头）是契约违规，由 `01` 的 `resolveAudioRef` **`console.warn`（fail-loud 落日志）+ resolve 为 `null`**——**无 `errors` 出参、响应形状不扩**（评审 B1：初稿写"写 `errors`"，与 01 §5.1 矛盾，已按 00 §3.1 勘误口径改）。

### 2.2 `world.json` 新增字段（契约 §3.2，冻结）

```jsonc
"audio": { "theme": "<bare-key>" }   // 可选；解析同 bgm 规则
```

- 顶层，与 `material` 平级。**只有世界主题曲在这里**；层音频 MUST NOT 写进 `world.json`（`00` §9.7）。
- **跨包落点**：`WorldManifestSchema` 是 `.passthrough()`（`packages/shared/src/schemas/world.ts:44`），运行时保留 `audio` 但**类型未声明**（`:25-44`），TS 会报错。**必须**在 `packages/shared/src/schemas/world.ts:25-44` 的 `WorldManifestSchema` 增一行：
  `audio: z.object({ theme: z.string().optional() }).optional(),`
  改后需 `pnpm build`（`packages/shared` 是构建包）。该字段是 05（写 world.json）与 01（读 manifest）**共同前置**，唯一定义处在 `schemas/world.ts`。

## 3 行为契约逐步（每步写"漏了会怎样"）

1. **内容作者在层 README frontmatter 写 `ambient`/`bgm` 裸名。**
   漏了 → 字段 undefined → 走继承链（§3.3）→ 可能继承到 map 层或 null；不报错，但声音不确定。
2. **服务端 `01` 的 `readLayerAudio(fm, …)` 读 `fm.ambient`/`fm.bgm`，按 `00` §2.3 逐序试探 `fs.existsSync`。**
   漏了 → `/api/layer` 的 `audio` 恒为 `{ambient:null,bgm:null}`，接多少素材都听不见。
3. **命中 → 返回 URL 形式；全落空 → 该字段 `null`。**
   漏了 → 前端拿裸名去 fetch，必然 404（前端收的是 URL，见 `00` §4.1）。
4. **前端 `03` 把 `audio.ambient/bgm` 交给 `setAmbient`/`setBGM`。**
   漏了 → 主轨不动。
5. **世界主题曲：`world.json.audio.theme`（裸名）→ 服务端在 `/api/manifest` **解析为 URL**（`01` §5.2 落地）→ `03` 把 URL 交给 `setTheme`。**
   漏了（模板没写 theme）→ 世界无主题曲，直接进层 BGM（`00` §3.2 允许）。
6. **`ambient`/`bgm` 解析为 null 时：该轨静音，合成器也停**（`00` §7）。
   漏了 → 会把"声明静音"误当"加载失败"而回落合成噪声，语义丢失。

## 5 落账 / WS 前端联动

**无。**

音频声明是**纯静态配置**：写进 README/`world.json` → 被 `readLayerAudio`/manifest 读取 → 前端 effect 应用。不产生事件、不进 `history.db`、不触发 WS 广播。内容作者改 README 后由既有 `fs.watch → file_changed` 机制自然刷新（见 `docs/tools/00-共同上下文.md` 进程图），无需本文新增通道。

## 6 错误边界

| 边界 | 行为 | 依据 |
|---|---|---|
| 声明了不存在的裸名（如 `ambient: orchard-night`） | 解析为 `null` → 静音该轨，**不报错** | `00` §2.3 末句 |
| 声明了非法的第三种形态（含 `/` 但非 `assets/` 开头） | `resolveAudioRef` **`console.warn` + resolve `null`**（fail-loud 落日志，无 `errors` 出参） | `00` §3.1 冻结点 |
| stub 层无 README | `readLayerAudio` 拿不到 fm → 该层继承 map（§3.3）或 null | `00` §3.3 |
| `world.json` 缺 `audio` | 世界无主题曲，直接进层 BGM | `00` §3.2 |
| `world.json.audio` 写入但 schema 未声明 | TS 编译报错（运行时 passthrough 保留） | `schemas/world.ts:44` |
| `theme` 素材 fetch/decode 失败 | **静音 theme 轨**（无合成可回退；不拿 drone 冒充世界主题曲） | `00` §7（theme 行） |
| YAML 语法坏 | `parseFrontmatter` 返回 `frontmatter:null` → 该层无音频声明 | `frontmatter.ts:211-215` |

## 7 代码落点（精确到文件与函数名）

**本模块不新增任何函数**（内容声明是数据，不是代码）。

1. **内容落点**（7 个层 README + 2 个 `world.json`）：见 §4 表。仅"音频承载层"（`world/**` 的层）加 `ambient`/`bgm`；非层 README（封面、角色卡、journal、player、skills）**不加**（加了也不被 `/api/layer` 读——`world.ts:259` 只读 `<layer>/README.md`）。

   - `readLayerAudio` / `resolveAudioRef` → `01`（`apps/server/src/routes/world.ts`）。
   - `setTheme` / `setAmbient` / `setBGM` / `preloadAudio` → `02`（`apps/web/src/lib/audio.ts`）。
   - `LayerState.audio` ← `/api/layer`（**不是 manifest**：实测 `deriveLayers` 只派生 `name`/`parent`，`store/layers.ts:52`）→ `03`。
