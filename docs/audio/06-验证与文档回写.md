async function harness({ readme, mapReadme, manifest } = {}) {

  await store.writeFile('world.json', JSON.stringify(manifest ?? { id: 'p', name: 'P', description: '', author: '', genre: 'test', createdAt: '', updatedAt: '' }));

## 3. 行为契约逐步（每步写"漏了会怎样"）

**V1. 先构建，再跑测试。**
`pnpm --filter @airp/shared build && pnpm --filter @airp/server build`，再 `node --test apps/server/test/audio-routes.test.mjs`。
测试导入 `../dist/routes/world.js`（同 `smoke-routes.mjs:19`）。**漏了会怎样**：跑旧 `dist`，新路由不存在 → 全部 `/api/audio` 断言 404，误判"路由没落地"（`AGENTS.md §6.5` 红线）。

**V2. `/api/audio` 是平台级、不依赖 active world。**
断言其**不应**因 `getActiveStore()` 为 null 而 400（平台池，契约 §2.1）。**漏了会怎样**：把平台路由写成世界级，未进世界时主题曲/BGM 全 404。

**V3. 解析律黑盒化。**
`resolveAudioRef` 不导出 → 用 `/api/layer` 响应反推（§9 A 组）。**漏了会怎样**：`import` 未导出符号 → 测试文件 `SyntaxError`，整套挂掉。

**V4. 降级区分可断言。**
"解析 null"（声明静音）在服务端表现为 `audio.* === null` 且 HTTP 200；"素材加载失败"（合成兜底）只在浏览器可断言。**漏了会怎样**：把"世界级 404 落入平台同名"当正确行为，两层语义漂移（契约 §7 关键区分）。

**V5. 回归护栏。**
`bg` 形状**不变**（消费者 `SceneBackdrop.tsx:5-12`）。**漏了会怎样**：改 `readLayerBg` 时顺手改 `bg` 形状，前端材质色崩且无测试拦住。

**V6. 修订文本同 commit。**
`doc-19:124` / `doc-04:236,238` / `前端改造计划:224` 的假契约与代码同 commit 改（`AGENTS.md §6.3`）。**漏了会怎样**：下一批实现者照 doc 复制"作家 mood 标签"，重踩已证伪的坑。

**V7. `theme` 失败即静音（无合成回退）。**
契约 §7 补行：世界主题曲**没有**平台兜底合成轨（不拿 calm drone 冒充）。**漏了会怎样**：theme 加载失败时误回退合成 BGM，世界气质被通用 drone 顶替（与 §7"声明静音"语义冲突）。

**V8. `setBGM` 收 URL（契约 §5 裁定）。**
引擎对外 `setBGM(ref: string|null)`，与 `setAmbient` 对称；`BGMood` 仅合成兜底内部用。**漏了会怎样**：前端按 mood 键调用，与 `/api/layer` 下发的 URL 对不上，BGM 轨永久空转。

**V9. 继承链在服务端闭合（契约 §3.3/§4.2，评审 B1）。**
非 `map` 层**仅对本层未声明的字段**做 map 层回退——判据是**键是否存在**（`k in ownFm`），**不是 `??`**：键存在但解析为 `null` = 显式静音，**不回退**；map 层 own 即终值。**漏了会怎样**：用 `??` 会把"显式 null（声明静音）"误当"未声明"而去继承 map 值（`§7` 语义被破坏），或子层只声明 `bgm` 时 `ambient` 变 null（世界环境音整体消失）。

## 6. 错误边界

1. **Web Audio 在 node 不可用**：`initAudio()` 返回 null（`audio.ts:61-77`，`window.AudioContext` 缺失走 `:67`）。故 engine 测试**只断言请求态**，不断言 `ctx`/解码/混音。`02` 已确认 setter 无 `ctx` 时**仍记录 ref**。
2. **jiti 是外置依赖**：`createJiti` 来自 `<repo>/vendor/pi-rp/node_modules/jiti/lib/jiti.mjs`（先例 `tools/probe-tools.mjs:25`，它位于**仓库根**故写作 `../vendor/...`）。**测试文件在 `apps/web/test/`，须写作 `'../../../vendor/pi-rp/node_modules/jiti/lib/jiti.mjs'`**（`apps/web/test/` → 根需回退三级；写 `'../vendor'` 会解析到不存在的 `apps/web/vendor`，静默跳过 E 组）。pi-rp 子模块未初始化时该 import 失败 → engine 测试**跳过而非失败**（try-import + `test(...,{skip:true})`）。
3. **符号链接逃逸测试的前提**：`AUDIO_ROOT` 不可 import，但**可经 `repoRoot` 参数注入的临时 repo 间接测**（§9 B5 改为在临时 repo 的 `assets/audio/` 下放一个指向 repo 外的符号链接，断言 403）。若 `01` 未做 `fs.realpath` 二次校验，则符号链接会被 Express `sendFile` 跟随而 200 → 失败是**期望中的失败**（§10 冲突 B）。
4. **违约值只 warn、不入响应**：`RouteResolver` 确认 `readLayerAudio` **无 `errors` 出参**，违约（含 `/` 但非 `assets/` 开头）只 `console.warn`（文案含 `must be a bare pool key`）。故断言为 `audio.* === null` + 捕获 stderr（§9 A6）。
5. **继承链失败不 500**：map README 缺失/不可读时，`/api/layer` 捕获后保持 own（不继承），HTTP 仍 200（契约 §4.2 骨架的 `catch`）。断言 I6。
6. **测试时机确定**：全部一次 HTTP 往返，无定时器/动画参与，无 flake 面。
