# 素材版 UI 验收与施工顺序

以 `worldlines-canvas/app/src` 与 `http://127.0.0.1:8792/` 为参考。先固定验收，再施工；自动断言不能替代截图的视觉判断。此轮只调整入口与 UI，不扩展剧情、Agent 或生成流程。

| 编号 | 操作与通过条件 | 改造前 |
| --- | --- | --- |
| UI-01 | 冷启动服务后打开 `/`，直接呈现第一个世界 Fogwharf 的完整背景和开场；不出现 Holmes 或世界选择拦截页 | 不通过：服务默认 Holmes |
| UI-02 | 首次打开和切换世界后，Header 与左侧故事栏均收起；玩家、人物与场景仍可辨认 | 不通过：默认 reading |
| UI-03 | 顶部与左侧有明确可点击、可键盘聚焦的展开入口；两栏独立开关；全沉浸可一次隐藏全部，再恢复 | 不通过：共用 attention，唤起区不可见 |
| UI-04 | 展开两栏，均使用暖羊皮纸与低饱和紫色；正文有书籍排版，Markdown 不裸露；不出现纯白大片面板 | 不通过：白栏、裸露标题标记 |
| UI-05 | 左下角为玩家圆形身份入口；点击后明确显示当前身份与所在地 | 部分：仅 YOU 占位 |
| UI-06 | 常驻伙伴在右侧；遇见的人在底部圆形头像栏；物品有独立容器，角色不伪装成道具卡 | 部分：人物物品混排，伙伴重复 |
| UI-07 | 右上角简洁显示场景、世界时间与可用状态；未知数据不编造日期、数值 | 不通过：信息散落 |
| UI-08 | 开场 Chalk、选项和场景物件不互相遮挡；初始镜头能读完开场并看到入口；卡片沿用 Canvas 材质和字号层次 | 不通过：板书过大、物件遮挡、底部裁切 |
| UI-09 | 1440×900、1280×720、390×844 截图：栏位不挤压画布；控制可触达；小屏允许内容画布缩放，但界面不能溢出窗口 | 待测 |
| UI-10 | 世界切换、静音、角色入口、物品拖放仍可用；`pnpm build` 与 `pnpm probe` 通过 | 待测 |

- 5 项逻辑测试通过（先写失败用例，再补实现），`pnpm build`、`pnpm probe` 通过。
