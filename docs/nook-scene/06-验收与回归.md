### 3.1b N2-A3 / N2-A4：三种「不是这个场景」必须可区分（§4.2 的存在理由）

## 7. 错误边界（验收要覆盖的失败面）

N2 的错误码形状冻结在 N2 00 §4.2（**「未加载世界」= 409 `no_active_world`**，由路由级中间件给，即 `/nook` handler 内的 `if (!store) return 400`（`routes/world.ts:675-676`）是**死代码**；N2 相对 N1 只**新增**一条错误面：`?scene=` 指向的不是目录 → 404 `not_found`）。**每条都要有断言**（否则「错误码」只是文档里的一句话）：
