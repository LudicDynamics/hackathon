## 背景与现状（已定案，不重谈）

- 本地开源自部署 + 云端托管服务（doc-05 §0/§1），**MVP 本地优先**；
- worldStore 接口一致，云端实现 = S3 + PostgreSQL（doc-05 §8.3）——本篇要设计的是云端实现细节；
- 扩展系统：manifest `extensions[]` 声明（doc-05 §8.4 已定案）、`optional: false` 开世界必须加载、扩展可注册组件（doc-07 赛后 #6）；
- 世界 = 一个目录 + world.json（doc-08 定案）→ zip = 分享/迁移/备份三合一（doc-05 §8.6）。
