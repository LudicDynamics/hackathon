## 1. 一句话定位

把同一条权威演出阶段同时投影到视觉与声音：装饰可以被用户偏好、页面可见性和素材就绪状态安全地降级，但事实反馈、TTS 与可恢复的舞台状态不能被“看起来动了”冒充，也不能被性能优化静默吞掉。

## 3. 术语与模块边界

### 3.1 Module / Interface

- **Module**：`PerformanceLayer` 是公开 `show_frame` 的唯一视觉演出 Module；`lib/audio.ts` 是音频执行 Module；`SceneBackdrop`、`ParticleLayer`、`MotionPortrait` 是媒体生命周期 Module；`useAudio` 是 React binding，不拥有音频时序真相。
- **Interface**：视觉输入是 `show_frame`（由 `performShowFrame` 接受并做 target/resource lane 管理）；环境声输入是 `/api/layer`/manifest 解出的 `audio` URL；动作 Foley 输入是既有 `playFoley(FoleyName)`；情绪输入是 `playStinger(Emotion)`；角色页语音输入是 TTS 返回 URL 后的 `playVoice(url)`。
- **Implementation**：具体 z-index、rAF、AudioContext、video element、CSS transition 属于实现，不在本文另发同义接口。Depth 只使用 `background`、`stage`、`entity`、`performance`、`chrome`、`dialogue`，不得以“音频层”创造第七个 Depth。
- **Adapter**：`App` 负责把 layer/world 的最终 audio 和 theme URL 接到 `useAudio`；`SceneBackdrop` 负责世界相对视觉资产；`MotionPortrait` 负责对话中的单个可播放立绘。Adapter 不得重新解析 README 或自己决定动作成功。
- **Leverage**：使用已有 `audioDebugState()`、`voiceDebugState()`、`activeShow()` 和浏览器 Performance/Media 面板验证，不引入第二套状态记录。
- **Locality**：偏好门禁集中在视觉编排/媒体生命周期边界；素材解析留在服务端；声道等级留在 `lib/audio.ts`；动作结果留在动作层。任何 Module 不能以局部点击推断全局阶段。
- **Seam**：声画接缝是“权威结果已经成立”到“可选视觉/声音投影开始”的唯一边界。`chalk_landed`/`image_landed` 只是座位过户，不是 Seam，不得触发成功音效。

### 3.2 两类投影

1. **事实投影**：结果文案、卡片/门卡状态、dialogue 当前页、可读的失败反馈。Effects off、Reduced motion、隐藏或装饰素材失败都不能让事实消失。
2. **装饰投影**：粒子、parallax、背景视频、beam、fireworks、camera flight、ink splash、stinger。装饰可跳过、暂停或降级，但降级必须可观测，不得伪装成成功演出。

## 4. 冻结的视觉演出阶段与声画 Beat

阶段名是本文的跨 Module 语义；不新增 WS 帧、不改 show schema。

| 阶段 | 进入条件 | 视觉消费 | 音频消费 | 漏接后果 |
|---|---|---|---|---|
| `prepare`（资源准备） | layer/world 已有权威状态，静态背景/页内容开始检查；媒体尚未确认 ready。 | 先显示纸面/静态 poster/事实内容；不启动循环视频、粒子或 camera flight。 | 在 layer/world 变化时 setTheme/setBGM/setAmbient；按 `preloadAudio` 预热。不可因 preload 未完成阻塞事实 UI。 | 把“已请求”误当“已就绪”会出现黑背景、首帧掉帧或错拍声；把未声明音轨当默认 rain 会违反 `docs/audio/00 §5.4`。 |
| `intent`（动作意图） | 玩家开始拖拽、打开菜单、点击可操作实体，但尚无权威结果。 | 可显示低风险的操作中状态；不显示 unlock、gate-open、成功 spotlight 等结果专属视觉。 | 允许纯触觉意图 Foley（如现有拖拽 `paper-slide`），不允许成功/失败 Foley；不触发 gate-open。 | 意图播放成功音会让失败动作看起来成功，破坏 `docs/ux/00 §4.4`。 |
| `result`（权威结果） | 动作层返回成功、失败、冲突或取消，并持久事实/事件先行。 | 成功/失败事实先落 UI；只有结果允许的 show_frame 进入 PerformanceLayer。失败必须保留可见文案和重试/返回路径。 | 结果 Foley：`crit-chime`/`fumble-break` 等只消费真实 verdict；`unlock` 只在 use-item 结果成功时消费；失败不得播放成功声。 | 漏掉结果先行会出现“动画成功、事实失败”；把 `tool_end` 或座位过户当成功会制造假绿。 |
| `perform`（演出） | `show_frame` 已通过唯一 dispatcher，target/resource lane 合法，媒体门禁通过。 | spotlight/lights_out/ink/evidence/camera/fireworks/roll 按 Depth 投影；Reduced motion/Effects off 会改用静态事实版本或跳过装饰。 | 仅消费与同一 frame 对应的 foley/stinger；不重复消费层 ambient/BGM。`lights_out` 可临时降低 ambient，但不能改 BGM 所有权。 | 音频从局部 click 触发会与 show 错相；多处消费会重复声、重复粒子。 |
| `sustain`（持续/阅读） | show timer 尚未结束，或对话当前页仍可见。 | 保持静态结果；视频/粒子只在 Effects on、非 reduced、页面可见且资源 ready 时持续。TTS 页内逐字显示与视觉仍可读。 | ambient/BGM/theme 循环继续；当前 dialogue page 就绪时 playVoice，下一页先 stopVoice 再播。TTS ready 页不播 stinger；无语音/失败页才保留情绪 stinger（`docs/tts/00 §6.5`）。 | 语音与 stinger 同时出声会遮蔽台词；隐藏页继续播放会浪费资源并产生离开页面的错觉。 |
| `settle`（收束） | timer 到期、权威状态接管 phantom 或 dialogue page 完成。 | cleanup/remove 临时 DOM、burst group、camera takeover；只留下真实 card/layer。 | 不因 cleanup 再播成功声；主轨按新的声明 crossfade；stopVoice 在关闭/翻页时打断。**`chalk_landed`/`image_landed` 在任何阶段都不触发成功 Foley/stinger/BGM 变化。** | 若实现把座位过户当成功，会重复奖励；忘记清理会导致幽灵遮罩、rAF 和音频节点泄漏。 |
| `abort`（取消/失败/隐藏） | 用户 cancel、层切换、world freeze、target 离层、资源失败或 document.hidden。 | 立即清理可取消装饰；隐藏时暂停视频、停止 draw；重见时只恢复允许的循环，不重放一次性动画。 | 隐藏或取消时不补播已经错过节拍的 foley/stinger/TTS；主轨可由引擎/页面策略暂停或继续，但不得补放瞬时声。失败素材按 audio 契约 fallback 或静音并可诊断。 | 重新可见时重放旧 stinger/TTS 会让玩家听到过期句子；只清 DOM 不清 timer/rAF 会后台耗电。 |

### 4.1 四条主轨与演出阶段

- **theme**：`setTheme()` 在进入世界时声明，跨层持续，低于其它主轨；只由 manifest 的最终 URL 消费，不能由 show 或 `[emo:]` 推断。
- **bgm**：`setBGM()` 在进入层时消费 `/api/layer.audio.bgm`，与 ambient 独立 1.5s crossfade；不是 writer mood 的隐式推断。`docs/audio/00 §12` 已判定“作家单轮 mood”无生产者。
- **ambient**：`setAmbient()` 在层事实切换时消费 `/api/layer.audio.ambient`；`null` 是声明静音，不回退合成。`lights_out` 的局部 cut 只能保存并恢复当时 ref，不能重读或改写层配置。
- **foley**：瞬时、一次性、结果或触觉语义；不表示 card 座位 reconcile 成功。当前 `playFoley` 具备 visible/context/mute 门禁，但 gate-open/page-turn 仍没有真实调用点。
- **stinger**：`playStinger(Emotion)` 与角色情绪页正交于三条主轨；有 voice URL 且页已发 `playVoice` 时禁止 stinger，无 voice 时才作为情绪提示。它不得修改 BGM 增益。
- **TTS**：角色当前页成为可见页才消费 `playVoice(url)`；页封口可以预取，但翻走的页只预热不播放。没有可用音频时文字仍是完整事实内容，无合成 fallback。

### 4.2 声画绑定原则

1. **同阶段、不同通道**：show_frame 只拥有视觉演出入口；音频消费由该阶段的唯一 Adapter 发起，不能让 `ParticleLayer` 自己播放声音。
2. **先事实、后演出**：show 或 Foley 不能早于权威结果；背景主轨可在 layer/world commit 后 crossfade，不等同于动作成功。
3. **一次性不可补播**：hidden、未解锁、已错过时间窗时，foley/stinger/TTS drop，不排队补播；这一点与 `audio.ts` 对一次性声音的现状约束一致。
4. **失败显式可见**：音频素材失败可以走冻结的合成 fallback（theme 除外），视觉素材失败回静态/纸面；必须保留 `audioDebugState`、错误日志或玩家可见反馈，不能只让 console.warn 成为唯一的产品反馈。
### 4.3 Timing trace（结果帧 → Foley/BGM）

以下是验收用的时序，不是新增 WS 帧或 audio schema。测试可使用 `T_result`、`T_show`、`T_audio`、`T_layer_audio` 作为 **NEW、test-only trace markers**；生产代码继续使用既有 `performShowFrame`、`playFoley`、`setBGM`、`setAmbient`。

| 时间点 | 权威事实/视觉 | 声音 | 必须断言 |
|---|---|---|---|
| `T0` intent | 用户开始拖拽/点击；不把意图当成功。 | 可有触觉 `paper-slide`；不得有 `unlock`、`crit-chime`、`gate-open`。 | 失败 fixture 仍不能听到成功声。 |
| `T_result` | 动作层结果先落事实；成功/失败/冲突/取消已知。 | 结果 Foley 在结果确认后消费；`chalk_landed`/`image_landed` 以及 phantom seat 过户在此处均不触发成功声。 | `T_audio >= T_result`；座位事件单独到达时成功 Foley 计数仍为 0。 |
| `T_show` | 合法 `show_frame` 经 `performShowFrame` 唯一入口；偏好门禁通过后才建立 performance surface。 | 与 frame 对应的装饰声效不得早于 `T_show`；被 Effects/reduced/hidden/readiness 跳过的 show 不得留下声效。 | `T_audio >= T_show`（纯结果 Foley 可在 `T_result` 紧随消费）；禁止 renderer 自己另发音频。 |
| `T_layer_audio` | layer/world 的新权威 audio URL 被 App 消费；若结果没有切层，不能仅因结果 frame 改 BGM。 | `setAmbient`/`setBGM` 各自开始 1.5s crossfade；theme 继续跨层，不因 BGM 变化重启。 | 同 URL 不重复重启；`T_layer_audio + 1.5s` 后旧轨增益为 0/新轨到目标增益。 |
| `T_media_ready` | 背景 video 仅在 ready 后进入 sustain；3–5s loop 只描述素材目标，不代替 readiness。 | 主轨可继续循环；foley/stinger/TTS 仍按当前页/结果节拍，不因 loop 边界重复触发。 | ready 前无 play；loop 边界无额外 Foley/stinger。 |
| sustain | 远景/中景/前景按 0.25×/1.0×/1.35× parallax 语义运行；Effects/reduced/hidden 时静态或暂停。 | ambient/BGM/theme 继续按声明，TTS 当前页独占 voice channel；TTS ready 时 stinger=0。 | trace 能区分相机/视差运动与音频触发，不把每帧 draw 当音频事件。 |

`docs/audio/00 §5.3` 的 1.5s 是引擎冻结值；`docs/doc-19 §1.2、§1.1` 的 3–5s loop 与 1.35/1/0.25 是产品/视觉目标。截图只能证明观感，必须同时采集 trace/Media 面板，才能防止“动画看起来有了但结果声提前或主轨被重复重启”的假绿。

## 5. Effects、Reduced motion、hidden、asset readiness 优先级

冻结顺序（高 → 低）沿用 `docs/ux/00 §4.7`：

1. **用户明确关闭 Effects**；
2. **`prefers-reduced-motion: reduce`**；
3. **页面不可见或资源未就绪**；
4. **默认演出偏好**。

这不是“后者覆盖前者”的布尔合并，而是每个 Module 依次求最保守可用投影。若多个条件同时存在，取能保留事实且刺激/资源成本最低的版本。

### 5.1 Effects off

- Effects 是 `apps/web/src/App.tsx:151-180` 的视觉开关，默认 off，写入 `localStorage`；它不是 `MuteButton` 的音频 mute。
- off 时当前实现把粒子/动态背景/portrait loop 等通过 props 或不挂载降级；仍显示真实 card、结果文案、dialogue 文本与静态背景。主轨是否暂停不由 Effects 隐式决定。
- off 时 PerformanceLayer 已收到 `effectsEnabled`（`apps/web/src/components/performance/PerformanceLayer.tsx:520-554`），但各 renderer 仍存在门禁差异；不能把 `show_frame` 当成“无结果”。
- `SceneBackdrop.tsx:41-64` 在 `effectsEnabled && !still` 才产生 video src，关闭时回到 poster/paper；`SceneBackdrop.tsx:78-102` 负责 ready/visibility play gate。

### 5.2 Reduced motion

- `useStill()` 是全局 motion Adapter；`apps/web/src/lib/motion.ts:34-58` 已订阅 live `MediaQueryList.change`，系统设置变化无需 remount 即生效。
- 关键结果的视觉反馈可留“静态亮起/边框/文字”等低动量版本，但不得借 `effectsEnabled` 或 reduced 绕过用户关闭；与 components appearance motion 冲突时取更保守者。
- 声音偏好不由 reduced 自动等同 mute。结果 Foley/TTS 可保留，因为它们不是视觉位移；纯装饰 sound 必须与被跳过的装饰视觉绑定，不能在视觉已被门禁后独自播放。

### 5.3 `document.hidden`

- hidden 是媒体生命周期而非业务 cancel：
  - video/portrait：pause，释放可选解码/合成资源；重新可见只恢复仍属于当前阶段且资源 ready 的循环；不重放旧 TTS/stinger/foley。
  - ParticleLayer：停止 rAF scheduling；`apps/web/src/components/canvas/ParticleLayer.tsx:349-375` 负责 hidden/reduced/effects 变化时 stop/wake。
  - `playFoley`/`playStinger`/`playVoice`：当前 `apps/web/src/lib/audio.ts:911-965,1010-1042` 均检查 hidden/visibility epoch，不开始或补播过期瞬时声。
  - ambient/BGM/theme：可以按平台策略保留或暂停主轨，但当前实现未冻结统一行为；必须保持 `audioDebugState` 声明 ref，不可在重见时凭空改变轨道或补播瞬时声。[推断：主轨没有 visibility handler。]
### 5.4 asset readiness

- readiness 是播放前门禁，不是加载请求本身。最小状态：`unrequested → loading → ready | failed`；失败必须带资产身份，避免旧请求完成后覆盖新 layer。
- 静态图：`SceneBackdrop` `img.onload/onError` 决定可用与 fallback；先有纸面再替换图片，不让首帧等待媒体。
- 动态背景：至少等 `loadedmetadata`/可播放证据后才 `play()`；`preload="metadata"` 只是元数据提示，不等于已可持续播放。失败回静态 poster/image，一次失败不得每次 visibilitychange 反复 fetch。
- TTS/foley/stinger：audio engine 负责 decode cache/fail cache；preload 只预热不承诺播放，未 ready 的当前页必须在结果/文字上可见，过期页 ready 后只留缓存不出声。
- `App.tsx:302-314` 的 `Image` probe 只证明 `bg.src` 图像可读，不能证明 `bg.video` 或 `SceneBackdrop` 的最终媒体 ready；需要把 readiness 作为媒体组件边界的事实，而不是继续复用 `backdropReady` 猜测。
### 5.5 PerformanceLayer 的统一门禁

`PerformanceLayer` 必须是偏好门禁的唯一视觉编排边界；不能让每个 `show*` renderer 自己读 `localStorage`、`matchMedia` 或 `document.hidden`。`performShowFrame` 在调用 renderer 前按以下顺序判定：

| 顺序 | 门禁 | PerformanceLayer 行为 | 漏接后果 |
|---|---|---|---|
| 1 | `effectsEnabled === false` | 跳过纯装饰 renderer；事实 show 使用静态 focus/result adapter；不创建 fireworks、camera flight、动态 beam/ink DOM。 | App 关了 Effects，PerformanceLayer 仍制造动画和 burst，开关不再可信。 |
| 2 | `still === true`（`prefers-reduced-motion`） | 同样跳过大位移/循环装饰；结果使用低动量静态版本。`useStill` 的 live change 必须在下一帧更新 `ShowCtx`。 | 系统设置运行中改为 reduce，但已有 show 继续飞行或粒子继续画。 |
| 3 | `document.hidden === true` | 不启动新的瞬时演出；暂停/清理当前 transient visual，停止 performance surface 的 rAF；重见后不补播过期 frame/foley/stinger/TTS。 | 后台标签页持续耗电，回来时重放过期高潮。 |
| 4 | required asset 未 `ready` 或已 `failed` | 不创建依赖该资产的 renderer；回落静态 paper/poster/result；保留 frame/result 可读性。 | 请求发出被误认成就绪，出现黑帧、错误层覆盖或“动画成功”假绿。 |
| 5 | 以上均允许 | 才创建对应 renderer，并登记 `activeShow`/cleanup；ambient surface 与 performance surface 各自拥有可停止的生命周期。 | 未统一入口会出现 renderer 之间的声画、rAF、清理口径漂移。 |

该表只决定视觉投影。`playFoley`、`playStinger`、`playVoice` 必须消费同一个阶段门禁结果，但不会让 `PerformanceLayer` 直接拥有音频 schema；主轨仍由 App/useAudio 按 `docs/audio/00` 的 layer/world 声明驱动。

## 7. 错误边界

1. **未知/畸形 show frame**：沿用 `performShowFrame` 返回 false，不抛出，不播放音效；未知 component 只做开发可见警告。不能用“渲染失败”代替动作失败。
2. **target 不在当前 layer**：renderer 返回 null，不能播放 target-specific success Foley；现有 `showSpotlight`/`showInkBurst`/`showEvidenceBurst` 已有这一边界。
3. **层切换/freeze/cancel**：`cancelShow` 清理所有 transient show；不把清理当成功，不重复 stinger/foley；读取新 layer 的主轨声明。
4. **decode/fetch 失败**：ambient/BGM 用冻结合成 fallback；theme 静音；foley 失败用既有合成低音量 fallback；stinger/TTS 无 fallback 则静音。`audioDebugState`/`voiceDebugState` 可检查 declared ref 与 loaded 集合。
5. **autoplay/context suspended**：主轨 ref 可记录，unlock 后按既有 ramp 恢复；一次性 foley/stinger/TTS 不排队补播。
6. **hidden race**：请求在 visible 时发出、decode 在 hidden 完成时，完成回调必须再次检查 visible/当前 phase/token；不可因旧 Promise 完成而播放过期页。
7. **asset race**：layer A 的 video/image/audio Promise 完成时，若当前已是 layer B，丢弃 A 的 ready；必须按 URL/token 匹配。否则会出现旧背景或旧声音覆盖当前世界。
8. **没有视觉内容**：ParticleLayer 无 ambient、无 burst、或 hidden 时，不保留 rAF 作为隐形心跳。性能探针必须能观测 schedule count 归零。
9. **辅助功能**：装饰 root 可以 `aria-hidden`；但 `show_caption` 若携带事实信息，不能只存在当前 `PerformanceLayer` 的 `aria-hidden` 根（`PerformanceLayer.tsx:528`），须由既有可见 Chrome/notice 状态承载。motion 关闭不能让用户失去结果语义。
10. **错误文案**：失败动作必须由 App/动作层显示玩家可见文案（如既有 `notify`）；console.warn 只用于诊断，不是产品反馈。

### 8.2 声音阶段断言

- layer commit：断言 `setAmbient`/`setBGM` 使用服务端 URL 或 null；不能从 `bg.tone` 生成 rain/fireplace。
- world commit：断言 `setTheme` 只改变 theme；跨层不重复重启同一 URL。
- action intent：拖拽可有 `paper-slide`；把同一动作标记为失败时不能有 `unlock`/`crit-chime`。

- hidden/autoplay：hidden 或 context suspended 时一次性声音不排队；重新可见/unlock 不补播旧节拍。
- gate/page：当前无 callsite 的 `gate-open`/`page-turn` fixture 必须确认 0 次调用；接线后才分别增加 enter-success/page-index-transition 断言。
