## 16. 追加核验：Main 的「双向相等」不变量——方向 1 成立，方向 2 的事实**不成立**

Main 采纳修正版不变量 `CommandOutcomeCode === §10.2 表码集`，并给出两个可 grep 的锚点。**我逐条实测：**

**集合差实测**：`union − §10.2` = **空集**；唯一非空的方向是 `§10.2 − union`（5 个：上面 4 个 + `already_done`）。
