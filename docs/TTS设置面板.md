# TTS 设置与克制降级（niko）

顶部 Voice settings 提供本浏览器语音开关、服务配置状态、当前模型和默认音色。密钥仍由后端环境变量管理，不在浏览器显示或保存。角色声明的音色优先；面板当前仅展示服务模型和默认音色，不修改服务器配置。

`GET /api/tts/config` 返回 `{ configured, model, defaultVoice }`，不返回 key 或 gateway URL，禁止缓存。configured 只表示密钥存在，不表示上游调用已验证。

角色语音预取前共享一次配置检查。未配置时不发送合成请求，当前页面会话仅提醒一次，不阻塞文字。网络或合成失败后冷却 60 秒，面板可手动重新检查；关闭语音只阻止后续合成请求，不中断已经发送的请求。重新启动服务器配置密钥后点击 Recheck configuration 恢复检查。
