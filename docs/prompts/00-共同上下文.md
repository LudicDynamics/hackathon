## 3. 提示词的分层（冻结）

### 3.1 三层，各有唯一落点

| 层 | 是什么 | 住哪 | 生命周期 | 谁写 |
|---|---|---|---|---|
| **常驻层（identity）** | agent 是谁、怎么工作、硬约束 | `extensions/instructions.ts` 的导出常量 → preset slot | 每轮都在（缓存的 system prompt） | 平台（写一次，全世界共享） |
| **细则层（craft）** | 怎么把某件事做好：组件叙事、用工具演、节奏、（世界级）文风与剧情 | `skill://`，`<repo>/skills/` + `<world>/skills/` | 描述常驻，正文按需 `read` | 平台级=通用手艺；世界级=这个世界 |
| **工具层（capability）** | 每个工具做什么、何时用、何时别用 | `extensions/toolkit/*.ts` 的 `description`（进 schema）+ **可选** snippet/guidelines（进 slot） | `description` 每轮在（schema）；snippet/guidelines 取决于 preset slot | 平台 |

**判据：一条内容只住一层。** 同一句话写两处 = 改一处漏 N-1 处（doc-23 §2.9）。归属判据：

- "我是谁 / 我每轮都要守的规矩" → 常驻层；
- "这件事怎么做得好"（可举例、可长、偶尔才用） → 细则层；
- "这个工具是什么" → 工具层。

### 3.2 常驻层放什么 / 不放什么

**放**：身份与职责、单轮流程骨架（每步 + 漏了会怎样）、硬约束与其机制理由、"不做也是合法输出"的出口、**指路**（"细则见 skill X"）。

**不放**：工具逐个用法（→ 工具层 description + 细则层）、注入块已经承担的内容（`docs/hooks/00 §12` 反模式 4：状态块里不写规则，提示词里也不复述状态块）、剧情与文风（→ 世界级 skill）。

### 3.3 细则层（skill）的分工

| 层 | 位置 | 放什么 | 语言 |
|---|---|---|---|
| 平台级 | `<repo>/skills/` | 通用手艺：生图、组件叙事、用工具叙事（move_to/show/choice 的创意用法）、节奏、玩法咬合 | **英文** |
| 世界级 | `<world>/skills/`（与 `world/` 同级） | 这个世界的**文风**与**剧情脉络**；随世界包分发 | **跟随世界语言**（用户 2026-09-12 拍板：日式世界用日文，英文世界用英文） |

> **语言分层的一个例外（冻结）**：AGENTS.md §1.1 要求"喂给 AI 的 prompt 一律英文"，指的是**平台口径**。
> 世界级 skill 是**世界内容**（它描述的是这个世界用什么腔调讲什么故事），所以跟随世界的语言——
> 日式世界用日文写文风指导，正是它该有的样子。这条与 §1.1 不冲突，是 §1.1 未覆盖的一格。

- `SKILL.md` frontmatter 只有 `name` + `description` 必填（`vendor/pi-rp/.../docs/skills.md`）；**`description` 决定作家何时去读它**——写具体（"什么时候落 note、什么时候落 letter、什么时候只写 chalk"），不写"帮助处理组件"。
- 一个 skill = 一个含 `SKILL.md` 的目录；长料放 `references/`，正文按需引用（渐进披露）。

### 3.4 角色能不能有 skill（冻结）

**给，但只给"工具具身"类平台 skill，不给剧情/文风。**（用户 2026-09-12 拍板）

- 角色的**人格**来自 `identity.md` / `personality.md`（file slot），不是 skill；
- 角色**可以**学会"用 chalk / move_to / show / choice 演自己"，因为工具是它的能力（doc-20 §1）；
- 角色**不该**读"剧情脉络"——那是作家的全知视角（`docs/hooks/00 §3.3`：角色不注入 `bag`、不注入玩家相机，同一条精神）。
- 落地：`characterLaunch` 传 `--skill`（**仅**平台级 `<repo>/skills/`？还是两级？见 §6.3 待拍板），preset 加 `skills` slot。

## 5. 事实边界（冻结：提示词 MUST NOT 说错的事）

提示词里凡是"工具能做什么"的断言，MUST 与**代码真相**一致。以下是本批冻结的对照表（写正文时照此，不许凭印象）：

| 提示词会提到 | 真相（file:line） | 常见错误 |
|---|---|---|
| `chalk` 写正文 | `extensions/toolkit/chalk.ts`；动作 `packages/shared/src/actions/chalk.ts` | 说"用 write 写 chalk" |
| chalk 的 frontmatter | **工具不写** frontmatter（`chalk.ts:79` 注释）；互动字段由 Phase ② 的 `edit` 写回 | 说"chalk 里带 status/choice" |
| 默认 chalk 文件名 | `<layerDir>/NN-<slug>.md`（`docs/tools/00 §2.3`） | 说"自己起名" |
| `roll_dice` | 只收 `path`；`result/type/expect` 由引擎从文件读、**调用者不能传**（`extensions/toolkit/roll-dice.ts:36-39`） | 叫 agent 传 expect |
| `choose` | 只记"选了"，**不改文件、不删选项、不决定后果**（`choose.ts:26-28`） | 说"选完自动推进" |
| `move` vs `move_to` | `move` = 物件文件（`move.ts`）；`move_to` = 角色 presence（`move-to.ts:22-24`） | 混用 |
| `use_item_on` | **不消耗、不移动**物件（`use-item.ts`） | 说"用完就没了" |
| `show` | 一次性演出，**不写文件不落账**（`show.ts:29-32`） | 说"用 show 放一封信" |
| `delete` | 只报 dangling，**不重写引用**（`delete.ts:18-21`） | 说"自动清理引用" |
| 事件/状态 | **没有** `get_state`/`set_state`（doc-20 §2.3）；状态是实体 frontmatter 的一个键 | 造状态工具 |
| 注入块 | 每轮由 `context` 钩子临时注入，**不落盘**（`docs/hooks/00 §1`） | 说"上一轮的状态还在" |
| `[emo: tag]` 的**呈现** | 解析器 `apps/web/src/components/overlay/CharacterModal.tsx:60-65`（行首锚定 `^\[emo:\s*([a-z]+)\]\s*`，闭集 `apps/web/src/lib/audio.ts:37`） | 以为"标签一写就换脸"——**见下** |

### 5.1 跨端断链（**实测，写正文前必读**）

两条本批必须知道、但**不在本批范围内**的现状（避免把"提示词改了"误当成"行为会变"）：

1. **角色的回话今天根本没到前端。** `CharacterModal` 在 `handleSend`（`CharacterModal.tsx:176-184`）里发完 `character_prompt` 后，**直接读本地假数据** `FALLBACK_REPLIES`（`:40-47`）并流式播放；`character_delta` / `character_message`（server 侧 `event-bridge.ts:59,70` 会发）在 `apps/web/src` **零消费**（全仓 grep 仅命中 `apps/server`）。也就是说：**改 `CHARACTER_INSTRUCTION` 今天不会改变玩家看到的任何字**。[推断：接线属 `docs/前端改造计划.md` 的流式任务，非本批]
2. **演出帧全都没有前端消费方。** `writer_delta` / `writer_message` / `writer_idle` / `chalk_writing` / `chalk_landed` 同 `character_*` 一样只有 server 发布点；`useWorld.ts:276-318` 的 switch 只处理 `file_changed` / `item_moved` / `god_action` / `world_frozen` / `card_position` / `tool_start` / `tool_end`。**`show` 工具返回的 `show_frame`（`extensions/toolkit/show.ts:12`）在全仓连发布点都没有。**
