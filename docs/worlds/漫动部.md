> 2026-09-15 · niko 需求。定稿设定在 `worldlines-assets/worlds/summer-demo/`（`BRIEF.md` 世界与人物、`STORY.md` 主题与暗线、`prompts.md` 素材）；短剧在同目录 `movie/`。**本文只写：这个世界如何投影成无限画布上的实体，以及模拟玩法。** 不改引擎（引擎以 main 为准），全部用现有机制：层 / README / 卡片 / `choice_actions` / `roll_dice` + `dice_outcomes` / 作家 / 角色 presence / 心象風景。

## 一、玩家是谁

- **玩家 = 部长·沈知夏**（第一季，女性向主视角）。作家（writer）扮演"这一年"：把月考、招新、文化祭这些事件不断切进画布。
- 导演、文豪、高达、大白、狐狸、404、太太、P主、栀子、许老师、周望舒是角色 agent，各有 presence（在哪一层）与心象風景（暗线的房间）。

## 二、投影：层与实体

### 2.1 层（layer）= 地点

`map` 是校园俯视图（`prompts.md` M1 定稿作 `bg`），13 个地点各一层，坐标沿用 `prompts.md` §4 的表。每层 `README.md` 带 `bg`（场景背景）、`ambient` / `bgm`（`assets/audio` 现有池：`calm` / `tense`，环境 `rain` / `fireplace` 等），门卡（`type: gate`）从 `map` 进入。

| 层 id | 地点 | 常驻角色（presence） | 层内固定实体 |
|---|---|---|---|
| `world/gate` | 校门 / 教务处 | 教导主任（NPC 卡） | 申请书文件夹（note）、招新桌（第 5 话后出现） |
| `world/clubroom` | 顶楼活动室 A/B | 全部部员（部活时间） | 黑板（chalk，作家写）、杂志架（每期一张 note）、旧 PS2（物品）、谷子墙、游戏机时间表（status 卡） |
| `world/art` | 美术画室 | 许老师；部长独处时周望舒会来 | 画架（部长的画，玩家可"画一张"生成 note） |
| `world/lab` / `world/computer` | 实验楼 / 电脑房 | 周望舒 / 404、P主 | 排名墙（status 卡：本月名次）、深夜亮着的机器（导演暗线线索） |
| `world/hall` | 文艺会馆 | 文化祭期间全员 | 舞台（gate → 演出层） |
| `world/canteen` | 饭堂 | 狐狸、大白 | 谷子交易所（choice：买 / 卖 / 拼团） |
| `world/dorm` | 614 | 五个男生（夜间） | 电饭煲（被查事件触发点） |
| `world/pond` / `world/hill` / `world/field` / `world/courts` / `world/grade1` / `world/grade3` | 荷花池 / 后山 / 操场 / 篮球场 / 教学楼 | 按事件 | 夏夜、拍摄外景、招新摊位、篮球场（文豪、高达） |

### 2.2 卡片类型的对应

| 世界里的东西 | 画布实体 | 说明 |
|---|---|---|
| 一年里的事件（月考、招新、文化祭、漫展、被抓） | **chalk**（作家写） | "世界不断切进来"：作家按学期时钟把事件写成板书，附 `choice` / `roll_dice` |
| 申请书、海报、传单、杂志、钥匙、PS2 | **note / 物品**（`portable`） | 可拿进背包、可放回；杂志每期一张，封面是生成图 |
| 部员 | **character（sprite）** | presence 随时间表移动；`follow` 可带人走（拉人去画室 = 支线触发） |
| 排名墙、部费、部员人数、群人气 | **status 卡**（`status.data`） | 模拟数值的可见面 |
| 顶楼两间教室、舞台、漫展 | **gate** | 进层；未解锁前显示"还没有钥匙" |
| 每个角色的暗线 | **心象風景（nook）** | 导演的机房、部长的画室一角、P主的编曲台、栀子的直播间；只有 follow 到一定程度才开 |

## 三、模拟玩法

### 3.1 学期时钟

- 一回合 = **一周**。第一季 = 2016.9–2017.7，约 40 回合；作家每回合按大纲（`movie/S1-分集大纲.md`）把当周事件切进来，并留出空白周给支线。
- 每周玩家分配 **3 点时间**到：`学习` / `部活` / `画画` / `社交`（去某一层找某个人）。分配写进 `player/README.md` 的 status，作家读取。

### 3.2 数值（status 卡，作家维护，玩家可见）

| 数值 | 含义 | 涨跌 |
|---|---|---|
| `rank` 名次 | 实验班排名（1–50） | 学习点 ↑；部活过多 ↓；月考 = 掷骰结算 |
| `club_heat` 部活热度 | 部员人数与群活跃 | 活动、杂志、投稿 ↑；禁令、骂战 ↓ |
| `bond:<id>` 羁绊 | 与每个角色 | 社交、follow、支线完成 ↑ |
| `art` 画技 | 部长暗线 | 画画点 ↑；决定封面与艺考支线 |
| `mood` 部长心情 | 疏离 ↔ 融入 | 被叫"部长"、被拉进团舞 ↑；被排除在外 ↓ |

### 3.3 判定：月考 / 期末 / 高考

用现有 `roll_dice` + `dice_outcomes`（`docs/perform/D10骰子动画.md`）：

```yaml
# world/lab/monthly-exam.md（作家在月考周写出）
type: chalk
roll_dice: { type: 1d100, desc: 十月月考, expect: <=60 }   # 阈值 = f(学习点, rank)
dice_outcomes:
  great-success: 名次进前五；班主任放行部活
  success: 名次不变
  failure: 掉出前十；触发"禁令"事件
  fumble: 家长来电；部活封门两周
```

- **月考**：每 4–6 周一次。**期末**：阈值更严，结果影响下学期开局。**高考**（第三年才有，第一季不出现）：终局判定，同一机制。
- 阈值由作家按 `rank` 与本周学习点算，写进 `expect`；掷骰演出走现有 DiceCeremony。

### 3.4 事件卡（作家切进来的 chalk）

每张事件 chalk 带 `choice_actions`（现有：`take` / `read` / `enter` / `character` / `writer`）：

| 事件 | 选择 | 落到什么 |
|---|---|---|
| 招新周 | 摆桌 / 发群 / 都做 | `club_heat`、报名人数、下一张"审核"chalk |
| 部活禁令 | 服从 / 偷溜上顶楼 | `rank` 风险 vs `bond` |
| 漫展远征 | 去 / 不去 / 只去一天 | 家长关（骰子）、狐狸的谷子、栀子支线 |
| PS2 被抓 | 认错 / 狡辩 / 导演顶上 | 实验班筹码消耗、教导主任 `bond` |
| 文化祭 | 宅舞 / 只摆摊 | 高潮层 `world/hall` 解锁 |
| 分科表 | 理科 / 文科 / 背面画画 | 部长暗线分支 |

### 3.5 支线与心象風景

- 每个角色的暗线 = 一条支线：`bond` 到阈值后，该角色的 nook 开门（导演的机房：一台亮着的机器；P主：一首没署名的曲子；栀子：直播间）。
- 支线完成写回 `status`，并让作家在后续事件里回收（第 30 话 P主曝光、第 31 话栀子精）。

## 四、落位（第一季）

**现状（2026-09-15）**：第一版建在 `worlds/mandongbu/`（gitignore，不入库；由 `tools`-外的生成脚本产出，见本节末），可直接从「Saved games」打开试玩。`templates/` 有门禁：`check:worlds` 要求恰好是注册家族 × 三语言，所以进模板前要在 `tools/world-editions.mjs` 注册 `mandongbu` 家族，并补英、日两版（中文版可作为源，反向生成）。

```
worlds/mandongbu/   （试玩）→ templates/mandongbu-zh + mandongbu + mandongbu-jp（发布）
├─ world.json                 id、name「漫动部」、locale zh-CN、cover（K1）、audio.theme
├─ world/README.md            map：bg = M1 俯视图；13 张 gate 卡按坐标摆
├─ world/<layer>/README.md    各地点：bg、ambient、bgm
├─ world/clubroom/*.md        黑板、杂志架、旧 PS2、时间表
├─ characters/<id>/README.md  11 个角色 + 教导主任；presence.home、voice、avatar（prompts.md §5）
├─ characters/<id>/nook/      心象風景（暗线房间）
├─ player/README.md           部长；status：rank / art / mood / 时间点
├─ skills/mandongbu-play/SKILL.md  作家的"这一年"手册：学期时钟、事件表（引用 movie/S1-分集大纲）、数值规则、判定阈值
└─ assets/                    scenes（M1、各层 bg）、characters（立绘、6 情绪）、motion（导演循环动图）
```

作家 skill 是关键：它拿着 52 话大纲当"事件表"，按周切进画布，但**不照本宣科**——玩家的分配与骰子结果决定哪条支线先来、谁先叫她"部长"。

**引擎硬约束（已按此建）**：带 `dice_outcomes` 的判定卡只接受 `1d100 <="<=60"` 或 `2d10 ">=11"`，四段固定为 1–12 / 13–60 / 61–95 / 96–100（或 2–4 / 5–10 / 11–17 / 18–20）；学习投入的差别写进各段后果，不改阈值。占位图由生成脚本用 PIL 画出，正式图按 `prompts.md` 生成后覆盖 `assets/scenes/*.webp`、`assets/characters/*.webp`。
