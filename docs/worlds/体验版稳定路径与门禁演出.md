# 体验版稳定路径与门禁演出

> 2026-09-13。适用六个旧版 `*-playtest` 世界，现仅作为被忽略的归档／历史 fixture，不是正式世界入口。用户已自行清理存档，后续只修改模板，不恢复或继续迁移存档。

## 1. 路径与语言

世界、地点、时间场景、人物、道具和 Chalk 都使用英文稳定文件/目录 ID；日语标题、正文、角色显示名与世界指令继续使用日语，英文世界继续英文。

例如 `world/harbor-chart/README.md` 的 `title` 为「霧埠 · 港の地図」，`characters/vera/` 的显示名为「ヴェラ」。链接、Gate target、requires.items、home、preset 文件槽与生成意图引用稳定路径，不能用显示标题寻址。

`tools/migrate-japanese-paths.mjs` 的固定映射同时供内容编译器使用。作者稿的本地化标签经过该映射成为稳定路径，不自动音译未知名称。未来生成的新场景、结局与新物品也遵守英文路径规范；不是仅改已存在的文件。

世界 skill 目录和 frontmatter name 一致，按世界加前缀，例如 `skills/wuwu-playtest-play/SKILL.md`。模板编译源在 `tools/experiences/`；现有目录不会被安装器覆盖。

## 3. 门禁未满足不是系统报错

服务端继续返回 `409 / requirements_not_met` 并阻止移动。前端通过结构化错误码识别，而不是匹配报错文案：

- 门牌顶层的 `blocked` 作为短旁白，淡入呈现；门牌与当前场景内可对应的缺失物短暂描边。`requires.items` 仅保存物品门槛。
- 提示仅列出真实缺失、且当前场景可识别的物件标题；不泄露内部路径，不凭空告诉玩家去未发现地点。
- 玩家可点击「この場に戻る」或按 Escape 收起。没有扣血、自动骰子、自动取物或自动再试。
- 只做临时演出，不落剧情历史，不调用作家或生图，不把拦截伪装成已发生的新剧情。
- 非门槛错误（网络断开、500、非法 Gate 配置等）继续走技术故障提示，不伪装成故事事件。

实现入口：`airp-gateway.ts` 保留错误结构，`gate-feedback.ts` 分类，`useWorld.ts` 派发本地呈现信号，`GateThreshold.tsx` 渲染。此信号不是新 WS 帧，既有跨端协议不变。
