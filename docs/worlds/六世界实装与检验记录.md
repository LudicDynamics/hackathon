# 六世界实装与检验记录

## 本轮边界

按「计划 → 实装 → 检验 → 反馈」推进。世界设计以各自的短闭环验收文档与《Chalk 玩法形态与判定约定》为准。

当前工作区有素材、动效、服务端并行改动。本轮使用内容编译器从既有模板复用图形，生成六个独立的 `*-playtest` 试玩模板；不覆盖原模板或玩家存档。源内容在 `tools/experiences/`，安装入口为 `node tools/install-experiences.mjs`。这是内容生产工具，不是第二套游戏引擎。安装后的模板继续走现有文件扫描、README 门牌、choice、move、roll_dice 和 Writer 管线。

## 计划与验收

| 世界 | 主视图 | 本轮关键实装 | 验收证据 |
|---|---|---|---|
| 雾坞镇 | 地点 | 委托与徽章都拿取后出门；提交调查材料，确认后才投骰；雾外新路 | 双物件门禁四种组合；判定预告与文件落盘 |

## 语言与演示节奏

前五个试玩包为日语，第六个为英语。保留系统协议名 `README.md`、`SKILL.md`、`world.json`、`preset.json`、`world/`、`player/`、`characters/`、`skills/` 与资源路径；普通目录、文件、人物标识统一英文稳定 ID，内容提示词随世界语言。skill 注册名与目录一致，使用 `<world>-playtest-play` 前缀。最新迁移及门禁演出验收见 `体验版稳定路径与门禁演出.md`。平台通用角色压缩提示词继续与 `presets/character.json` 保持一致，不在单个世界擅自修改；它不属于世界剧情提示词。

5 秒认出身份与情境，20 秒可做第一个动作，1–2 分钟内完成一个有回报的局部回路；生成只放在自然的边界。5–10 分钟是短剧本目标，不承诺模型耗时。30 分钟延展不是本轮验收目标。骰子数值仍为可调 Demo 候选。

骰子测试实际发现：行内 `roll_dice: { ... }` 虽能解析，却不支持结果回写。内容编译器已改用多行 YAML，世界规则也明确此限制。候选 `2d6` 分布为 3/12/18/3，共 36 种，不把引擎的双六 crit 与叙事的 11–12 大成功混为一谈。

### 尚未证明与暂未实装

- 提交、Hybrid、生成与结局规则已经写入场景和世界 skill，但判断语义、逐件落盘、缺件修复仍由 Writer 执行；不能视为机器事务保证。复杂剧情与两路初雪结局仍需真实作家验收。
- 暂无新多槽提交面板。先复用 Chalk 自由输入、引用现有物件、文章提交和显式确认。没有增加 `choice.mode: multi` 或另一套状态引擎。
- 初雪目前明确复用已存在的屋顶/雪景，而不是声称五张新 CG 已完成。学院本地只有角色素材，没有合适的已落地背景图；保留底座桌面，不捏造素材路径。
- 旧模板、旧存档不会自动迁移；新内容从「体験版 / Playtest → 新しく始める」进入。世界列表暂时同时保留新旧版本，正式入口收拢留待试玩结果确认。

### 重现

先 `pnpm build`，再 `node tools/install-experiences.mjs`。安装目录存在会拒绝覆盖；需要并排新版本时用 `--revision=<新英文标记>`，不会覆盖存档。本轮首次编译的临时草稿已移到 `.artifacts/six-world-first-build/`，可恢复，原模板未移动。

真实作家脚本为 `node tools/rehearse-experiences.mjs --live --world=all`：使用全新且保留的存档，固定 OpenAI GPT-4.1，六个世界约八个动作，不请求生图。初雪检查手纸、角色记忆、异地缺席和后日谈；未写之门检查信件 Context 与门外五个文件。其他四个目前只测关键开局，不能冒充其最终高潮通关。运行前需完成外部发送与费用授权。模型工具调用支持见 [OpenAI 官方模型文档](https://developers.openai.com/api/docs/models/gpt-4.1)。
