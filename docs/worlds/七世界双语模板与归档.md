# 七世界双语模板与归档

2026-09-14：六个最新 playtest 提升为正式模板，另保留「月下の誓い」。每个世界只保留英文、日文各一份。模板目录不再用 `playtest` 区分新旧；`*-playtest` 只作为被忽略的历史／实验 fixture。

## 1. 当前入口

在 `http://localhost:5173/` 的世界列表中选择对应语言，新建存档即可。图片、动画和路径共享同一套规则；不是只切换 UI 语言。

|---|---|---|---|

英文目录采用原世界 ID；日文加 `-jp`，中文加 `-zh`（`world.json.locale` 为 `zh-CN`）。初雪英文的正式 ID 为 `first-snow`（2026-09-14 按实际发布版本统一；登记表 family 键仍为 `firstsnow`，残留的 `templates/firstsnow/skills` 已删除）。`world.json.id` 与模板目录一致，名称标明 English／日本語／中文。角色、物品、地点 ID 和跳转路径始终是英文，只有世界级 skill 的目录随模板 ID 命名为 `<id>-play`，避免重名。

### 中文版（2026-09-14）

中文版以英文版为可执行契约，由 `tools/localize-zh-edition.mjs` 生成：`extract` 按 `mapText` 规则从英文版抽出人类文本单元（正文整段为一个单元），并按同一位置对齐日文原文作参照；译文写入忽略目录 `.artifacts/zh-edition/<world>/zh/*.json`；`check` 核对缺译、受保护字面量（路径、文件名、代码、数字、骰式、占位符、链接目标）、残留假名与语言指令；`build` 只替换这些文本单元生成 `templates/<id>-zh`，因此 ID、条件、路径与素材字节与英文版一致。角色 `world-language` 以「说中文。」开头，作家统一译作「作家」。翻译由本地 Claude 子 agent 完成，不调用付费翻译 API。修改玩法时三语版同步；改英文文本后重新 `extract` 并补译变化的单元。

## 2. 保留的内容与边界

- 以最新体验版为源，保留零级导入、主视图、物件、人物小天地、世界 skill、README intent、Chalk、选项操作和生成边界。
- 英文版翻译正文、标题、人物关系／日记／目标／心事、选项、场景及作家／角色本地提示词；日文版保留日文体验内容。未写之门补日文，月下之誓补英文和日文说明。
- 语言指令也适配目标语言，不把“用日语说话”直接留在英文版。平台共享 preset、工具名、协议枚举和 compaction 模板不按世界复制翻译。
- 门禁路径、人物 home、选项 ID、骰子公式与分档不变。雾坞／福尔摩斯的 12 张原始骰子卡及最新 rewards 声明，在两语版共 24 张卡中保留；奖励正文同样本地化。
- 图片和动画逐文件哈希相同；不重新生图。图片内既有文字不等于被翻译。资产来源 JSON 保留原始溯源记录，不改写历史。
- 不复制 `.airpworld`、`.pi` 或密钥到新模板，不给新玩家预发通关物品。`worlds/` 现有存档完全不迁移、不删除；列表里仍可能显示旧存档分组。
- 月下之誓保留作家演出人物与开放生成的形态，不临时增加注册 NPC 或硬编码选择流程。

## 3. 归档与恢复

原 18 个模板完整移到 `archive/templates/pre-bilingual-2026-09-14/`。包括六个 playtest、被替换的原模板、旧题材原型和技术测试模板 `dice-lab`。归档不在世界列表扫描的 `templates/` 根目录内，因此不会作为新游戏选项出现。

同目录 `archive-manifest.json` 记录原路径和内容哈希；归档是可恢复移动，不是删除。需要重开旧版时，将对应归档目录复制到一个**新的**模板目录或临时存档，检查 `world.json.id` 后使用；不要覆盖当前双语版或已有存档。运行缓存和密钥不纳入 Git。

## 4. 后续维护

当前内容真相源是上述 21 个模板（英文版为可执行契约）。修改玩法时同步三语版；不再修改 `*-playtest` 后期待线上内容变化。

`tools/experiences/` 保留旧内容编译器与历史回归语料。`install-experiences.mjs` 从归档原型取素材，只输出到 `.artifacts/experience-builds/` 或显式测试目录；禁止重新把旧编译器产物塞回正式模板列表。旧 `sync-template-assets.mjs` 的地图映射已过时，归档后拒绝写入，需审阅正式场景路径后再使用新素材映射。

原型回归测试和六个旧引擎探针改为引用归档 fixture；当前版本由 `tools/check-world-editions.mjs`、`tools/world-editions.test.mjs`、`tools/shipped-experiences.test.mjs` 验证。历史设计文档中的旧路径按当时版本阅读，不是当前入口。

- 14 个模板、820 个文件：文件集合、可执行字段、素材哈希一致；英文本地化字段无残留中日文；人物小天地、preset 文件槽与头像引用均可解析。
- 临时新存档通过真实本机 HTTP 路由测试：14 个版本、两语拓扑一致，164 个声明式选择完成，无 Agent 派发；雾坞在缺少委托／徽章时阻止进入，拿齐后可进入。
