## 7. 硬约束（派发时已写入，违反即返工）

1. **跳过全量验证**：不要 `pnpm build` / `pnpm test` / 全量 lint——N 个 agent 同时开 N 份重负载会卡死机器。**本批是设计批次，产出是文档，不写实现代码。**
2. **示例当代码自检**：文档里的代码片段只引用**真实存在**的符号；新函数标 `NEW`。
3. **不臆造**：不存在的 slot 名、不存在的动作 kind、不存在的 API、不存在的职级——都不许写。
4. **事实带证据**：凡断言「现状是 X」，必须带 `file:line` 或可复现命令。
5. **推断标 `[推断]`**，未知写进第 12 节，**不许把未知伪装成已定**。
6. **有重大发现立刻用 `hub send` 通知主 agent 与相关兄弟**，不要憋到最后。
7. **重叠即联系兄弟**：边界有交叉时先发消息达成一致，再动笔。
