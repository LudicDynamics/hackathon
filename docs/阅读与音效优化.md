# 阅读与音效优化

- 背包实体点击打开完整 Markdown；只有明确点击「放回场景」才移动文件。失败保留阅读窗。
- 普通画布文档点击正文或聚焦后 Enter 打开详情；不把查看转换成剧情选择。按钮、链接、门、人物和特殊道具保留各自行为。
- 阅读窗最大宽度 780px，衬线字体、18px 字号、1.85 行高；长文内部滚动。关闭按钮、页尾关闭、纸外点击、Escape 均可收起，避免拖动结束误开。
- 存档确认后立即收起选择器，独立显示加载遮罩；失败重新打开选择器。加载尚未完成时不允许继续操作旧世界。
- 交互音复用 Canvas 的魔王魂素材及 0.14–0.28 音量；旧素材保留。相同音效至少间隔 500ms，并按音频时长阻止重叠。迟到超过 500ms 的加载结果丢弃，静音、后台、音频上下文未运行时不排队补播。
- 主题曲、层 BGM、环境音解析与三轨关系不变。素材署名见 `assets/audio/CREDITS.md`。
