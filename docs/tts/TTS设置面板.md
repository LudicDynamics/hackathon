# TTS 设置与克制降级（niko）

2026-09-14 音频体验修正：顶部入口显示为“声音与设置”，面板首段直接提供语音与背景音乐两路音量及百分比；两路仍复用音频引擎的独立总线并实时生效，不重播语音、不重新合成。总静音时面板显示明确提示和“开启声音”操作，避免滑杆数值变化却仍无声。语音播放使用 5ms 防咔哒起音，背景音乐与主题曲继续使用 1.5s 渐变；不再让语音沿用主轨渐变而压低开头单词。

2026-09-14 增补：初雪七海支持本机优先与线上兜底，请求增加可选 characterId / emotion；本机配置也计入 configured，失败以响应头通知浏览器警告。最新契约见 [10-本机角色语音与线上兜底](10-本机角色语音与线上兜底.md)。下文单供应商与 emo 仅立绘的旧描述以该增补为准。

顶部“声音与设置”提供本浏览器语音开关、服务配置状态、线上兜底模型和默认音色，以及 DashScope TTS、OpenAI-compatible、Flow media proxy、DeepSeek 的连接配置。角色语音区单独提供七海本机 TTS 的基址、声音 ID、超时（1–120 秒）与可选密钥，并独立保存；清空本机基址后保存会关闭本机路径。已有密钥不回显，不进入 localStorage；密钥留空保留原值，关闭面板销毁草稿。模型和线上默认音色仍只展示。说明、表单标签、状态与错误均支持英中日文，切换语言时状态文案同步翻译；品牌、模型 ID 和 URL 保留原文。

`GET/POST /api/connection-settings` 仅允许 loopback socket、localhost Host/Origin，拒绝转发来源；POST 还要求 JSON 和专用请求头，不能通过 Tailscale 展示地址修改。GET 密钥字段只返回是否配置。POST 白名单校验后原子保存仓库 `.local.env`（若存在），否则保存 `.env.local`（创建时请求权限 0600），保留其他变量并更新当前进程环境。未提交字段保持原值；本机声音 ID 限 1–64 个字母、数字、下划线或短横线，首字符必须是字母或数字；超时以整数字符串毫秒传输，范围 1000–120000。TTS 后续请求立即生效，已有 Agent 进程需重新启动；Flow 配置是媒体代理，不代表作家模型已切换。保存不是上游连通性验证，不自动发起付费调用。

`GET /api/tts/config` 返回 `{ configured, model, defaultVoice }`，不返回 key 或 gateway URL，禁止缓存。configured 表示线上密钥或本机基址至少配置一项，不表示上游调用已验证；model/defaultVoice 指线上兜底。

角色语音预取前共享一次配置检查。未配置时不发送合成请求，当前页面会话仅提醒一次，不阻塞文字。网络或合成失败后冷却 60 秒，面板可手动重新检查；关闭语音只阻止后续合成请求，不中断已经发送的请求。保存设置后自动重新检查。
