# 世界语言与自然语气

2026-09-14 增补：初雪七海支持本机优先与线上兜底，请求增加可选 characterId / emotion；本机配置也计入 configured，失败以响应头通知浏览器警告。最新契约见 [10-本机角色语音与线上兜底](10-本机角色语音与线上兜底.md)。下文单供应商与 emo 仅立绘的旧描述以该增补为准。

2026-09-13 修正：UI locale 只控制按钮与界面；角色问候、沉默台词和 TTS language 都跟随 manifest.locale，缺省英文。问候缓存升为 v2，加入内容语言，避免英文／日文互相抑制。不清除存档、剧情或聊天历史。

Vera（wuwu 英文／日文体验版）改用 `warm-cheerful` → Cherry；Nanami（firstsnow / first-snow-jp 及体验版）改用 `girl-next-door` → Nini，避免与澄的 Cherry 重复。两者均为已通过项目音色门禁的候选。不全局修改别名表，以免影响其他角色；只同步仍使用旧别名的现有存档，保留已自定义的其他音色。不通过播放速度或音高加工假造年龄，最终听感仍需用户试听确认。

角色 system-char 指令要求读 world.json 确认世界语言，旧聊天语言与 UI 语言不作为覆盖依据；短句口语表达，少量适度情绪，不用夸张叹号、拖长音、喘息词或舞台说明。emo 标签继续只控制立绘，不直接当成音频指令或被念出来。

`/api/tts` 请求体仍为 text / voice / language，不新增角色私密设定。服务端仅对 `qwen3-tts-instruct-flash`（含日期版本）添加固定英文自然语气 instructions，关闭自动改写；普通 Flash 不传不支持的参数。指令与朗读正文分离，指令变更进入缓存键，不删除原缓存。

普通 `qwen3-tts-flash` 不具备指令控制能力。本机端点已用 Cherry 英／日各一句验证 Instruct 返回有效 WAV，`.local.env` 已启用 AIRP_TTS_MODEL=qwen3-tts-instruct-flash；这不是主观音质评分。其他部署需确认自身端点权限。对日语语音也使用英文指令；厂商限制的是指令文本语言，而非日语朗读。

依据：[官方接口文档](https://www.alibabacloud.com/help/en/model-studio/qwen-tts-api)、[官方音色清单](https://www.alibabacloud.com/help/en/model-studio/qwen-tts-voice-list)。
