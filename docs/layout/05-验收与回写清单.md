## 1. 一句话定位

**给「生成组件不重叠」这件事开一张能跑、能红、能绿的判决书**：把 00 的每条冻结形状翻译成**四层**断言（静态 grep / 纯函数单测 / 服务端集成 / 浏览器实测），每层写清它**能**证明什么、**不能**证明什么；给出**四条修复前必红、修复后必绿的非空性 fixture**（含今天 `[实测]` 的重叠数值）；最后列出落地后 MUST 同一 commit 回写的上位文档。

**05 不实现任何功能**。它回答的唯一问题是：**「没有这条接线/这个几何就会失败」如何被机械证明。**

四层分工（00 §8 第 7 条的直接兑现）：

| 层 | 证明什么 | 不证明什么 |
|---|---|---|
| 静态 grep（§9） | 旧几何/旧口径**已清除**、无新帧、无 metadata 越界 | 任何行为 |
| 纯函数单测（§3 A 组） | `flowColumns` 的**几何不变量**（列主序、超列高、障碍右扫、旧卡不动、耗尽标记） | 服务端真的调了它、前端真的用了它 |
| 服务端集成（§3 B/C/E 组） | 一次真实 `/api/layer` 后 `cards.x/y` **不重叠**、批内顺序稳定、幻影与真实坐标一致 | 玩家**看到**的绘制盒不重叠（表单名义高 ≠ 绘制高） |
| 浏览器实测（§10，`[手测]`） | 真实 `offsetHeight` 下**画面上**不叠；Chalk 拖拽锁真的生效；相机取景真的把新流框进来 | 跨会话持久性与幂等（那要集成层） |

> **绝不用「浏览器看着不叠」代替几何断言，也不用「几何断言绿」代替浏览器实测**——00 §8 第 7 条逐字要求「两者都要验收」。

**判据（本文冻结为验收口径，供 `01`/`04` 对齐）**：

- **P-O1**：`flowColumns` 的 `origin` 是**列流起点**，对**所有**层取同一个值（00 §4.3 缺省）；**MUST NOT** 为「初始化层」引入第二个 anchor（00 §8 第 6 条：座位只有存储层与共享纯函数两个接缝）。

- **P-O3**：「空层」不是几何特例：测试断言 = 「同一层在『只有 `opening.md`』与『有 `opening.md` + 三张卡』两种输入下，`opening.md` 的 placement **都是** `origin` 处的第一列第一格」——它**证明**没有 anchor 特例，而不是引入特例。
- **P-O4**（负断言）：任何「层为空 → 换个中心锚点」的实现在 P-O3 上**必红**。

**反例（迁移前会失败的形式）**：迁移前空层的第一张卡由 `seatUnplaced` 螺旋放在 `SEAT_ANCHOR = {x:960,y:540}` 附近，而 00 要求 `origin.x = 360`——**P-O3 迁移前必红**；现已由 `flowColumns` 的缺省 origin（`flow-columns.ts:31-38`）满足。
