## 2026-09-10 架构变更记录

> 本次文档重构依据的架构调整（明月 2026-09-10 口述，逐条确认）。核心一句话：**叙事文本是唯一主角，其余全是修饰和呈现辅助**。

| # | 变更 | 旧（2026-08-31） | 新（2026-09-10） |
|---|---|---|---|
| 1 | **砍世界内角色编排** | 独立角色进程 + 作家 call_character 搭线 + pass_mic 角色间直连 + 黑板旁听 + 节拍偶发推演 | 角色退化为**对话遮罩 + 小天地**：被点开才 spawn 独立进程（懒灵魂），不参与世界编排、不打断剧情。角色间交互彻底砍掉，互动由作家叙事现写 |
| 2 | **不再分独立角色 vs NPC** | 独立角色（有 agent）≠ NPC（作家现编） | 统一：任何角色点击进遮罩（背后有 agent，第一句话才 spawn）；没点开就是布景头像 |
| 3 | **角色呈现** | 角色精灵 + idle 演出动画 | **类光标 + 圆形头像**（画布上）；进入单聊遮罩 → 左右分屏大半身立绘 |
| 4 | **状态/选项/骰子收编** | 独立状态文件 + 状态栏 UI 配对；ask_option/roll_dice 独立工具 | **全部作为 `type: chalk` 的 frontmatter**（status.data / choice / roll_dice），类 md 表格渲染，可折叠，随叙事走；**无独立状态文件、无状态栏** |
| 5 | **组件降级** | 组件 = 可交互单元，前端按 component 渲染 | **组件 = 叙事补充**（视觉/沉默细节），不承载玩法推进；推进靠 choice 选下一段 |
| 6 | **单轮管线** | 作家 chat history 进画布？ | **chat history 不进画布，只有 chalk 落板**。单轮四阶段：Hook 注入场景上下文 → chalk 落正文 → edit 回写 frontmatter → write/edit 演化场景物件 → 轻量收敛 |
| 7 | **角色小天地** | —（无此概念） | 每个角色保留目录小天地——**`characters/<角色名>/` 根目录本身就是小天地**（参考 `角色-yoshi.html`）。"角色自己写"三分情境：场景单聊顺手写（不可实时见，提示"留下了东西"）/ 进小天地根目录为空触发初始化 / 小天地内聊天实时可见可评论 |
| 8 | **桌伴方向** | 桌面陪伴产品（doc-06） | **否决归档**（`archive/doc-06-桌伴产品构想.md`），只做无限画布 |
| 9 | **玩家背包（新增）** | —（player/ 只是玩家文档目录） | **`player/` 目录 = 玩家的小天地**：右侧边栏"背包"tab 以资源管理器式列表预览；背包 ↔ 场景**双向拖拽**（场景→背包=收藏拿走，背包→场景=放回），本质是文件搬移（路径即 id），作家经 fs.watch 感知并可叙事回应 |
| 10 | **角色 tab（新增）** | —（角色只能画布上找） | 右侧边栏"角色"tab 列出 `characters/` 头像：**导航**（点头像跳到角色场景）、**聊天**（点「聊」进遮罩）、**跟随**（点「跟」后角色在场状态跟玩家走，切场景跟着来）；跟随是运行时状态不是文件搬移 |

## 2026-09-11 多模态与游戏性升级记录（评委导向，详见 doc-19）

> 依据四位顶级黑客松评委 Advice（Playable Intelligence 警示不用 Blender/要 playable；PlayCo 要求视听动全满贯；Supercell 要求经典游戏玩法与 Tool Pipeline；AnotherBall 要求舞台大秀与情感沉迷）。

| # | 维度 | 旧口径（2026-09-10） | 新口径（2026-09-11，doc-19 定案） |
|---|---|---|---|
| 1 | **核心哲学** | 叙事文本是唯一主角，其余全为修饰和呈现辅助 | **叙事是世界的灵魂，多模态（视听动）与实体交互（道具/骰子/空间）是游戏的肉体与玩法主力** |
| 2 | **组件与背包解谜** | 组件仅是装饰/沉默细节不承载玩法，推进全靠 choice；背包仅是文件搬移（拿走/放回） | **以物解谜（Point-and-Click）**：背包道具可拖拽释放到场景卡片/门/NPC（`use_item_on`），出示证据/开锁直接驱动剧情演化 |
| 3 | **感官多模态** | 0 音效、0 BGM；背景为纯静态 PNG | **全景声场体系**（环境白噪音 + 实体拟音 Foley + 动态 BGM）+ **AI 微循环动态背景**（3~5s 视频循环） |
| 4 | **视觉空间** | 纯平面画布，极度沉静克制暮色手账 | **2.5D 纸雕微缩立体剧场**（CSS 3D perspective 视差 + 浮尘粒子 + 高潮时刻舞台追光 Spotlight） |
| 5 | **角色呈现** | 类光标头像，无表情无演出 | **全套 6 情绪立绘差分**（normal/smile/shock/sad/angry/thinking），角色 Prompt 显式输出句首 `[emo: <tag>]` 格式标签驱动平滑切换；呼吸动效 |
| 6 | **状态感知** | 不做状态栏，全收进 frontmatter 折叠表格 | **轻量时间印章**：底层仍随 frontmatter 走，暂不做复杂 HUD，界面仅以极简印章呈现世界时间与天数 |
| 7 | **大号物理掷骰** | 静态表格卡片判定 | **大号 2.5D 物理骰子演出**：旋转蓄力、撞击拟音、CRITICAL/FUMBLE 戏剧大标结算 |
| 8 | **上帝模式** | 玩家直接改写 Markdown 文件 | 包装为 **AI 游戏工坊管线（Tool Creation Pipeline）**：右键一键生成新 NPC/新关卡/道具 |

## 一句话总结

画布是全空间（一切都在上面发生），缓冲是黑板（一切动作沉淀成给 Agent 的结构化上下文），消息是指路牌（聊天只说"看黑板"）——**而叙事是世界的灵魂，视听动多模态与实体道具交互是游戏的玩法主力**：用 2.5D 视差纸雕剧场演戏，全景声音造境，道具拖拽解谜，大骰子定乾坤，打造有秀感（Show）、可玩性（Playable）和情感沉迷（Obsession）的活世界。
