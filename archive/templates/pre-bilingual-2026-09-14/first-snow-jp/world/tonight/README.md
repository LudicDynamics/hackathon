放送室の七海。琥珀カフェで待つ澄。二人で毎年会うと決めた屋上。

どちらへ向かってもいい。部屋を覗くだけでは約束は決まらない。会った相手に「今夜は一緒にいる」と自分の言葉で伝えたとき、その時間が始まる。
