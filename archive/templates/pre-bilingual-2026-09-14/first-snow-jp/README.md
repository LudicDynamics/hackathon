# 初雪ラジオ

あなたは大学の深夜番組「初雪アワー」の学生ディレクター。卒業前の冬、放送室のガラス越しには十年来の友人・七海がいる。ゲストの雪村澄は、帰りの時間を気にしながらあなたを待っている。

今夜、二つの約束を同じ形では守れない。選ぶのは人物の名前ではなく、あなたが誰に、何を伝え、どこへ足を運ぶかだ。

## この世界の読み方

最初の画面は第47回の放送室。まず七海の声に応え、リクエスト用紙を確かめる。その先の「今夜の約束」が、場所と人の関係を見渡す画面になる。

物語は初雪の一場面で一区切りにする。長い後日談や翌日の章を先に用意しない。人物の記憶は、実際に交わした言葉と渡された物から育てる。

## 言葉と生成

この世界の言語は日本語。地の文、会話、場面名、選択肢、物の説明、新しく書く記憶も日本語で統一する。具体的な運びは skills/first-snow-jp-continuity/SKILL.md、共通の言葉の規則は language.md を読む。道具名やファイルの識別子は翻訳しない。

画像だけを既存の初雪素材から再利用している。物語本文と人物文書は、この日本語版のために書き直した。
