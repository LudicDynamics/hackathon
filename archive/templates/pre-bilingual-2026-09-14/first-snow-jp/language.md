# この世界の言葉

- 地の文、人物の台詞、選択肢、場面名、手紙、物の説明、関係の変化と記憶は、自然な日本語で書く。英語の原文を併記しない。
- プレイヤーは「あなた」、親しい七海は必要に応じて「ディレクター」と呼ぶ。プレイヤーが名乗った名前は、その後の会話で尊重する。
- 表記は「七海」「雪村澄」「初雪アワー」「ホワイトアルバム」「琥珀カフェ」で統一する。
- YAML / JSON のキー、type / component / role のプロトコル値、ツール名、既存のパスと識別子はそのまま保つ。新規ファイル名は小文字の ASCII とハイフンで付け、表示名は日本語にする。
- 世界外の技術的な説明を台詞に混ぜない。翻訳済みの定型文を返すのではなく、この場で相手が見聞きした事実に応える。
- 未実行の処理や未生成の画像を、完了した出来事として語らない。画像がなくても、既存の絵と短い日本語の場面描写で応答できる。
