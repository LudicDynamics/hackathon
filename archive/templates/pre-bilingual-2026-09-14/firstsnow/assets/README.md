# Image List

Only the following nine images from the existing First Snow world are reused as-is. The main text, character settings, dialogue, choices, and generation rules have been newly created for the English version. Text embedded on signs within the images is included in the scope of image reuse.

- scenes/intro.webp: Introduction before broadcast ends
- scenes/winter-schedule.webp: Floor plan of tonight's promise
- scenes/radio-studio.webp: Broadcast room
- scenes/amber-cafe.webp: Amber Cafe
- scenes/campus-rooftop.webp: Rooftop
- scenes/first-snow.webp: First snow scene
- characters/nanami.webp: Nanami
- characters/sumi-yukimura.webp: Sumi Yukimura
- characters/radio-director.webp: Player

Images use relative paths within the world and are served from /api/asset. Matching with original images is verified by tools/first-snow-jp.test.mjs. Conversation histories, databases, pre-generated worlds, and voice settings from the old version are not carried over.
