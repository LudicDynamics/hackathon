# Archive Cabinet · 私人档案柜

## 命题

把游玩页想象成一间仍在使用的私人证物室：世界不是一组菜单，而是中央证物桌上正在被观察的空间。档案柜只在玩家需要回看、换取对象或核对责任时拉开。记忆点是“同一张桌面上，纸面线索和真实落盘记录彼此对照”。

材质语法只有四种：亚麻墙面、粗纤维纸、铅笔线、低饱和红/蓝/黄标记。金属夹与封条只作为方向提示，不把页面做成复古道具展。没有图片时，钥匙、地图、头像都由简单线条和色块保留可读信息。

## 页面构图

- **中央证物桌（主舞台）**：占据最大面积，三件证物有轻微不同旋转和重叠关系，像一张可探索的工作桌，不是等宽列表。蓝色封条信件、黄铜钥匙、北墙地图分别代表证据、物品、未证实记录。
- **左侧索引轨（低频家具）**：物件、人物、故事、活动、存档五个抽屉标签。它不抢画布注意力，点击后从左侧拉出档案抽屉。
- **右侧人物卡（角色入口）**：林澄的 presence、当前状态和“进入她的私域”主入口独立于故事台词；人物索引里有同一入口的等价路径。
- **底部行动台（唯一主确认）**：物品槽 + 意图输入 + “确认这一个行动”。只有这一处会确认行动，不在证物卡和详情页重复放第二个执行按钮。
- **详情纸页（阅读层）**：点击证物进入右侧 detail/read 面板，包含证据、事实、猜测三段着色但克制的分层。详情页不会移动或替换证物桌。
- **活动/事实抽屉**：活动记录以时间线和处理结果呈现；故事抽屉的事实记录以档案条目呈现。两种表达明确区分“系统做过什么”和“世界现在多了什么”。

## 交互路径

1. 默认态：先在中央证物桌识别三件对象，状态条提示“桌面已就绪”。
2. 点击信件/地图/钥匙：打开 detail/read。详情中的证据、事实、猜测有不同层级标签。
3. 钥匙可拖进底部行动槽，也可点击后在详情中按“把它放入行动台”；拖拽没有键盘依赖，槽位支持 Enter/Space 等价操作。
4. 输入意图后只启用一个确认按钮。点击后依次显示：`已接收，等待世界处理（accepted）` → `处理中 · 正在核对锁孔（processing）` → `已落定 · 行动写入档案（landed）`。
5. 落定后活动抽屉自动打开，展示这次落盘事实；活动抽屉另保留一次静态 `rejected` 示例（尝试进入不存在的北墙门），说明拒绝不会改变世界。
6. 人物索引与右侧人物卡共用私域入口。打开私域入口只显示“准备进入”，不会伪装对话已经发生。

## 状态与事实诚实度

- `accepted`：意图被接收，尚未写入世界；状态条写明“世界还没有改变”。
- `processing`：正在核对锁孔，只表达进行中，不用动画代替结果。
- `landed`：锁孔吻合并写入档案；活动抽屉提供可回访说明。
- `rejected`：静态活动样例明确说明“没有可进入的门、没有改变世界”。
- 证据是玩家能直接看见或检查的材料；事实是已落盘、可回访的记录；猜测是玩家方向，明确不会自动写入世界。

## 动效、降级与无障碍

- 动效只用于证物 hover、抽屉拉出和状态条出现；效果开关关闭时仍保留颜色、文字、焦点和可操作路径。
- `prefers-reduced-motion: reduce` 将所有过渡降为瞬时；不依赖位移、粒子或图片来传达落定。
- 所有主要触点是原生 button/input，详情页和抽屉有 dialog 语义，Escape 关闭并回焦触发控件，状态条使用 `aria-live`。
- 390px 构图不是桌面缩小：索引轨变成横向文件标签，角色卡收进抽屉，中央桌面仍占主舞台，行动台固定为两行“槽位 + 输入/确认”。
- 外部字体加载失败时回退到 Georgia、Segoe UI、等宽字体；所有图像内容本身为 CSS 线稿，因此无图仍可读。


## 连续世界窗口（新增）

- **世界坐标**：证物桌不是固定面板，而是 `1400 × 820` 的连续纸面；390px 手机使用 `1080 × 710` 纸面。视口只是这张纸的窗口，证物用世界坐标落点，不卡在窗口四角。
- **操作**：在证物之间的空白桌面按住拖动即可平移；滚轮以指针位置为锚点缩放（72%–145%）。触屏使用同一 pointer 拖动路径；原生证物按钮仍可直接阅读，拖放钥匙到行动台与相机平移不冲突。
- **第二片空间**：向左移动桌面后可发现 `NORTH WALL / CONTINUATION` 的封存西侧储物柜。它是同一世界纸面的远端区域，不是弹窗或另一个列表，初始窗口不会提前剧透。
- **连续性**：detail、档案抽屉、活动回执和底部行动台都是窗口上的覆盖层；打开或关闭它们不会重置 `worldCanvas` 的平移/缩放。效果关闭和 reduced motion 仅移除过渡，不改变相机与世界坐标。
