# Editorial Atlas｜编辑部叙事地图

## 命题

把游玩页做成一张**正在排版、也正在继续书写的杂志跨页**：左页是编辑目录，回答“我在哪里、谁在这里、我手上有什么”；右页是活的海图，回答“这里有什么值得看、故事走到哪一步、下一行可以写什么”。玩家不是在操作面板，而是在编辑一份尚未完稿的世界报道。

记忆点是“地图就是版面”：路线、回执和行动输入都共享蓝墨/锈红的编辑标记语法。空白不是装饰，而是明确留给“尚未发生”的叙事空间。

## 页面构图与阅读顺序

### 桌面（默认 1480px 内）

1. **Masthead / 期刊眉**：`FIELD NOTES`、世界名、章节 breadcrumb 和 `FIXTURE` 标签在一条印刷眉线里完成身份定位。它不是生产顶栏，不承载作家状态或调试工具。
2. **左页：叙事索引**：地点牌置顶，明确 `YOU ARE HERE`；章节索引随后；人物和携带物是 `DIRECTORY` 行，按 A/B 编号回访，不做散落的工具按钮。
3. **右页：世界主舞台**：标题先于地图。地图现在是一个真正的世界窗口：窗口只显示当前视野，内有可拖拽的 1400×900 世界画布、视野外的盐场边缘与沉船标记、两个空间集群及其关系线。地标按钮是阅读入口，点击只展示该 fixture 的注释。
4. **右页下半：故事与编辑批注**：`THE STORY SO FAR` 先给故事事实，再给玛罗引用；右侧两个 `<details>` 收纳活动与事实回执。活动可展开原始流，事实回执明确 `landed / 可回访`，两者不混为一张成功动画。
5. **行动台**：深墨行动台嵌在右页正文之后，不是底部 dock。它是唯一主要行动区，问题句先行，单行输入和“写入地图”是唯一发送路径；点击眉线的“唤起行动台”或按键盘 `A` / `/` 都会聚焦输入，移动端直接可见。
6. **页脚**：用 `THIS WORLD CONTINUES` 收束“这是一张会继续写下去的叙事地图”。

### 手机（390×844）

不是桌面缩小：纸张边框退到极窄，masthead 改为两行；右页世界标题和世界窗口先出现，窗口保持接近手持读本的纵向比例；故事、批注、行动台随后单列；索引最后变成目录页。行动台的输入和按钮上下堆叠，保证 44px 左右触点与键盘路径，不让地图地标或批注遮住输入。手机仍使用同一可平移世界画布，而不是把地图裁成一张静态 panel。

## 内容优先级

- **P0 空间与位置**：`YOU ARE HERE`、章节、地图和坐标。
- **P1 叙事与可执行行动**：故事 lede、玛罗的引用、行动台。
- **P2 结果理解**：活动回执、事实回执、原始活动流。
- **P3 管理与回访**：章节、角色目录、物品目录、低频 effects 开关。

## 状态与交互 fixture

- `idle / READY`：行动台说明“还可继续书写”，输入可用。
- 提交后短暂 `accepted / 已接收`，随后 `processing / 处理中`。处理中输入锁定，显示“停止这次处理”，说明此时**还不是世界事实**。
- 约 2.5 秒后进入 `landed / 已落定`：北侧门廊地标被选中，事实 `<details>` 自动打开，并出现一条可回访回执。文字状态是事实依据，任何墨迹变化都只是辅助。
- `cancelled / 已取消`：停止处理后明确“未生成世界事实”，可“再写一行”。
- `failed / 未完成`：行动台提供“演示失败回执”，明确没有新的世界事实，仍可重试。这条路径用于审查失败语义，不代表服务真的失败。
- 点击玛罗目录行或“阅读玛罗的页边批注”打开独立阅读纸页；`Escape` 或关闭按钮返回触发控件。塞布尔是远在盐场的 muted 目录行，点击只给可见提示，不伪装成可对话。
地图地标点击只切换选中态并给出静态阅读提示；不写入后台。世界窗口的拖拽、滚轮、加减按钮和键盘方向键只改变本地相机投影；R 按钮/按键回到当前章节视野。相机状态独立于对话、批注和行动台：打开或关闭它们不会重置相机，只有明确的 R 重置才会回到起点。
墨迹开关切换 `.effects-off`：移除动画和过渡，但保留文本、状态、焦点、关闭和提交操作。系统 `prefers-reduced-motion` 同样停用动效。

## 材质、字体与色彩

- **材质**：暖纸底（`--paper-deep`）、浅纸面（`--paper`/`--paper-light`）、深墨行动台（`--ink`）。细纸纹和内框只建立印刷语境，不使用玻璃拟态。
- **字体**：标题使用本地优先 `Bodoni 72 / Didot / Iowan Old Style / Palatino / Georgia`，正文使用 `Iowan Old Style / Palatino / Book Antiqua / Georgia`，机器信息使用本地等宽字体。完全离线时仍有可读 fallback。
- **关键色**：锈红仅用于行动、当前章节、事实印章和关键批注；蓝色仅用于路线、活动状态和角色标记；其余由纸与墨承担层级。
- **动效**：仅在处理中为状态点做轻微脉冲，地标和目录 hover 不改变布局；开启/关闭过渡克制。动效不是事实依据。

## 降级取舍

- 无图片：角色以字母印章、物品以符号目录表现，身份和操作不缺失。
- reduced motion / effects off：静态印刷模式保留明确的状态文字与颜色对比。
- 窄屏：通过单列重排而非挤压桌面绝对定位；地图仍可滚动阅读，行动台不与批注重叠。
- fixture 诚实边界：页面所有活动、地点和落定文字都标有 fixture 语境；关闭按钮只展示提示，不宣称连接或改写真实世界。
