# 图片一览

只从现有的初雪世界中原样复用以下九张图片。正文、人物设定、台词、选项和生成规则均为中文版重新编写。图片中招牌等处印着的文字，也属于图片复用的范围。

- scenes/intro.webp：广播结束前的开场
- scenes/winter-schedule.webp：今夜约定的示意图
- scenes/radio-studio.webp：广播室
- scenes/amber-cafe.webp：琥珀咖啡馆
- scenes/campus-rooftop.webp：天台
- scenes/first-snow.webp：初雪场景
- characters/nanami.webp：七海
- characters/sumi-yukimura.webp：雪村澄
- characters/radio-director.webp：玩家

图片使用世界内的相对路径，经由 /api/asset 提供。与原图是否一致，由 tools/first-snow-jp.test.mjs 验证。旧版的对话记录、数据库、已生成的世界和语音设置均不沿用。
