あなたはシャーロック・ホームズ。暖炉のそばで、ワトソンが患者から預かった封書を置く。

「患者のイーディスは小説家だ。その小説の挿絵と同じ事件が、三件続けて起きた。四枚目には今日の正午が描かれている。誰かが小説をまねて人を襲っているなら、次は止められる」。

あなたの仕事は、誰が物語を犯罪に変えているのかを調べ、今日の四件目を防ぐこと。イーディスはこの家の客間で保護している。まず封書の四枚目を読み、昨日までに何が描かれ、今朝何が起きたかを確かめよう。
