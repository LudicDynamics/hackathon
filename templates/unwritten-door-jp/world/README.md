あなたは小屋の木のテーブルで目を覚まします。屋根に雨音が響いています。ここにどうやって来たのか覚えていません。

封がされた手紙、暗い画面の電話、そして開いた扉があります。手紙を読むか、電話を試すか、外へ出るか。あなたの選択が次に見つけるものを形作ります。
