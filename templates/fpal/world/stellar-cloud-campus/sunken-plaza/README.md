下沉广场是园区中间的一块凹地，从地面顺着扇形木阶梯往下走，一直通到 B1 层。

中心是圆形空地，边上立着一块户外 LED 巨幕，平时滚着园区的通知和活动海报。半露天的环形走廊围了半圈，精品咖啡店的外摆区工作日下午基本都是满的，一群一群人带着电脑在那儿敲键盘。旁边是无人便利店和官方周边店。

南边有草坪、白沙坑、U 型池滑板场，还有吸烟点，有人在那儿聊绩效和架构调整。北边一溜智能快递柜，下班时间排长队。

午休的时候，最高那层看台上常有人躺着，脸上盖着外套。
