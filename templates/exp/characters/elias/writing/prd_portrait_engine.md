# PRD: 人像绘制引擎 (Portrait Engine) - MVP v0.1

**作者:** Elias (埃利亚斯)
**状态:** 草案 / 待评审
**目标:** 构建一个参数化的人物肖像生成系统，通过组合预设的图层模板与可控参数，生成风格化（非写实）的人物形象。

---

## 1. 背景与动机

在静态图形生成场景中，人物绘制是当前最薄弱的环节。手绘路径 (path) 对比例和结构敏感，容错率极低。
本项目的本质是**将“艺术问题”转化为“工程问题”**：预先定义高质量的组件库，用户（角色）仅通过参数组合来“装配”形象，而非直接绘制。

参考实现思路：Picrew 的分层装配机制 + Rough.js 的手绘质感渲染。

## 2. 目标用户

- 需要表现自身或他者形象，但不具备手绘能力的 AI 角色。
- 需要一致性人设图（同一人物多次生成需保持同一张脸）的角色。

## 3. 核心功能需求

### 3.1 图层结构 (Layers)
渲染顺序从后到前，固定层级：
1.  **背景 (Background)**: 纯色 / 简单纹理（如粗糙纸质感）
2.  **身体 (Body)**: 肩颈 / 上半身轮廓（MVP 可先简化为“剪影”）
3.  **头发后层 (Hair Back)**: 头发中位于脸后方的部分
4.  **五官 (Face)**: 眉、眼、鼻、嘴（核心难点，见 3.3）
5.  **眼镜/配饰 (Accessories)**: 眼镜框、耳饰等（可选）
6.  **头发前层 (Hair Front)**: 刘海、鬓角等覆盖在五官之上的部分

### 3.2 参数系统 (Parameters)
每个图层至少包含：`style_id`（选择哪个预设）+ `color`（主色）+ `offset_x/y`（微调位置）。

### 3.3 五官子系统 (关键)
- **眼睛 (Eyes)**: 至少 3 种基础风格（圆眼/丹凤眼/下垂眼），支持 `eye_scale`, `eye_distance`, `eye_height` 微调。
- **嘴 (Mouth)**: 至少 3 种（直线/微笑/抿嘴），支持 `mouth_width`, `curvature`。
- **眉 (Brows)**: 至少 3 种（平眉/剑眉/八字眉），支持 `brow_angle`。

### 3.4 风格化渲染 (Rendering)
- 底层使用 **Rough.js** 绘制，确保输出具有手绘质感，线条允许微小抖动。
- 必须支持导出为静态 PNG / SVG。

## 4. MVP 范围 (v0.1)
- [ ] 头像模式（仅头部+肩部剪影）
- [ ] 参数 ≤ 12 个（风格选择类 ≤ 6 个，数值微调类 ≤ 6 个）
- [ ] 预置 1 个默认角色模板（详见附录 A）
- [ ] 单 HTML 文件交付，无后端依赖

## 5. 非目标 (Non-Goals)
- ❌ 写实风格
- ❌ 任意笔刷自由绘制
- ❌ 动画支持
- ❌ 用户上传自定义图层

## 6. 验收标准
1.  修改任一参数后，能实时看到渲染结果变化。
2.  同一组参数生成两次，形象高度一致（粗略目视一致即可，Rough.js 抖动除外）。
3.  默认模板渲染结果需通过“特征可辨识”测试（见附录 A）。

---

## 附录 A：默认角色模板需求（代号: M.R.）

首个模板用于验证引擎的表现力上限，特征描述如下：

| 图层 | 参数 | 描述 |
|---|---|---|
| 发型 | style: 短碎发, color: 墨黑 | 蓬松、微微凌乱，发丝线条柔和 |
| 眼睛 | style: 下垂眼, color: 深棕 | 温和，笑起来会弯成缝（需支持表情参数） |
| 眼镜 | style: 细金属框, color: 黑 | 圆角矩形镜框，有轻微反光留白 |
| 肤色 | color: 暖调米白 | — |
| 表情 | style: 微笑(闭眼), curvature: 高 | 嘴角上扬幅度明显，眉眼放松 |
| 衣领 | style: 法兰绒衬衫, color: 姜黄/黑格纹 | 领口微敞，格纹用简化几何线条表现 |

**验收特征点：** 看到渲染图的人应能联想到“一个爱笑的、戴细框眼镜、穿黄色格纹衬衫的男生”。不要求精确还原，要求“神态对味”。
