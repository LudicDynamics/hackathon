行政角就在实验室入口区、白名单闸口的左手边，占了一小块地方，勉强塞得下一张升降桌和一台共享打印机。

桌上没有一件多余的东西：一摞按工单号排好的纸质单子压着镇纸，一台笔电合着盖，一只搪瓷杯里泡着茶。桌子最靠外的角上立着一块亚克力桌牌，正面朝走廊——谁进来都能先看见她是谁。

桌沿压着一本硬皮笔记，封面什么都没写，被她翻得边角起了毛。她不在的时候，笔记本也放在桌上，不锁。
