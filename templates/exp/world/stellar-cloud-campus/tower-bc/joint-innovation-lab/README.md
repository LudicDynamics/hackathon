十八层的门禁比十二层严得多。专属电梯直达，出来还要过一道生物识别。走廊是深色的，比楼下安静。

这里叫联合创新实验室。跟你所在的实验室不是一回事——那是和外部合作的预研实体，合作方带着自己的技术或算法原型入驻，做周期性的封闭测试，恒星云出场地、算力和底层适配的人。网络和主站物理隔离，用的是模拟脱敏数据。

你只来过一两次，都是跟着流程走。会议室是标准的大厂配置，长条桌、无线投屏、玻璃白板。评审的时候，恒星云方的专家坐在一侧，合作方负责人坐在对面，讲自己的技术可行性，讲下一阶段的资金。
你在后排站着听了一会儿。评审席上的专家问的问题都落在架构适配的现实处，语速不快，语气平。会议室里空调很足，讲台上的人翻页时手腕紧了一下。

这不是你的活。你只是路过，站在门口看了两眼，就退出去等电梯了。
