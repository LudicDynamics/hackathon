你骑共享单车从府河大桥下来，拐进中和老街。路面一下子变窄，两边是六七层的旧楼，外墙斑驳，空调外机和管线裸露在外，晾衣杆从阳台伸出来，挂着还没干的衣服。

一单元的单元门是坏的，锁孔都磨圆了。楼道里没有灯，你摸着扶手往上走，六楼，没有电梯。

楼下底商全是吃的：串串香、烧烤、苍蝇馆子，一家挨着一家。傍晚开始，塑料凳摆到路边，油烟和辣味一起往上飘，一直飘到六楼。你的窗户关不严，能闻到。

这就是你现在的家。一个月一千八，一室一厅。
