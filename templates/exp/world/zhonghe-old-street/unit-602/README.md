六楼，没有电梯。你走到门口的时候气还没匀。

防盗门是老式的，锁孔磨得发亮。推开门，先是一小段玄关，鞋架和半高鞋柜挤在一起，门后挂着购物袋、胸包和一把备用的黑伞。

往里是客厅，也是你的工作区。一张长条电脑桌靠墙放着，带鱼屏亮着，桌下的主机上插满了各种接收器和数据线。另一边是一张旧布艺沙发和矮茶几，茶几上堆着没拆的快递、几罐饮料、一台 Switch。

客厅侧面是厨房，没有门，直接连通。内侧是卧室。走廊尽头是卫浴间。客厅外还连着一小块阳台，晾衣架上挂着几件深色的衣服。

五十平，一个月一千八。你在这儿住了快一年。
