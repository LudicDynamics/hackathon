# AIRP failure and revisit contract

This is the single shared contract for failure, interruption, repeated input, generation, and degraded media. Domain skills add only their own expression or operation concerns.

## Stages

Use these stages for any asynchronous or generated action:

`accepted → processing → landed → revealed → completed`

`rejected`, `failed`, and `cancelled` are terminal branches. “Accepted” means the request was received, not that a writer ran or a world fact exists. The exact automatic-writing mode is a world/runtime decision; do not invent an unconditional immediate-completion promise.

## Failure classes

- **Rejected** — a prerequisite, permission, or declared boundary is missing; do not consume or roll; name the missing thing and a viable next step.
- **Execution failure** — the attempted action was valid but did not succeed; apply only the previously disclosed cost, keep recoverable evidence, and offer a real alternative.
- **Service failure** — a model, image, audio, or network service failed; preserve already landed text and facts, say what is unavailable, and do not silently retry.
- **Cancelled/interrupted** — preserve committed facts, remove only uncommitted presentation, and resume or revisit without double settlement.

## Repeat identity

The same intent, target, prerequisites, authorization, risk, and world context reuses the existing result. A changed material, target, authorization, risk, or world version is a new attempt. Re-entry and repeated clicks must not duplicate rewards, costs, generated locations, or rolls.

## Growth boundary

One generation increment is playable only when it has a readable entry, at least one actionable target, required facts or objects, a return path, and an explicit missing/failed state. A partial set is processing/partial, never complete. Text and a usable path precede optional imagery and ambience.

## Revisit proof

On revisit, the player should find the same landed facts and a clear next action. A second visit may repair missing pieces, but it must not silently rewrite settled truth or reroll the same action.
