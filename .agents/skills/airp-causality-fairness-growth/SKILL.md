# AIRP causality, fairness, and growth

## Use this skill when

Use it whenever a proposal says **success**, **failure**, **cost**, **proof**, **generated**, **unlocked**, **remembered**, or **changed**. This skill owns whether the result is real. It does not decide whether the result is fun; that belongs to `airp-play-and-sandbox`.

Read [the shared vocabulary](../_shared/shared-vocabulary.md) and [the failure contract](../_shared/failure-and-revisit.md).

## The product answer

A result is real only when this chain can be pointed to:

`intent → prerequisites and material check → authorization/risk check → execution or fair random decision → result and cost land → player-readable evidence → next step and revisit`

“Accepted” is not “completed.” A model reply, a new filename, a generated image, or an event entry is not enough by itself.

## Decide in this order

1. **Classify the intent.** Is it a question, proposal, low-risk action, evidence submission, or uncertain execution? Do not let a plan bypass a prerequisite or risk confirmation.
2. **Separate facts.** Record fixed facts, changeable facts, and claims still to be checked. A world skill may authorize a changeable fact; this skill must not let a writer invent a new truth merely to satisfy the prompt.
3. **Check before acting.** Verify the actual target, material, relationship, permission, and current world context. File presence is physical evidence, not proof of deduction, consent, or ending.
4. **Expose uncertainty.** Use deterministic resolution when the outcome is already known. Use random resolution only for genuine execution uncertainty, after showing the reason, odds, rewards, costs, and the choice to proceed. Never use dice to outsource a fixed truth.
5. **Land before performing.** Distinguish `accepted → processing → landed → revealed → completed`; branch honestly to rejected, failed, or cancelled. Sensory performance can amplify a landed result but cannot establish it.
6. **Bound growth.** One generation increment needs a readable entry, an actionable target, required facts or objects, a return path, and an explicit missing/failed state. Text and a usable path come before optional imagery or ambience.
7. **Protect identity and revisits.** The same intent, target, prerequisites, authorization, risk, and context reuses its result. Changed material, target, authorization, risk, or world version creates a new attempt. Interruptions inherit the original identity; they do not double-settle.
8. **Hand off expression.** Ask `airp-natural-flow-direct-manipulation` how stages are operated, `airp-human-language-information-hierarchy` how the actual state is said, `airp-aesthetic-performance-attention` how it is amplified, and `airp-decision-governance` what evidence supports the claim.

## Hard stop conditions

Do not call an action complete when prerequisites were not checked, risk changed after consent, a failure was hidden, the only proof is a backend event, a repeat visit rewrites settled facts, or a partial generation lacks a playable return path. Image/audio failure must preserve landed text and facts. No silent retries.

## Decision output

Return: intent classification; fact class; prerequisites and authorization; deterministic/random decision and disclosed cost; stage; durable readable evidence; repeat identity; failure/revisit behaviour; evidence level; unknowns. If the runtime mode changes what can happen next, name the mode instead of promising “immediate generation.”
