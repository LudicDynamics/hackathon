## 1. 视觉语言（YC 风）

- 字体 Inter Tight 900，字距 -4%，大到压满屏宽 60–80%。
- 墨黑 `#0A0A0A` · 纸白 `#F4F1EA` · 唯一强调色 YC 橙 `#FF6600`。
- 2D 虚拟相机 + 运动模糊，spring 激进推拉；录屏做跟随光标自动放大，AI 等待片段 4–8× 变速。
- 转场只用：拍点硬切 / 2 帧白闪 / 甩镜 / 画布缩放穿越。

## 4. 音乐

- **OneRepublic《Sunshine》不能用**：有版权、有人声，公开发布的 demo 视频会被平台识别下架。
- **v1 先用自己合成的 120 BPM 纯器乐占位轨**（`remotion/public/music/`），段落与上表对齐，没有歌词。
- 定稿时换成有授权的纯器乐（Artlist / Epidemic Sound / YouTube Audio Library 里搜 "upbeat electronic 120 bpm" 或 "Sunshine" 那种明亮流行感的伴奏）。换曲只要改 BPM 和 drop 位置。
- 仓库自带的 CC0 / 魔王魂曲目偏安静，只用在 S3 / S5 的底噪或转场音效（`assets/audio/foley/*`：掷骰、翻页、开门、写字）。

## 5. 工程与渲染

```sh
cd video/remotion
npm install && npm run sync          # 从 templates/ 复制素材到 public/（public 媒体已 gitignore）
npm run studio                       # 浏览器里逐帧预览；每段 S0–S7 也是独立 Composition
sh scripts/render-chunks.sh          # 960×540 预览 → out/worldlines-launch-preview.mp4（约 7 分钟，可断点续渲）
SCALE=1 OUT=out/worldlines-launch.mp4 sh scripts/render-chunks.sh   # 1080p 成片
```

- 录屏放进 `video/footage/`，再复制到 `remotion/public/footage/`，文件名以 `r0-` / `r1-b` … 开头即自动替换占位；从长片里截取就在 `src/lib/cuts.ts` 给对应槽位加 `from`（秒）/ `rate`（变速）。
- 不要一次性整片渲染、也不要把并发调高：之前 8 并发 + 运动模糊把内存打满、渲染进程被杀。分段脚本每段一个新进程。
- 画布卡片必须各自在屏幕坐标里定位（`components/Canvas.tsx`）；整块世界层做 transform + filter 会被 Chrome 裁掉一半。
