# 中文旁白录音稿（你自己念）

- **跟读视频**：`remotion/out/worldlines-launch-v19-zh-novo.mp4`——中文版画面 + 音乐 + 角色原声，没有旁白；每句旁白的中文字幕会在它该出现的时间显示，看着字幕念。
- **怎么录**：每句一个文件，按下表编号命名 `n-00.wav`、`n-01.wav`……（m4a / mp3 也行），放进 `video/vo-recordings/zh/`。句首句尾留点空白没关系，会自动裁掉；音量会自动统一。
- **窗口**是这句在片子里能用的时长；超出一点会自动加速（最多 1.25 倍），超太多会标 LONG，重录时念快一点或换个短说法。
- **云扬参考**是 TTS 念这句用的时长，给你当语速参考。
- **角色台词**（Vera、Ryo、Elias 的字幕）不用念，保留原声。

录好（哪怕只录了一部分）后，在 `video/` 目录运行：

```sh
CAPTIONS_FILE=captions-zh.ts NARRATOR_PROVIDER=files NARRATOR_DIR=vo-recordings/zh VO_TAG=zh-self node music/make-narration.mjs
cd remotion && DIR=out/chunks-1-zh V=v19 sh scripts/mix-vo.sh zh-self
```

成品：`remotion/out/worldlines-launch-v19-zh-self.mp4`（不用重新渲染画面，几分钟）。没录的句子会显示 MISS 并跳过。
